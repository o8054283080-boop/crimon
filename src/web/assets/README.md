# 画像の置き場所

**配信される画像はすべてここにある。**他の場所には置かないこと。

`src/web/assets/` の直下にはファイルを置かない。必ず用途のフォルダへ入れる。
直下に増えていくと、何がどの画面のものか分からなくなる
(実際に20枚まで溜まり、その中に**2.1MBの未使用ファイル**が紛れていた)。

| フォルダ | 中身 | 枚数 |
| --- | --- | --- |
| `monsters/` | モンスターの絵。`sprites.json` が色と縦横比を持つ | 60 |
| `home/` | ホーム画面の部品(世界の絵・枠・行き先の札) | 23 |
| `stages/` | ステージの絵 | 8 |
| `backgrounds/` | 各画面の背景とタイトル絵 | 7 |
| `cards/` | ホームから入る各画面のカード絵 | 6 |
| `brand/` | ロゴ・紋章・飾り罫 | 6 |

## モンスターの絵の決まり

`spriteUrlFor()`(`src/web/three/spriteArt.ts`) が**名前だけで引く。**

```
<種族>-<属性>.webp   属性ごとに別の絵があるとき   ancient_beast-FIRE.webp
<種族>.webp          6属性で色替えして使い回すとき  abyssreaper.webp
<種族>-idle.webp     コマ送りの待機アニメ          slime-idle.webp
```

**1枚の絵を6属性で色替えして使い回す**のが基本。属性ごとに描き分けるのは
見た目が大きく変わる種族(古代のけもの等)だけ。
`sprites.json` のキーはファイル名(拡張子なし)と一致させること。

## 配信しない元素材は `art/` へ

大きい生データ(描き出す前のPNG等)は**ここへ置かない。**`art/` に置く。
配信されないのにビルドとリポジトリを重くするため。

| 場所 | 中身 |
| --- | --- |
| `art/monsters-raw/` | モンスターの生PNG(1枚2MB前後)。webpの作り直しに使う |
| `art/sources/` | アプリアイコンなどの元画像 |

## 使われていない画像を置かない

`tests/assets.test.ts` が**どこからも参照されない画像を落とす。**
将来のために残したいものは、そのテストの `KEEP_UNUSED` へ
**理由を書いて**加えること。理由なく残っている画像は、次に触る人が
消していいのか判断できない。
