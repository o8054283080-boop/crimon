# 元素材(配信しない)

**ここのファイルはアプリに含まれない。**作り直すために置いてある。

| フォルダ | 中身 |
| --- | --- |
| `monsters-raw/` | モンスターの生PNG。`src/web/assets/monsters/*.webp` の元 |
| `sources/` | アプリアイコンの元画像。`public/icons/*` の元 |

## 置く時の決まり

- **配信する画像をここへ置かない。**画面に出す絵は `src/web/assets/` へ
- 生PNGは1枚2MB前後ある。**変換したら、対応するwebpがあることを確かめる**
- ここが重い自覚を持つこと。いまで27MBあり、**リポジトリの半分以上**を占める

## 消してよいか

`monsters-raw/` は全12枚が `src/web/assets/monsters/` に変換済みで、
**アプリの動作には要らない。**それでも残しているのは、
絵を描き直す時に元の解像度が要るため。

もし容量が問題になったら、git の履歴からは消えないので
**追跡を外す(`.gitignore`)だけでは軽くならない。**その場合は
別の場所(クラウド等)へ移す判断が要る。
