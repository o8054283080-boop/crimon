# 元素材(配信しない)

**ここのファイルはアプリに含まれない。**道具が使う元絵を置く。

| フォルダ | 中身 | 使う道具 |
| --- | --- | --- |
| `sources/` | アプリアイコンの元画像 | `tools/bakeAppIcons.mjs` → `public/icons/*` |

## 置く時の決まり

- **配信する画像をここへ置かない。**画面に出す絵は `src/web/assets/` へ
- **ここへ置くのは、道具が名指しで使うものだけ。**
  「いつか使うかもしれない」で置くと、誰も消せなくなる
- 置いたら、使う道具を上の表に書くこと

## モンスターの生PNGを消した経緯

`monsters-raw/` に12枚(27MB)の生PNGがあった。**リポジトリ52MBの半分以上**を
占めていたが、全部 `src/web/assets/monsters/*.webp` に変換済みで、
**アプリの動作にも道具にも要らなかった。**

「絵を描き直す時に元解像度が要る」ため残していたが、
**git の履歴からは消えない**ので、必要になったら取り出せる。

```sh
git show c70675e^:art/monsters-raw/fenrir.png > fenrir.png
```

なお**作業ツリーが27MB軽くなるだけで、clone の大きさは変わらない。**
履歴に入ったものを本当に消すには履歴の書き換えが要り、
それは他の人の手元を壊すので、ここではやっていない。
