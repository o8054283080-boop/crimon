# crimon

モンスター4対4のターン制コマンドバトルゲーム(サマナーズウォー風)の基盤リポジトリです。

## ゲームの基本ルール

- **4vs4のターン制コマンドバトル**。行動順はSPD(速度)に応じて溜まるATBゲージ方式で決まります(ゲージが100%に達したユニットから行動)。
- **属性は全6種類**。
  - 火・水・電気・草の4属性は一周する三すくみ(四すくみ)の関係を持ちます。
    ```
    火 → 草 → 電気 → 水 → 火 …
    ```
    矢印の先の属性に対して1.5倍のダメージ、逆に攻撃されると0.5倍になります。
  - 光と闇は他の4属性とは無関係ですが、光と闇の間だけは互いに弱点(1.5倍)です。
- **モンスターは同じ種類でも6属性の色違いバリエーションが存在**します(例: スライムなら火/水/電気/草/光/闇のスライムがいる)。属性ごとにステータスの得意分野が少し変わります。
- **モンスターはスキルを3つ持ちます**。スキル1はクールタイム無しの通常攻撃で全属性共通ですが、スキル2・3はクールタイムのある強力な技(ダメージ・回復・バフ/デバフ・スタンなど)で、それぞれ3種類の候補から属性に応じて異なる組み合わせが選ばれます(同じ種類のモンスターでも属性違いで使えるスキル2・3が変わります)。6属性全てで(スキル2, スキル3)の組み合わせが重複しないように選ばれるため、同じ種族で技構成が完全に一致する2体は出ません。スキルの名前・効果・クールタイムは、モンスター詳細画面で確認できます。
- **モンスター図鑑**: モンスター一覧画面から「📖 モンスター図鑑を見る」で、所持の有無に関わらず全モンスター種×全属性のスキル構成を確認できます。各スキルはLv.1(初期)/Lv.4/Lv.5(最大)の実効値を並べて表示するので、レベルを上げると何がどう変わるかが図鑑上で確認できます。
- **スキルレベル(1〜5)**: 所持モンスターのスキルにはそれぞれ1〜5のレベルがあります。レベル2〜4はダメージ倍率・回復量・状態異常の発動確率が少しずつ上昇し、レベル5に到達すると威力の伸びは止まる代わりにクールタイムが1ターン短縮され、バフ/デバフの継続ターンが1ターン延びます。**ただしスタン・火傷は強力すぎるため、継続ターンはレベルによらず常に一定で、発動確率のみ成長します**。また、クールタイムの無いスキル1はレベル5でもクールタイム短縮の恩恵を受けられないため、代わりにダメージ・回復・発動確率がもう一段上昇します。
- **モンスター強化**: モンスター詳細画面の「💪 モンスター強化」から、いらないモンスターを素材にして経験値を与え、対象のレベルを上げられます。**どのモンスターでも素材にできます**(星・レベルが高いほど経験値の価値も高くなります)。さらに、**対象と同じ種族のモンスター(属性=色違いでもOK)を素材にすると、1体につきランダムでいずれか1つのスキルレベルも+1**されます。素材選択画面では同種のモンスターに★マークが付き、経験値・スキル強化の見込みがひと目で分かります。
- **回復スキルの多様化**: 回復スキルは最大HPに対する割合で回復するものが基本ですが、一部は施術者自身の**攻撃力・防御力に対する割合**で回復量が決まるタイプや、**与えたダメージの一部を自己回復に変えるライフスティール型**もあります(スキル説明に明記されます)。星が上がるほどスキルの威力・効果も強力になるよう設計されており、SR(グリフォン/セラフ)・SSR(ドラゴン/ネメシス)はどちらも全6属性で登場しますが、セラフ/ネメシスは同格のグリフォン/ドラゴンよりも強力な専用スキルを持ちます。
- **火傷・追加ダメージスキル**: 一部のスキルは相手に**火傷**を付与します。火傷を負ったユニットは、自身の手番終了時(スタンで行動できなかった時も含む)に自分の攻撃力と同じ量のダメージを受けます。また、自身のSPD(速度)やDEF(防御力)が高いほどダメージが伸びる追加効果を持つスキルもあります。
- **仮アイコン**: 専用のモンスターアイコン画像を用意するまでのつなぎとして、種族ごとに絵文字(🟢スライム/🐺ウルフ/🗿ゴーレム/🧚フェアリー/🐷転生ピッグ)を割り当てています。カード・詳細・図鑑・パーティ編成のアバターに表示されます。
- **バトル画面**: アリーナ風の背景に、敵チームを上段・味方チームを下段に丸いポートレート型で配置し、行動中ユニットの発光ハイライト・HPバー/ATBゲージ付きで進行します。「🤖 オート/✋ 手動」で切り替え可能で、オート時はAIが両チームとも自動で行動し▶再生/一時停止/x1・x2・x4速度切替/結果までスキップで観戦できます。**手動時は自分のモンスターの番になるとスキルと対象(単体対象スキルの場合)を自分で選んで操作**でき、敵の番は引き続きAIが自動で行動します。モード切り替えはバトルの途中でもいつでも可能です。

## 周回・育成の基本ルール

- **モンスターの入手方法**は2つ。①ガチャ形式の「召喚」(ダイヤを消費して1回/10連)、②ステージクリア報酬としてたまにドロップ。召喚は**星3以上が確定**で、星4はSR・星5はSSRの専用モンスターです。**光・闇属性はレア枠**(排出率低め)、それ以外の4属性(火・水・電気・草)は通常枠です。SR(グリフォン/セラフ)・SSR(ドラゴン/ネメシス)はどちらも全6属性で登場する新規モンスターで、どの属性で出るかとは関係なく2種類からランダムに決まります(セラフ/ネメシスの方がグリフォン/ドラゴンより強力な専用スキルを持ちます)。星が上がるほどステータス・スキルとも強力になります(具体的な排出率はゲーム内・READMEには非公開)。10連には天井があり、レア(光/闇)が1体も出なければ最後の1体が確定でレアになります。
- **ステージは全4チャプター、各チャプター5ステージ(1-1〜1-5, 2-1〜2-5, 3-1〜3-5, 4-1〜4-5)、各3ウェーブ構成**。ウェーブ間はHPを持ち越したまま連戦し(全滅した仲間はそのステージ内では復活しない)、各チャプターの5ステージ目だけボス戦になります。**全4チャプター20ステージを通しで見た「ステージ番号」を基準に、敵の星・レベル・実効ステータスが連続的に上昇していく**ため、チャプターをまたいでも強さが据え置きになったりリセットされたりせず、同じステージ番号(例: 1-3と2-3)でも必ずはっきり差が付きます。初心者でもチャプター1の序盤は無理なく勝てるよう調整しつつ、終盤のチャプター4のボス(最上位の星6に到達する唯一の敵)は、ランクアップやそのチャプターで手に入るテーマ装備でしっかり育てないと勝てないくらいの手応えがあります。ウェーブ・ステージクリア報酬(ゴールド・経験値)もチャプターが上がるほど大きくなります。
  - **チャプターごとのテーマドロップ**: チャプターをクリアすると、そのチャプター固有のテーマモンスター(星1)とテーマ装備シリーズ(星1)が出やすくなります。
    | チャプター | テーマモンスター | テーマ装備シリーズ |
    | --- | --- | --- |
    | 1 | スライム | 会心 |
    | 2 | ウルフ | 筋力 |
    | 3 | ゴーレム | 守護 |
    | 4 | フェアリー | 体力 |

    (具体的なドロップ確率はゲーム内・READMEには非公開)
  - **ボスステージのボーナスドロップ**: 各チャプターの最終ステージ(ボスがいるステージ)をクリアすると、装備ドロップの星がたまに+1されます(具体的な確率はゲーム内・READMEには非公開)。
  - **難易度(ノーマル/ハード/ヘル)**: ステージ詳細画面で3段階の難易度を選んで挑戦できます。難易度が上がるほど敵の星・レベル・実効ステータスが強化される代わりに、**ドロップする装備の星がハードで+1、ヘルで+2**上がります。同じステージでも難易度ごとに初回クリア判定・ダイヤ報酬は別枠で管理されます。
- クリア報酬はウェーブ毎のゴールド・経験値と、ステージクリア時のボーナスゴールド+モンスタードロップ抽選。**周回してレベルを上げたり、新しいモンスターを増やしたりして強くなっていく**循環が基本ループです。
- **レアリティは星1〜6**。星が上がるごとに最大レベルも上がります(星1:Lv15 / 星2:Lv20 / 星3:Lv30 / 星4:Lv40 / 星5:Lv50 / 星6:Lv60)。星6はガチャでは出現せず、星5を最大レベルまで育ててランクアップすることでのみ到達できる最上位ランクです。
- **ランクアップ(進化)**: 対象モンスターがそのランクの最大レベルに達すると、同じ星の他のモンスターを素材として犠牲にすることで星を1つ上げられます。ランクアップするとレベルは1に戻り、直後のステータスは進化前(旧星の最大レベル時点)の70%からのスタートになりますが、新しい星でレベルを上げ直すと最大レベル時点で進化前の1.4倍(複利)まで伸びます。レベルアップ自体でもステータスは伸びるため、進化直後は一時的に弱くなるものの、育て直すことで大きく強化される設計です。必要な素材数は星の数と同じ(星1→2は1体、星2→3は2体、星3→4は3体、星4→5は4体、星5→6は5体)。星6が上限で、それ以上のランクアップはできません。**SPD(速度)だけは星・レベルの影響を受けず、常に基礎値のまま**変化しません。
- **装備(ルーン)**: モンスターごとに6つの装備スロットがあり、スロット番号と同じ番号の装備しか装着できません(スロット1はATK+固定、スロット3はDEF+固定、スロット5はHP+固定、スロット2/4/6は複数候補からランダムなメインステータスが付きます)。装備にはメインステータス1つとサブステータス0〜4個が付き、星は1〜6まで。通常ステージのドロップは星1(そのチャプターのテーマシリーズ)固定・サブは最大2個までに制限されており、サブ付きの装備が出る確率はかなり低めにしてあります。
  - **装備の強化**: ゴールドを消費して装備を+0〜+15まで強化できます。強化するたびメインステータスが上昇し、+15到達時の上昇量は+1〜+14までの通常の上昇より大きくなります。+3/+6/+9/+12/+15に到達するたびサブステータスが強化され、サブがまだ4個未満なら新規に1個ランダム追加、既に4個埋まっていれば既存のサブのうち1つが強化されます。モンスター詳細画面の装備スロットから、装着中の装備をタップすると装備詳細画面に直接移動でき、そこからも強化できます(装備タブに移動し直す必要はありません)。
  - **星ごとのメイン初期値**: 星1〜4は一定間隔で初期値が上がりますが、星5・6は初期値が大きく跳ね上がり、強化1レベルあたりの上昇量(%・実数値とも)も星1〜4よりはっきり高く設定されています。
  - **装備セット効果**: 装備には7種類のシリーズがあり、同じシリーズを2個以上装着すると2セット効果が、4個以上そろえると2セット効果に加えて4セット効果も発動します(両方重複して発動)。
    | シリーズ | 2セット効果 | 4セット効果 |
    | --- | --- | --- |
    | 会心 | クリ率+15% | クリダメ+30% |
    | 筋力 | 攻撃力+20% | 与えるダメージ1.2倍 |
    | 守護 | 防御力+20% | 受けるダメージ0.8倍 |
    | 体力 | HP+20% | 毎ターンHP5%回復 |
    | 的中 | 状態異常付与率+15% | 敵の状態異常抵抗率25%無視 |
    | 抵抗 | 状態異常抵抗率+25% | 状態異常を抵抗した時HP15%回復 |
    | 速攻 | 速度+5% | 速度+12%(2セット効果と重複) |

    ※デバフ・スタン・火傷など状態異常の的中判定は、まずスキルごとの発動確率を判定したうえで、成功したら「(1 − 相手の効果抵抗率 + 自分の効果命中率) ÷ (1 + 自分の効果命中率)」の的中率でさらに判定します。この式により、効果命中率をどれだけ積んでも相手の効果抵抗率を完全には無効化できません(例: 効果命中率100%のモンスターが効果抵抗率50%の相手にスキル発動確率100%のデバフを当てると、的中率は75%になります)。
- **装備ダンジョン(1〜10階)**: より高い星・サブステータス4個が出やすい高難度専用コンテンツです。通常ステージと違い、クリアすると装備が1個確定でドロップします。1〜3階は星4まで、4〜6階は星5まで、7〜10階は星6までの装備が出現し、階層が上がるほど高レアリティが出やすくなります(具体的な排出率はゲーム内・READMEには非公開)。ただし攻略難易度が下がった1階付近ほど、もらえる装備の質はかなり渋め(低い星に大きく偏る)にしてあり、良い装備を狙うにはより深い階層への挑戦が必要です。
  - **専用パーティ**: 通常ステージの4体パーティとは別枠で、装備ダンジョン専用に最大5体まで編成できます。
  - **段階的な難易度**: 敵は全階層とも星5・Lv50(最大値)固定で、階層が上がるごとに敵の実効ステータス倍率(powerScale)がなだらかに線形上昇します。**1階は星3モンスターに星1装備くらいの、まだ育成途中のパーティでも挑める**入り口になっており、そこから階層を追うごとに着実に手強くなっていきます。10階は星5装備をフルで固めればしっかり勝てる水準ですが、**星6装備クラスならより安定して突破できる**最終関門です。装備ダンジョンの装備でさらに自分を強化しながら段階的に高い階層へ挑む、育成の最終到達点となる周回コンテンツです。
  - **単一属性の敵編成**: 各階層の敵は全員同じ属性で統一されています(火/水/電気/草を階層ごとに巡回)。その階層の弱点属性のモンスターでパーティを組めば、有利属性ボーナス(1.5倍ダメージ)を活かして格上の階層にも挑みやすくなります。階層選択画面・詳細画面には出現する敵の属性と弱点属性のヒントが表示されます。
  - **ボーナスドロップ**: 装備とは別に、低確率で「召喚の書」(全階層共通、約5%)がドロップします。「転生ピッグ」も全階層で低確率(約10%)にドロップし、1〜6階は星2、7〜10階は星3のピッグが出ます。
- **レベル上げダンジョン(初級/中級/上級)**: モンスターの経験値稼ぎに特化した専用コンテンツです。装備ダンジョンと同じく通常パーティ(4体)ではなく編成画面のパーティを使って挑みますが、消費スタミナは通常ステージ・装備ダンジョンより多い20です。その代わり、クリアで直接もらえる経験値が大きく、さらにクリアするたびに経験値フィード専用の「経験ピッグ」を確定で1体入手できます。**難易度が上がるほど獲得経験値・経験ピッグの星の両方が大きくなり**、上級では星6の経験ピッグが手に入ります。
- **転生ピッグ**: ランクアップ素材専用のモンスター。ガチャには一切出現せず、通常ステージ(低確率・約5%、星2固定)と装備ダンジョン(約10%、階層に応じて星2/星3)でのみドロップします。常にそのレベル上限(星2ならLv20、星3ならLv30)で手に入りますが、ステータスは同じ星の他モンスターよりはるかに低く、戦力にはなりません。ランクアップに必要な同じ星の素材として、育てた手持ちモンスターを犠牲にせずに済むための存在です。
- **経験ピッグ**: モンスター強化(経験値フィード)専用のモンスター。転生ピッグと同じく戦力にはなりませんが、用途はランクアップ素材ではなく経験値稼ぎで、レベル上げダンジョンでのみ確定入手できます。星が高いほど素材にした時の経験値量が大きくなるため、上級ダンジョンの星6経験ピッグは1体で大量の経験値を稼げます。
- **召喚の書**: ガチャ「召喚」1回分のチケットです。石を消費せずに単発召喚を1回行えます。通常ステージ(低確率・約1%)と装備ダンジョンの全階層(低確率・約5%)にドロップし、召喚画面から消費して使います。
- **スタミナ・ファイターレベル**: ステージ・装備ダンジョン・レベル上げダンジョンへの挑戦にはスタミナを消費します(通常ステージ5、装備ダンジョン10、レベル上げダンジョン20)。スタミナが足りないと挑戦できません。
  - スタミナは初期値150で、時間経過でも自然回復します(5分に1ずつ)。
  - プレイヤー自身の強さを表す**ファイターレベル**(上限30)があり、各コンテンツのクリアで経験値を獲得して上がります。ファイターレベルが上がるたびスタミナが全回復し、スタミナ上限も+10されます。経験値カーブはやや緩やかに調整されており、レベルが上がるほど次のレベルまでに必要な経験値が大きく増えていきます。
  - ホーム画面から**ダイヤを消費してスタミナを回復**できます(💎50で+100回復、💎200で全回復)。スタミナが満タンの時は実行できません。
- **ダイヤ(💎)の入手方法**: ステージ・装備ダンジョン・レベル上げダンジョンの各コンテンツを**初めてクリアした時は+200ダイヤ**、2回目以降のクリアではそのコンテンツの消費スタミナと同量のダイヤがもらえます(通常ステージなら+5、装備ダンジョンなら+10、レベル上げダンジョンなら+20)。ガチャ召喚の対価として使います。
- **オート周回**: ステージ・装備ダンジョンの詳細画面から「🔁 オート周回」で、任意の回数(1〜999)を指定して自動で連続挑戦できます。1回ごとにバトルを即座にシミュレーションして決着させ、スタミナが尽きる・敗北する・パーティ未編成のいずれかに達するとそこで自動的に中断します。終了後は挑戦回数・獲得ゴールド/ダイヤ/経験値・レベルアップ・ドロップ内容をまとめた結果画面が表示されます。
- **パーティ編成画面**: 上部に「通常パーティ」「🏰 装備ダンジョン専用」の切り替えタブがあり、どちらもこの画面から直接編成できます(装備ダンジョン画面からの入口も従来通り利用可能)。現在編成中のメンバーはホーム画面と同じスロット表示でひと目でわかるほか、編成中のモンスターカードには「✅ 編成中」バッジが付きます。
- **スクロール位置の記憶**: 一覧画面をスクロールした状態で詳細画面に入り、また一覧に戻ってきた時など、画面(+選択中の対象)ごとにスクロール位置を記憶して復元します。戻るたびに先頭までスクロールし直す必要はありません。

## 使い方

```bash
npm install

# ブラウザ版を開発モードで起動(スマホのホーム画面に追加できるPWA)

# ビルドしてプレビュー(本番相当のService Worker込みで確認)
npm run build && npm run preview

# 4vs4のオートバトルをコンソールで観戦する(CLI版)
npm run battle
# シード指定で再現可能なバトルにする
npx tsx src/simulate.ts --seed=42

# 型チェック
npm run typecheck

# テスト
npm test
```

## スマホのホーム画面に追加する(PWA)

`npm run build && npm run preview` (または実機からアクセス可能な形でホスティング)した上で、スマホのブラウザでURLを開きます。

- **iOS (Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: メニュー → 「アプリをインストール」/「ホーム画面に追加」(自動でインストールバナーが出ることもあります)

`vite-plugin-pwa` で `manifest.webmanifest` と Service Worker を自動生成しており、アイコン(`public/icons/`)・スタンドアロン表示・オフラインキャッシュに対応しています。PWAとして正しく認識させるには**HTTPS(またはlocalhost)での配信が必須**です。
