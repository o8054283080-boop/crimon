# crimon

モンスター4対4のターン制コマンドバトルゲーム(サマナーズウォー風)の基盤リポジトリです。

## ゲームの基本ルール

- **4vs4のターン制コマンドバトル**。行動順はSPD(速度)に応じて溜まるATBゲージ方式で決まります(ゲージが100%に達したユニットから行動)。
- **属性は全6種類**。
  - 火・水・電気・草の4属性は一周する三すくみ(四すくみ)の関係を持ちます。
    ```
    火 → 草 → 電気 → 水 → 火 …
    ```
    矢印の先の属性に対して1.5倍のダメージ、逆に攻撃されると0.5倍になります。
  - 光と闇は他の4属性とは無関係ですが、光と闇の間だけは互いに弱点(1.5倍)です。
- **モンスターは同じ種類でも6属性の色違いバリエーションが存在**します(例: スライムなら火/水/電気/草/光/闇のスライムがいる)。属性ごとにステータスの得意分野が少し変わります。
- **モンスターはスキルを3つ持ちます**。スキル1はクールタイム無しの通常攻撃、スキル2・3はクールタイムのある強力な技(ダメージ・回復・バフ/デバフ・スタンなど)です。

## 周回・育成の基本ルール

- **モンスターの入手方法**は2つ。①ガチャ形式の「召喚」(石を消費して1回/10連)、②ステージクリア報酬としてたまにドロップ。召喚では**光・闇属性はレア枠**(排出率低め・星3〜4確定)、それ以外の4属性は通常枠(星1〜2)。10連には天井があり、レアが1体も出なければ最後の1体が確定でレアになります。
- **ステージは1-1〜1-5の5ステージ、各3ウェーブ構成**。ウェーブ間はHPを持ち越したまま連戦し(全滅した仲間はそのステージ内では復活しない)、1-5の3ウェーブ目だけボス戦になります。ステージが進むほど敵が強くなりますが、初心者でもステージ1-1は無理なく勝てるよう難易度を調整しています。
- クリア報酬はウェーブ毎のゴールド・経験値と、ステージクリア時のボーナスゴールド+モンスタードロップ抽選。**周回してレベルを上げたり、新しいモンスターを増やしたりして強くなっていく**循環が基本ループです。
- **レアリティは星1〜5**。星が上がるごとに最大レベルも上がります(星1:Lv15 / 星2:Lv20 / 星3:Lv30 / 星4:Lv40 / 星5:Lv50)。
- **ランクアップ(進化)**: 対象モンスターがそのランクの最大レベルに達すると、同じ星の他のモンスターを素材として犠牲にすることで星を1つ上げられます。ランクアップするとレベルは1に戻りますが、ステータスは1.2倍(複利)になります。必要な素材数は星の数と同じ(星1→2は1体、星2→3は2体、星3→4は3体、星4→5は4体)。
- **装備(ルーン)**: モンスターごとに6つの装備スロットがあり、スロット番号と同じ番号の装備しか装着できません(スロット1はATK+固定、スロット3はDEF+固定、スロット5はHP+固定、スロット2/4/6は複数候補からランダムなメインステータスが付きます)。装備にはメインステータス1つとサブステータス0〜4個が付き、星は1〜6まで。通常ステージのドロップでは星1〜3・サブは最大2個までに制限されており、星3やサブ付きの装備が出る確率はかなり低めにしてあります。
  - **装備の強化**: ゴールドを消費して装備を+0〜+15まで強化できます。強化するたびメインステータスが上昇し、+15到達時の上昇量は+1〜+14までの通常の上昇より大きくなります。+3/+6/+9/+12/+15に到達するたびサブステータスが強化され、サブがまだ4個未満なら新規に1個ランダム追加、既に4個埋まっていれば既存のサブのうち1つが強化されます。
  - **星ごとのメイン初期値**: 星1〜4は一定間隔で初期値が上がりますが、星5・6は初期値が大きく跳ね上がり、強化1レベルあたりの上昇量(%・実数値とも)も星1〜4よりはっきり高く設定されています。
  - **装備セット効果**: 装備には7種類のシリーズがあり、同じシリーズを2個以上装着すると2セット効果が、4個以上そろえると2セット効果に加えて4セット効果も発動します(両方重複して発動)。
    | シリーズ | 2セット効果 | 4セット効果 |
    | --- | --- | --- |
    | 会心 | クリ率+15% | クリダメ+30% |
    | 筋力 | 攻撃力+20% | 与えるダメージ1.2倍 |
    | 守護 | 防御力+20% | 受けるダメージ0.8倍 |
    | 体力 | HP+20% | 毎ターンHP5%回復 |
    | 的中 | 状態異常付与率+15% | 敵の状態異常抵抗率25%無視 |
    | 抵抗 | 状態異常抵抗率+25% | 状態異常を抵抗した時HP15%回復 |
    | 速攻 | 速度+5% | 速度+12%(2セット効果と重複) |

    ※状態異常の抵抗判定は「相手の効果抵抗率 − 自分の効果命中率」で決まるようになり、装備の効果命中%ステータスが実際に意味を持つようになりました。
- **装備ダンジョン(1〜10階)**: より高い星・サブステータス4個が出やすい高難度専用コンテンツです。通常ステージと違い、クリアすると装備が1個確定でドロップします。1〜3階は星4まで、4〜6階は星5まで、7〜10階は星6までの装備が出現し、階層が上がるほど高レアリティが出やすくなります(具体的な排出率はゲーム内・READMEには非公開)。7〜10階の星6排出率は、初期実装時からおよそ半分まで下げてあります。
  - **専用パーティ**: 通常ステージの4体パーティとは別枠で、装備ダンジョン専用に最大5体まで編成できます。
  - **最上級コンテンツ**として敵は全階層とも星5・Lv50(最大値)固定で、階層が上がるごとに敵の実効ステータス倍率(powerScale)が1.7倍〜3.1倍まで線形に上昇します。装備なし・星4装備までの星5モンスターでは1階すら勝率1割未満で、**6箇所すべてを星5装備で固めた星5モンスターでようやく1階が現実的に突破できる**難易度です。目安として1〜5階は星5装備(サブ4個)、6〜10階は星6装備でないと安定して勝てないくらいに調整してあり、装備ダンジョンの装備でさらに自分を強化しながら段階的に高い階層へ挑む、育成の最終到達点となる周回コンテンツです。
  - **ボーナスドロップ**: 装備とは別に、低確率で「召喚の書」(全階層共通、約5%)がドロップします。10階クリア時のみ、低確率(約10%)で「転生ピッグ」もドロップします。
- **転生ピッグ**: ランクアップ素材専用のモンスター。ガチャやステージには一切出現せず、装備ダンジョン10階だけでドロップします。常に星3・そのレベル上限(Lv30)で手に入りますが、ステータスは同じ星の他モンスターよりはるかに低く、戦力にはなりません。星3→4のランクアップに必要な素材(星3モンスター3体)として、育てた手持ちモンスターを犠牲にせずに済むための存在です。
- **召喚の書**: ガチャ「召喚」1回分のチケットです。石を消費せずに単発召喚を1回行えます。装備ダンジョンの全階層で低確率(約5%)にドロップし、召喚画面から消費して使います。

## ディレクトリ構成

```
src/
  core/
    element.ts        属性の相性・倍率計算
    stats.ts           ステータス型
    skill.ts            スキル型(ダメージ/回復/バフ/デバフ/スタン)
    monster.ts          モンスターテンプレート ⇔ 6属性色違いバリエーション生成
    rarity.ts            星ランク・最大レベル・経験値カーブ・実効ステータス計算
    monsterInstance.ts   プレイヤー所持モンスター(星・レベル・経験値・装備)の型と操作
    equipment.ts         装備(ルーン)の型・生成ロジック・ステータス適用計算
  battle/
    unit.ts      戦闘中のユニット状態(HP・ATBゲージ・クールタイム・バフ)
    damage.ts    ダメージ計算(属性相性・防御力・クリティカル)
    ai.ts        スキル選択・対象選択の簡易AI
    engine.ts    4vs4バトルの本体(ATBループ・スキル実行・ログ生成・再生用TurnRecord・HP持ち越し対応)
  data/
    monsters.ts          サンプルモンスター(スライム/ウルフ/ゴーレム/フェアリー)×6属性 + 転生ピッグ
    stages.ts            ステージ1-1〜1-5・各3ウェーブの敵編成と報酬定義
    equipmentDungeon.ts  装備ダンジョン1〜10階の敵編成・ボーナスドロップ(召喚の書/転生ピッグ)定義
  game/
    gacha.ts         ガチャ(召喚)の抽選ロジック
    progression.ts   ランクアップ(進化)の判定・実行
    playerState.ts   所持モンスター/通貨/パーティ/ステージ進捗の永続状態(localStorage)
    stageRunner.ts   ステージのウェーブ戦闘セットアップ・HP持ち越し
    dungeonRunner.ts 装備ダンジョンの単発バトルセットアップ
  simulate.ts    CLIで4vs4のオートバトルを観戦できるシミュレーター
  web/           ブラウザ版UI(ホーム/召喚/モンスター/装備/パーティ/ステージ/バトル観戦・PWA登録)
tests/           vitest によるユニットテスト
public/icons/    PWA/ホーム画面アイコン
```

## 使い方

```bash
npm install

# ブラウザ版を開発モードで起動(スマホのホーム画面に追加できるPWA)
npm run dev
# ビルドしてプレビュー(本番相当のService Worker込みで確認)
npm run build && npm run preview

# 4vs4のオートバトルをコンソールで観戦する(CLI版)
npm run battle
# シード指定で再現可能なバトルにする
npx tsx src/simulate.ts --seed=42

# 型チェック
npm run typecheck

# テスト
npm test
```

## スマホのホーム画面に追加する(PWA)

`npm run build && npm run preview` (または実機からアクセス可能な形でホスティング)した上で、スマホのブラウザでURLを開きます。

- **iOS (Safari)**: 共有ボタン → 「ホーム画面に追加」
- **Android (Chrome)**: メニュー → 「アプリをインストール」/「ホーム画面に追加」(自動でインストールバナーが出ることもあります)

`vite-plugin-pwa` で `manifest.webmanifest` と Service Worker を自動生成しており、アイコン(`public/icons/`)・スタンドアロン表示・オフラインキャッシュに対応しています。PWAとして正しく認識させるには**HTTPS(またはlocalhost)での配信が必須**です。
