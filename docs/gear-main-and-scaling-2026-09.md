# 装備メインの見直しと、HP/DEF比例攻撃の上方修正

2026-09-14。新しい防御式(`1000 / (1000 + 1.2 × DEF)`)を入れた後の追加調整。
**測った値だけを書く。**途中で考えた案は混ぜない。

## 何を変えたか

| 対象 | 変更 |
|---|---|
| 装備メインの HP% | **×0.85**(生成・強化・既に持っている装備) |
| 装備メインの クリダメ% | **×1.35**(同上) |
| DEF比例の攻撃ダメージ | **×1.5** |
| HP比例の攻撃ダメージ | **×2**(フェニックス・ベヒモスは個別値) |

**サブOPは1つも触っていない。**モンスターの基礎値、タイプ転生、能力付与、
セット効果、バフの共通値も変えていない。回復・シールド・継続回復も変えていない。

## なぜメインだけか

メインは枠ごとに1つ選ぶもので、2・4・6枠の選択がそのままビルドの形になる。
サブは引いたものを使うしかない。**選べる側だけを動かせば、厳選のやり直しを
強いずに選択肢の重みを変えられる。**

`rollStatValue`(サブ用)と `rollMainStatValue`(メイン用)を分けてある。
`ratio === 1` かどうかで見分ける作りにすると、いつか誰かがサブを ratio 1 で
呼んだ日に静かに壊れる。

## B. 既に持っている装備の移行

`normalizeLoadedState`(`src/game/playerState.ts`)で、印が無い控えだけを一度だけ通す。

```
if (!state.equipmentMainHpCritRebalanced) {
  for (const equipment of state.equipment) {
    const main = equipment.mainStat;
    const tuning = mainStatTuning(main.type);   // HP% 0.85 / クリダメ 1.35 / 他は 1
    if (tuning !== 1) main.value = roundStatValue(main.type, main.value * tuning);
  }
  state.equipmentMainHpCritRebalanced = true;
}
```

**二重適用の防止は印そのもの。**装備の速度を半分にした時
(`equipmentSpeedRebalanced`)と同じ形にしてある。印を付け忘れると、
開くたびに 0.85 が重なって装備が痩せていく。

新しく始めた人の控えは最初から印が立っている(装備が新基準で生成されるため)。

触らないもの: サブOP、他のメイン(攻撃%・防御%・速度・クリ率・命中・抵抗)、
星・強化値・シリーズ・特殊効果・ロック・おまかせ対象外の印・装着先。

`tests/equipmentMainRebalance.test.ts` が8件で見張っている
(値域・サブに乗らないこと・二重適用しないこと・他項目が動かないこと・
序列が逆転しないこと・移行後と新規生成の値域が揃うこと)。

## D. 比例部分は各ヒットに乗る

`src/battle/damage.ts` の実装:

```
const perHitBase = calculateBaseDamage(atk, ..., dependentStat, coefficient) * (1 + finalBonus);
const hits = Math.max(1, Math.floor(effect.hits ?? 1));
const resolutionDefense = applyDefense(perHitBase * hits, atk, def, effect.ignoreDefense);
```

比例項は `perHitBase` に入り、それが `hits` 倍される。**スキル全体で1回ではない。**
そのため多段技は比例の総量が見た目の係数より大きい。

| スキル | 表記 | 実質の比例総量(旧 → 新) |
|---|---|---|
| たいあたりラッシュ | DEF×0.75 × 3回 | 1.50 → **2.25** |
| 血のいけにえ | DEF×0.75 × 2回 | 1.00 → **1.50** |

### 4番耐久% と 4番クリダメの関係

どの個体でも同じ形になった。

- **クリ火力** … 4番クリダメが **+35%前後**
- **非クリ** … 4番耐久%がわずかに上(HP/DEFが高いぶん比例項が大きい)
- **耐久** … HP型で −8%、DEF型で −17%

**耐久を1割前後捨てて、会心が出た時の火力を35%取る。**選択として成立している。

## F. HP特化 と DEF特化 の新しい耐久比(162個体)

`npx tsx tools/playerDefenseAudit.ts`。

| 指標 | 変更前 | 変更後 |
|---|---:|---:|
| DEF特化EHP / HP特化EHP(通常時) | 1.14 | **1.24** |
| 同(防御75%低下中) | 0.98 | **1.06** |
| 同(防御UP中) | 1.19 | **1.30** |

火ドラゴンの具体例:

| 型 | HP(旧→新) | EHP(旧→新) |
|---|---|---|
| ATK特化 | 26,055 → 26,254 | 78,356 → 77,675 |
| HP特化 | 98,730 → **90,505** | 343,896 → **312,899** |
| DEF特化 | 33,777 → 33,438 | 390,598 → 387,588 |

**「DEF特化=100 / HP特化≒85」という目標に対して、変更前は 87.7、変更後は 80.6。
目標をまたいで反対側へ移った。**

あわせて、**防御低下中にHP特化が上回る関係が消えた**(0.98 → 1.06)。

**依頼主の判断: この動きは良い傾向。据え置く。**
目標の85は「HP%が一択だった頃の目標」であって、そこへ戻す理由は無い、ということ。
**次にここを触る時、80.6 を 85 へ戻そうとしないこと。**
数字が目標から離れているのは、直し忘れではなく決めた結果。

## G. 個別調整候補(**数値は変えていない**)

**依頼主の判断: 3件とも据え置く。**「少し強いスキルがあってもいい」。
下の3つは**直すべき不具合ではなく、把握しておく偏り**として読むこと。
次に触る時、ここを見て「直し忘れだ」と思わないように。

### 1. ゴーレム「たいあたりラッシュ」(★3 S2 CT2 全体3回)

| | 敵DEF2500 クリ | DEF3000かつ防御75%低下 クリ |
|---|---:|---:|
| たいあたりラッシュ(CT2 S2) | **30,948** | **65,154** |
| オブシディアンクラッシュ(CT3 S3) | 20,109 | 42,334 |

**CT2のS2が、CT3のS3より1.5倍強い。**比例が各ヒットに乗るため
実質 DEF×2.25 になり、単発のS3(DEF×1.5)を上回る。しかも★3。

ただし**今回の変更で新しく生まれた歪みではない。**旧値でも
1.50 対 1.00 で同じ向きに偏っていた(1.5倍に拡大しただけ)。
直すなら「3回の技だけ係数を据え置く」か「1発の係数を 0.5 へ戻す」。

### 2. ネメシス「血のいけにえ」(★5 S2 CT2 単体2回)

実質 DEF×1.5。同じ個体のS3(ラストジャッジメント)がクリ28,334に対し
18,854 なので**S3を食ってはいない。**倍率(1.2×2 対 5.9)の差が効いている。
念のため一覧に残すが、いまのところ手を入れる理由は見つかっていない。

### 3. 防御低下と重なった時のDEF比例

DEF3000へ防御75%低下を入れると、ネメシスのラストジャッジメントが
クリ **59,650**。CT4の単体なので突出とまでは言えないが、
**防御低下は味方が入れるもの**なので、実戦では常に重なり得る。

### 危険判定に引っかからなかったもの

- 単体で10万超え … 敵DEF0(仮想の下限)でのみ発生。実戦の敵DEFは
  ダンジョン・塔とも1,000〜4,500で、そこでは3万に届かない
- 全体で8〜10万 … 同上
- 4番耐久%が4番クリダメをクリ火力で上回る … **どの個体でも起きていない**
- 純攻撃型を食う … 闇ドラゴンがクリ61,938で、比例型の最大(29,406)の2倍以上
