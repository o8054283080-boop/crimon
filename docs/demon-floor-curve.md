# 魔人ダンジョン 10F→11F→12F の曲線検証

11Fを中間層として成立させられるかを、確定候補のプレイヤー仕様を固定したまま測った。

**本番データは1つも変えていない。** 検証ツール上で一時適用しただけ。

## 判断軸は TYPICAL と MID

装備ダンジョンは周回コンテンツなので、**STRONG（完成育成）で100%なのは正常**です。
階段が見えるべきなのはその手前の装備段階なので、判断は TYPICAL / MID で行い、
STRONG は参考として併記しています。

## 測定条件

| 項目 | 値 |
|---|---|
| プレイヤー側 | 採用候補で固定（新防御式1.2・体力/防御タイプ・DEF AP+5・防御低下75%・防御UP30%） |
| 敵側の土台 | 確定倍率 HP×0.80 DEF×0.30 ATK×2.20（全階共通） |
| 変えたもの | **11FのHP/DEF/ATKだけ**（SPD・スキル・AI・ギミックは不変） |
| 戦数 | 各200戦・seed 20260913 |
| 編成 | 実戦通常 / 実戦毒 / 実戦耐久 / 共通高レア / 魔人攻略高レア(水フェニックス) / 防御無視 |

---

## 現行の敵ステータス（確定倍率を当てた後）

| 敵 | 10F HP/ATK/DEF/SPD | 11F | 12F |
|---|---|---|---|
| 古代の魔人 | 279,939 / 10,025 / 1,006 / 196 | 328,000 / 13,420 / 975 / 200 | 440,000 / 22,000 / 1,080 / 204 |
| 古代のクリスタル | 80,657 / 3,067 / 681 / 122 | 96,000 / 3,067 / 675 / 145 | **280,000** / 3,067 / 750 / **200** |
| 古代の呪晶 | 77,298 / 4,433 / 536 / 128 | 92,000 / 5,610 / 525 / 132 | 108,000 / 6,380 / 585 / 136 |

**クリスタルのATKは3階とも同じ**（3,067）です。11・12階とも10階の実効値で揃える設計なので、
階ごとの倍率をここへ掛けると11Fが12Fを追い越します。今回の候補では**クリスタルのATKは据え置き**にしました。

---

## 結論1: 11Fの倍率強化では、勝率の階段は作れません

TYPICAL / MID とも、**候補A〜Dのどれでも11Fは99〜100%のまま**でした。

| 候補 | TYPICAL 11F勝率（6編成） | MID 11F勝率 |
|---|---|---|
| 現行 | すべて100% | すべて100% |
| A ×1.10 | すべて100% | すべて100% |
| B ×1.15 | すべて100% | すべて100% |
| C ×1.20 | 99〜100% | すべて100% |
| D ×1.25 | 99〜100% | すべて100% |

HP・DEF・ATKを1.25倍にしても勝率が動きません。

## 結論2: 12Fが壁なのは「編成が刺さるかどうか」で、階の強さではありません

TYPICAL の12F勝率を編成別に見ると、はっきり割れます。

| 編成 | 12F 勝率（TYPICAL） |
|---|---|
| 実戦通常 | **12%** |
| 共通高レア | **9%** |
| 魔人攻略高レア(水フェニックス) | 90% |
| 実戦毒 | **100%** |
| 実戦耐久 | **100%** |
| 防御無視 | **100%** |

**毒・耐久・防御無視は12Fでも100%**です。12Fの壁は階の絶対的な強さではなく、
「その編成が12Fの仕掛け（クリスタルのゲージ供給）に対処できるか」で決まっています。

そのため11Fをどれだけ強くしても、この3編成にとっては10F・11F・12Fがすべて100%のまま
並ぶことになります。

## 結論3: 手数では差が作れます

手数の位置（10Fを0%、12Fを100%とした時の11Fの位置。目安は30〜70%）:

**TYPICAL**

| 編成 | 現行 | A ×1.10 | B ×1.15 | **C ×1.20** | D ×1.25 |
|---|---|---|---|---|---|
| 実戦通常 | 2% | 4% | 4% | 5% | 5% |
| 実戦耐久 | 逆転 | 100% | 81% | **52%** ← | 24% |
| 共通高レア | 10Fより短い | 10Fより短い | 10Fより短い | **0%** | 2% |
| 攻略高レア | 10Fより短い | 10Fより短い | 0% | 4% | 4% |
| 防御無視 | 0% | 13% | 22% | **35%** ← | 48% ← |
| **目安帯に入る数** | 0 | 0 | 0 | **2** | 1 |

**MID**

| 編成 | 現行 | A | B | **C** | D |
|---|---|---|---|---|---|
| 実戦耐久 | 逆転 | 100% | 77% | **31%** ← | 0% |
| 防御無視 | 8% | 16% | 28% | **36%** ← | 48% ← |
| 共通高レア | 10Fより短い | 10Fより短い | 10Fより短い | 2% | 4% |
| **目安帯に入る数** | 1 | 0 | 0 | **2** | 1 |

**現行では「11Fが10Fより短い」編成が3つ**あり、階段になっていません。
C（×1.20）で初めて解消し、目安帯に入る編成も最多になります。

## 参考: クリスタルを動かす案（E/F/G）も測りました

12Fのクリスタル（HP280,000 / SPD200）が生き残ってゲージを配ることが12Fの仕掛けなので、
11Fのクリスタルも部分的に動かす案を測りました。

| 候補 | 11Fクリスタル | TYPICAL 目安帯に入る数 |
|---|---|---|
| E | HP15万 / SPD165 | 1（防御無視39%） |
| F | HP20万 / SPD180 | 2（実戦耐久33%・防御無視48%） |
| G | HP20万 / SPD180・倍率×1.15 | 1（防御無視61%） |

Cと同等で、**Cを上回りませんでした**。加えてクリスタルのHP/SPDを動かすと
11Fの戦い方そのものが12F寄りになり、「11Fは11Fの戦い方」という差が薄れます。
今回は**ステータス倍率だけのC**を推します。

## 11F < 12F の上限チェック

候補Cの呪晶が12Fをわずかに超えます。

| 敵 | 11F（候補C） | 12F | 判定 |
|---|---|---|---|
| 古代の魔人 | 393,600 / 16,104 / 1,073 | 440,000 / 22,000 / 1,080 | ✓ |
| 古代のクリスタル | 115,200 / 3,067 / 743 | 280,000 / 3,067 / 750 | ✓（ATKは同値） |
| **古代の呪晶** | **110,400 / 6,732** / 578 | **108,000 / 6,380** / 585 | **✗ HP・ATKが超過** |

超過の理由は、**12Fの呪晶が11Fに対してほとんど伸びていない**ためです
（HP 1.17倍・ATK 1.14倍。同じ区間で魔人はHP 1.34倍・ATK 1.64倍）。
お供の伸びだけが鈍く、そこが11Fの上限を縛っています。

解き方は2つあります。

| 案 | 11F | 12F | 11F<12F |
|---|---|---|---|
| **案1: 12Fの呪晶だけ引き上げる** | ×1.20 のまま | 呪晶のみ HP・ATK ×1.15 | ✓ 保てる |
| 案2: 11Fを上限内に収める | HP×1.17 / DEF×1.10 / ATK×1.13 | 据え置き | ✓ 保てる |

**案1を推します。** 12Fの呪晶だけなら12F全体の難易度はほとんど変わらず
（12Fの主役は魔人とクリスタル）、11Fに余裕も生まれます。
なお12Fの魔人まで一緒に上げたC+案は、実戦通常が12%→2%、攻略高レアが90%→73%と
12Fが重くなりすぎたので採りません。

## 最終提案

### 候補C: 11F を HP×1.20 / DEF×1.10 / ATK×1.20、あわせて 12F の呪晶だけ HP・ATK ×1.15

| 判定基準 | 結果 |
|---|---|
| 1. 10Fより明確に強い | **手数では達成**（共通高レア 28→28手で10F並み、防御無視 30→38手）。勝率では変わらない |
| 2. 12Fより明確に弱い | ✓（12Fは実戦通常12% / 共通高レア9%） |
| 3. STRONGで周回可能 | ✓ 全編成100% |
| 4. TYPICALで少し苦戦 | **未達**。TYPICALでも99〜100% |
| 5. 毒・防御無視だけ極端に有利にならない | ✓ 11Fでは全編成が同じく100% |
| 6. 時間切れが大量発生しない | ✓ 11Fの時間切れは全候補で0% |
| 7. 10→11→12の手数が自然 | ✓ 目安帯に入る編成が最多（TYPICAL 2 / MID 2）、逆転も解消 |

### 正直な限界

**「TYPICALで少し苦戦する11F」は、ステータス倍率だけでは作れませんでした。**
12Fが壁として働いているのはクリスタルのゲージ供給という仕掛けであって、
HP・ATK・DEFの大きさではないためです。

倍率で作れるのは**手数の階段まで**です。勝率でも階段を作りたい場合は、
11Fにも何らかの仕掛け（クリスタルを部分的に動かす、など）が要りますが、
今回測ったE/F/G案はCを上回りませんでした。

# 追補: 12Fの仕掛けを弱めて11Fへ入れる案

「12Fと同じスキル・ギミックにして、それを少し弱める」案を試しました。

## 結果: **弱めた仕掛けは発動しません**

12Fのクリスタル（HP 280,000 / SPD 200）のS2「古代の加護」を、
ゲージ付与を35〜50%に弱めて11Fへ入れ、クリスタルのHP/SPDも上げて測りました
（共通高レア・TYPICAL・100戦）。

| 条件 | クリスタル生存率 | 加護の使用回数 | 魔人の行動回数 |
|---|---|---|---|
| 10F 現行 | 0% | 0.0回 | 2.6回 |
| 11F 現行 | 0% | 0.0回 | 1.8回 |
| 11F H: 晶15万 SPD170 ゲージ35% | **0%** | **0.0回** | 2.2回 |
| 11F I: 晶20万 SPD180 ゲージ45% | **0%** | **0.0回** | 2.8回 |
| 11F J: 晶20万 SPD185 ゲージ50% | **0%** | **0.0回** | 2.8回 |
| 12F 現行（ゲージ70%） | 5% | 0.7回 | **16.7回** |

**HP20万でもクリスタルは生存0%、加護は一度も撃たれません。**
12Fの280,000でようやく生存5%・加護0.7回です。
PR #334で12Fのクリスタルを350,000（確定倍率後280,000）にしたのは
まさにこの理由で、**それより下では巻き込みで即死して置物のまま**です。

## では12Fの壁は何か

12Fの魔人はATK 22,000、11Fは13,420で**1.64倍**あります。ここを振りました（TYPICAL・200戦）。

| 編成 | 11F現行 | ATK×1.3 | ATK×1.45 | ATK×1.6+HP×1.15 | 12F現行 |
|---|---|---|---|---|---|
| 実戦通常 | 100%/58 | 100%/60 | 100%/61 | 99%/62 | **12%/300** |
| 共通高レア | 100%/21 | 99%/23 | 97%/24 | **86%/26** | **9%/76** |
| 攻略高レア | 100%/21 | 100%/24 | 100%/24 | 100%/24 | 90%/77 |
| 実戦耐久 | 100%/66 | 100%/74 | 100%/82 | 100%/**150** | 100%/71 |
| 防御無視 | 100%/30 | 100%/34 | 100%/35 | 100%/37 | 100%/53 |

ATKを12F並み（×1.6 = 21,472）にしても、共通高レアは86%で12Fの9%には遠く届きません。
**12Fの壁はATKでもなく、クリスタルのHP 280,000 を削るのに76手かかること**でした。

## クリスタルHPを上げる案も不可

11Fのクリスタルを18万・22万にして測ったところ、**実戦耐久の手数が跳ねます**。

| 候補 | 実戦通常 | 共通高レア | 実戦耐久 | 防御無視 |
|---|---|---|---|---|
| 11F 現行 | 100%/58 | 100%/21 | 100%/**66** | 100%/30 |
| N: ATK×1.45 晶18万 | 98%/62 | 97%/29 | 99%/**133** | 100%/43 |
| O: ATK×1.45 晶22万 | 99%/60 | 98%/30 | 99%/**165** | 100%/45 |
| 12F 現行 | 12%/300 | 9%/76 | 100%/**71** | 100%/53 |

実戦耐久が **66手 → 165手** と2.5倍になり、**12Fの71手を大きく超えます**。
周回コンテンツとして長すぎるうえ、11Fが12Fより重くなるので採れません。

## 正直な限界（変わりません）

**「TYPICALで明確に苦戦する11F」は、敵ステータスでは作れませんでした。**

12Fが壁として働いているのは、**クリスタルのHP 280,000 を削る時間**という構造です。
それを11Fへ持ち込むと（クリスタルHPを上げると）、今度は耐久編成の手数が2.5倍になり
周回コンテンツとして壊れます。12Fの仕掛けを弱めて入れる案も、
**弱めるとクリスタルが生き残らず一度も発動しません**。

11Fで作れるのは手数の階段までです。それでも現行の
「11Fが10Fより短い」という逆転は解消できるので、この提案には意味があります。

# 最終決定: 候補Q

`tools/dungeonPressure.ts` の6編成を TYPICAL / MID で200戦ずつ測り、次の候補に決めた。

## 11F = 全体×1.10 ／ 魔人のATKのみ×1.45 ／ クリスタル HP160,000・SPD170

| 敵 | 11F（決定） | 12F | 11F<12F |
|---|---|---|---|
| 魔人 HP / ATK / DEF / SPD | 360,800 / 19,459 / 975 / 200 | 440,000 / 22,000 / 1,080 / 204 | ✓ |
| クリスタル HP / ATK / DEF / SPD | 160,000 / 3,067 / 743 / **170** | 280,000 / 3,067 / 750 / 200 | ✓（ATKは同値） |
| 呪晶 HP / ATK / DEF / SPD | 101,200 / 6,171 / 525 / 132 | 108,000 / 6,380 / 585 / 136 | ✓ |

**全ての敵・全ての能力で 11F < 12F を保つ。**呪晶も上限内に収まる。

## なぜQを選んだか

| 候補 | 10Fより短い編成 | 実戦耐久の手数 | 共通高レア |
|---|---|---|---|
| F（晶20万・ボスATK据置） | **2件** | 85手 | 100% / 31手 |
| F+（晶20万・ATK×1.45） | 0件 | 168手 | 96% / 32手 |
| **Q（晶16万・ATK×1.45）** | **0件** | **146手** | **98% / 30手** |
| O（晶22万・ATK×1.45） | 0件 | 168手 | 95% / 31手 |

**逆転（11Fが10Fより短い）を全部解消したうえで、実戦耐久の手数を最も抑えられる**のがQ。

なお「12F超」と判定された実戦毒は無視してよい。毒は 10F 21手 / 12F 23手 と
元から差が2手しかなく（12Fでも100%・23手）、11Fが25手になるだけで超過になる。
これは12Fが毒に対して弱いだけで、11Fの問題ではない。

## 残る難点: 実戦耐久の146手

これは**属性差によるもの**で、ステータスでは解消できない。

実戦耐久の削り役は火ドラゴン1体だけで、11F（電気）には等倍、12F（草）には有利（×1.5）。
**同じHPでも11Fは1.5倍の時間がかかる。**実効HPに直すと、
11Fのクリスタル160,000（×1.0）に対し 12Fの280,000は186,667相当（×1.5で割る）で、
数字ほどの差がない。

ただしこれは削り役が1体・その属性が11Fに刺さらない、という偏った編成で起きる話で、
実際に11F（電気）へ草編成を持っていけば起きない。他の5編成では逆転していないため、
**この1件より「11Fが10Fより短い」逆転の解消を優先した。**
