# 本番戦闘ダメージ仕様

## 1. 基礎ダメージ

ダメージ効果は途中計算を小数のまま保持する。通常ATK依存は `effectiveATK × A`、最大HP依存は `effectiveATK × A + maxHP × H`、DEF依存は `effectiveATK × A + effectiveDEF × D` である。`A` は `multiplier`、`H` は `hpCoefficient`、`D` は `defCoefficient` としてスキルごとに保持する。最大HPと実効DEFには、戦闘ユニット作成時の装備・能力ポイント・タイプ補正、および攻撃時点の対応バフ/デバフが反映される（HPは現在HPではない）。旧 `scaleBonus` は速度依存技の互換用途であり、移行済みHP/DEF技には併用しない。

## 2. 正式な防御方式E

攻撃時点の実効ATKを `ATK`、対象の実効DEFを `DEF`、基礎ダメージを `B` とする。

- 割合軽減率: `DEF × 1.5 / (DEF × 1.5 + ATK)`
- 割合軽減後: `R = B × ATK / (DEF × 1.5 + ATK)`
- 固定軽減: `F = min(DEF × 0.25, R × 0.25)`
- 防御後: `max(0, R - F)`

処理順は **基礎ダメージ → DEF割合軽減 → DEF固定軽減 → クリティカル → 属性 → 与ダメージ補正 → 被ダメージ補正 → 丸め → 通常最低1**。既存互換のため属性とクリティカルはともに防御後へ乗算し、与ダメージ、被ダメージの順も維持する。基礎ダメージ全体（HP/DEF独立項を含む）が防御・クリティカルの対象となる。

## 3. 多段・複数対象

`multiplier` は従来どおり1Hit当たりの倍率である。多段では、1対象への1つのDAMAGE効果について全Hit分の基礎ダメージから固定軽減を一度だけ算出し、Hit数で均等配賦する。割合軽減は線形なので総量は同じになる。各Hitは従来どおり個別にクリティカル抽選し、整数ダメージを表示して直ちにHP/シールドへ適用する。このHit単位丸めにより総量に最大でHit数の半分程度の丸め差があり得る。

全体・複数対象は戦闘エンジンが対象ごとに効果を解決するため、各対象自身のDEFで固定軽減を各1回計算する。敵全体で共有しない。ランダム対象についても、各対象への解決単位を同じ規則で扱う。

## 4. 防御無視・最低値・将来効果

`ignoreDefense` は割合軽減と固定軽減をともに0にする。クリティカル、属性、与ダメージ、被ダメージ等は通常どおりである。

`roundNormalDamage` が通常攻撃を `Math.round` で最終整数化し最低1にする。基礎・防御の途中では丸めない。一方、将来の無敵・完全無効は通常計算の後で1を0へ潰すのではなく、通常丸め関数を呼ばず0を返す独立段階として実装できる。基礎計算、防御計算、通常丸めは純粋関数に分離してあり、我慢・反射・被クリ補正等はそれらの間または後段に追加する。
