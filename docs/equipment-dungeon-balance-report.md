# 装備ダンジョン難易度・報酬バランス要約（⑥）

## 判定

現在の装備ダンジョン全体は、**数値上「簡単すぎる」とはいえません**。完成した★6編成なら1～6階は高速周回できますが、それは下位階層の想定対象を超えているためです。7階から急に難化し、8～10階はむしろ厳しい状態です。高育成・高レア5体・★6装備サブ4でも、完全オート50試行の勝率は7階100%、8階78%、9階48%、10階22%でした。

|1|★3Lv30+★1装備|3 適正|初心者導線として維持。未育成はほぼ勝てない|

最も簡単すぎる候補は**対象育成基準では5階**、適正は1～4階と6階、最も難しいのは10階です。最大原因は「全体が弱い」ことではなく、**6→7→8階の急な段差と、通常モンスター編成/高レア編成の格差**です。

## プレイヤーと敵の数値

代表戦力は A=★1～2未装備、B=★3Lv30+★1装備、C=★4～5+★3～4セット、D=★5～6+★5～6装備+能力点、E=★6Lv60+★6サブ4選別+能力点100の5体です。タイプ補正は現在すべて1.0、潜在能力候補は未登録なので、どちらも現状火力を増やしません。

高育成の比較用代表値では、ATK型の主力がボスHPを1階57.9%/6階16.5%/10階4.1%、HP型の`ATK×0.8+最大HP×0.04`が18.6%/4.6%/0.8%、DEF型主力が68.0%/17.4%/3.6%削ります。HP/DEF依存は正式な独立加算で成立していますが、高階ボスHPが大きいため過剰ではありません。完全防御無視は高DEF相手に相対的に強いものの、10階を一撃化しません。

逆方向では、ボス主力の非クリ/クリがATK型HPに対し6階3.1/5.5%、8階18.1/31.9%、9階24.4/42.9%、10階19.4/34.1%。DEF型ではそれぞれ1.0/1.8%、6.2/11.0%、8.5/15.0%、6.7/11.8%です。高耐久は単発をよく抑えますが、9～10階の全体攻撃、反撃、DEF低下、回復阻害を合わせると永久耐久できず、耐久編成勝率は9階2%、10階0%でした。

## SPD・AI・回復・シールド

ボスSPDは153～210、10階196。高育成プレイヤーは概ね120～200、速度選別で216前後なので、終盤ボスは先手争いが成立しています。お供SPDは82～133と遅めですが、9～10階は専用お供の耐久で行動機会を確保します。終盤の簡単さをSPD不足が作っているとは判定しません。

AIはCTが明けたS3→S2→S1の順で使用し、単体攻撃は有利属性・低HPを優先します。弱点は、満HPでも回復を撃つ、シールド残量を見ない、古代の結晶のATK buffが必ずしもボスへ向かないことです。回復は最大35%/CT5、シールドは最大HP15～20%/CT5程度で1～7階を安定化しますが、9～10階の剥がし・回復60%阻害により完封にはなりません。

新しい我慢・復活・無敵・反射・挑発・強化不可・スキル使用不可・被クリ率増減は本番モンスターに未割当で、現在は影響なしです。

装備は全7セット、全6slot、+15強化、主能力はslot別候補、副能力0～4。毎回1個確定です。★6率は7階5%、8階9%、9階15%、10階23%。全階スタミナ10なのでクリア単位では上層ほど良い一方、実測勝率を含む★6期待値/挑戦は高レア速度編成で9階7.2%に対して10階5.1%となり、**10階より9階を回る方が効率的**です。高階層に挑む意味は初回報酬と最高単発品質にはありますが、10階周回の意味は不足しています。
