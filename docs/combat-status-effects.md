# 戦闘状態効果 正式仕様

## 分類と共通規則

本番戦闘の状態効果は `STATUS_EFFECT_CATEGORY` により次のように分類する。

| BUFF | DEBUFF |
|---|---|
| 被クリ率ダウン、我慢、反射、復活、無敵 | 挑発、強化不可、スキル使用不可、被クリ率アップ |

全効果は `durationTurns` を持ち、対象自身の手番開始時に1減る。同名効果はスタックせず、成功した再付与で残りターンを上書きする。挑発は付与元も上書きする。分類は強化不可、STRIP/CLEANSE、および将来の `removeAllBuffs` / `removeAllDebuffs` の共通判定に用いる。

## 各効果

- **被クリ率ダウン (BUFF)**: 被攻撃時の最終クリティカル率から30 percentage pointsを引く。
- **被クリ率アップ (DEBUFF)**: 被攻撃時の最終クリティカル率へ50 pointsを足す。両方があれば `clamp(攻撃者実効クリ率 + 0.50 - 0.30, 0, 1)` とする。
- **我慢 (BUFF)**: HPへ通るダメージが致死ならHP1にする。発動しても消費せず、各Hitに適用する。
- **復活 (BUFF)**: 我慢がない致死時、`round(maxHp * 0.25)`（最低1）で即時復活し、自身を消費する。多段の残Hitは継続する。
- **無敵 (BUFF)**: 通常計算後の受けるダメージを0にする特殊経路。通常ダメージの最低1丸めを通さず、シールド、HP、我慢、復活を動かさない。付随するDEBUFFの命中・抵抗判定は妨げない。
- **反射 (BUFF)**: 1Hitごとの実HP損失の25%を `round` して攻撃者へ特殊ダメージとして返す。シールド吸収量は含めず、我慢なら実際に減ったHPだけを使う。DEF、固定軽減、クリティカル、属性を再適用しないが、反射先の無敵・我慢・復活は適用する。
- **挑発 (DEBUFF)**: `SINGLE_ENEMY` の選択を記録した付与元へ強制する。`ALL_ENEMIES` は変更しない。本システムにランダム対象型はなく、`SELF`、`SINGLE_ALLY`、`ALL_ALLIES` にも影響しない。付与元が死亡・不在なら即時除去する。
- **強化不可 (DEBUFF)**: 新しいBUFFと同名BUFFの更新を拒否する。既存BUFFは残り、既存BUFFの発動も妨げない。能力BUFFに加え、状態BUFF、シールド、免疫、継続回復も対象とする。
- **スキル使用不可 (DEBUFF)**: スキル1のみ使用可能。手動入力はロジックでも拒否してスキル1へフォールバックし、UIはスキル2/3をdisabledにする。AIもスキル1を直接選ぶ。CTはリセットせず通常どおり進行する。

## ダメージ、シールド、致死、多段

優先順は **通常ダメージ計算 → 無敵 → シールド → 実HP損失 → 我慢 → 復活 → 反射**。我慢が復活より優先する。復活後は生存状態へ戻るため同じDAMAGE効果の残Hitが続く。無敵でもDAMAGE以外のスキル効果解決は継続する。

反射イベントは `sourceType = reflect` として共通ダメージ適用へ渡す。反射由来イベントから新たな反射は生成しないため、両者が反射を持ってもループしない。反射で死亡した場合も共通致死処理により我慢・復活が働く。

## 解除との関係

既存STRIPはカテゴリBUFF（新5効果を含む）を除去し、既存CLEANSEはカテゴリDEBUFF（新4効果を含む）を除去する。専用解除スキル追加時にも同じカテゴリを参照し、効果名の個別列挙は行わない。
