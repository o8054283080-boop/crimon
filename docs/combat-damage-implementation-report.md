# 戦闘ダメージ方式E 本番実装レポート

## 概要

2026-08-27に、検証専用ではなく本番 `calcDamage` へ方式Eを導入した。変更前は `B=ATK×(A+scaleBonus)`、軽減率 `DEF/(DEF+ATK)`、固定軽減なしだった。変更後は独立HP/DEF項を含むBへ `DEF×1.5` の割合軽減と上限付き固定軽減を適用する。DEF能力ポイントは `1pt=+3` のまま変更していない。

## HP依存スキルの移行と採用係数

比較条件は ATK 2000、最大HP 30000（防御前、1Hit当たり）。比較値は `旧 = ATK×(A+旧bonus)`、候補は `ATK×A + HP×H`。

## 回帰値

純粋な方式E（非クリティカル）は ATK/DEF/倍率 = 1000/3000/3 → **409**、1000/4000/3 → **321**、1000/6500/3 → **209**、2000/4000/3 → **1125**、4000/6500/3 → **2618**。ATK 3000、DEF 6500、倍率2の完全防御無視は割合・固定軽減とも0で **6000**。

ATK 2000、DEF 4000、総倍率3の1/3/6Hitは理論防御値がすべて1125。本番はHit単位 `Math.round` のため **1125 / 1125 / 1128**（最大3の表示丸め差）で、固定軽減のHit回数分重複はない。432条件相当を包含する指定マトリクスでは方式Eによる1ダメージは0件だった。

## 既存機能と注意点

ウルフ「ふいうちの牙」は0.45倍×2Hit・単体・CT2、ドラゴン「破壊の流星」は2.0倍×1Hit・全体・CT5・完全防御無視のまま。倍率、Hit、CT、対象、能力ポイント、装備値、基礎能力、クリ倍率、防御係数1.5、固定係数.25、上限25%は追加調整していない。通常、単発、多段、全体、防御無視、クリティカル、属性、与/被ダメージ、シールド、回復、装備、能力ポイント、AI、ログ、表示は全テストで回帰確認する。

丸めは全補正後の各Hitで `Math.round` し最低1。多段の合計には小さな丸め差が残る。ランダム対象は現行エンジンの対象解決方式に従う。将来の完全無効0は通常最低1とは別段階で実装する必要がある。
