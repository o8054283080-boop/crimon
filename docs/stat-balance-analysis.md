# 初期レアリティ・タイプ・能力ポイント調査（2026-08-27）

## 結論

今回の計測では、初期★3/4/5の差に「星倍率」と「専用テンプレートの基礎値差」が重なっている。
★6 Lv60の平均では初期★5は初期★3に対して HP 1.16倍、ATK 2.29倍、DEF 1.27倍、SPD 1.24倍だった。
特にATKは大きい。ただし初期★3母集団は攻撃・回復・防御など8種、★4/5は各2種かつ攻撃寄りであり、
母集団の役割構成が一致しない。この集計だけから全高レアの基礎値を一律に下げると、防御・補助役まで誤って弱体化する。
そのため、今回は戦闘ダメージ式と本番ステータス値を変更せず、候補を再計算可能にして判断材料を固定した。
詳細な全数値は自動生成レポートを参照する。

## 現状と変更案と変更後

| 区分 | 内容 |
|---|---|
| 現状 | 星ごとの倍率は `1.4^(星-1)`、Lv最大でさらに2倍。SPDは星・Lvで成長しない。タイプ補正は全て1.0。能力ポイントはHP +20/pt、ATK +2/pt、DEF +3/pt、SPD +1/10pt。 |
| 変更案 | タイプは得意能力を概ね+7〜10%とし、ATK型にはHP/DEF -4%、HP型にはATK -4%、DEF型にはATK -5%・SPD -3%などのトレードオフを置く。Lv1補正とLv成長補正を分離する。初期レア差は、役割別ベンチマークを追加した後に★4/5テンプレート個別で縮小する。 |
| 変更後（今回） | ゲーム本番値は現状維持。比較候補を `TYPE_PROPOSAL`、装備条件を `EQUIPMENT_SCENARIOS` に集約し、コマンド一つでレポートを再生成可能にした。 |

## タイプ補正候補

攻撃型を単純な上位互換にしないため、全タイプに少なくとも一つ1.0未満の能力を設定した。
候補は「Lv1に掛かるbase」と「Lv1から最大Lvまでの増分に掛かるgrowth」を分離している。
速度は現行仕様上レベル成長しないのでbaseだけが有効となる。

- 攻撃: ATKの基礎+8%・成長+8%と引き換えに、HP/DEFの基礎-4%・成長-2%。
- 体力: HPの基礎/成長+8%と引き換えに、ATK基礎-4%、SPD基礎-2%。
- 防御: DEFの基礎/成長+10%と引き換えに、ATK基礎-5%、SPD基礎-3%。
- 補助: HP/DEF/SPDを小幅に上げ、ATK基礎-4%。
- 妨害: SPD基礎+7%と引き換えに、HP/DEF/ATKを小幅に下げる。

これは**採用値ではない**。タイプと既存の`role`の対応、命中をタイプ能力に含めるか、タイプ転生コストが未確定のため、
本番の `MONSTER_TYPE_STAT_MULTIPLIERS` は中立値のままとした。

## 能力ポイント

候補値で100ptを極振りするとHP +2,000、ATK +200、DEF +300、SPD +10となる。
★6 Lv60の火スライムを基準にした増加率はHP約+12%、ATK約+15%、DEF約+31%、SPD+10%で、
DEFだけ相対効果が大きい。25/50/100ptの結果をレポートへ出すため、係数変更後にも直ちに比較できる。
現時点ではDEF依存ダメージ式を次タスクで扱う予定であり、DEF +3/ptの採否は保留する。

## 装備込み

「強装備」は★6+15相当の%主能力3枠、「理論装備」は通常は成立しない同能力6枠として上限圧力を見る。
%装備は能力ポイント加算後の値にも乗るため極振りを増幅するが、比較用の理論装備を含めても計算は有限で、
オーバーフローや負値は発生しない。一方で理論装備は基礎値の約5.79倍（セット補正込み）となるため、
本番バランスの根拠ではなく破綻検出用に限定する。セット固有の与ダメージ・被ダメージ・毎ターン回復は
「ステータス分布」と別軸であり、今回はダメージ式を変えない制約に従って評価対象外とした。

## 次に確定すべき値

1. 初期レアリティではなく「役割×属性」を揃えた比較基準。
2. ★4/5各テンプレートの個別目標（ATK差をスキル性能込みで何%残すか）。
3. タイプ補正を加算・乗算のどちらで装備前に適用するか、および既存`role`との対応。
4. DEF依存攻撃導入後のDEF能力ポイント係数。
5. 強装備の正式なパーセンタイル。今回の強装備は固定シナリオであり、ドロップ分布の実測値ではない。
