# ダメージ・HP/DEF依存・防御方式分析

## 調査範囲と前提

2026-08-27の現行コード、`create-monsters-system-roadmap.md`、前回の
`stat-balance-analysis.md` / `stat-balance-report.md` と再計算ツールを照合した。
数値表と全スキル監査結果は `damage-balance-report.md` に保存した。本稿の候補値は
**提案であり本番仕様ではない**。戦闘コード、スキルデータ、能力ポイント値は変更していない。

## 現行方式の問題点

現行防御式 `DEF/(DEF+ATK)` はATKとDEFが同値なら50%軽減となり育成段階を跨ぎやすい一方、
攻撃側ATKが分母に入るため、高ATKは基礎火力と防御貫通力を同時に得る。逆にATKが低い
HP/DEF型は同じスキル倍率でも強く軽減される。現行HP/DEF依存は独立加算ではなく
`ATK × (倍率 + 参照能力に応じた倍率)` なので、耐久能力を積んでもATKが低いと伸びない。

多段攻撃はhitごとに防御、属性、クリティカル、装備補正、丸め、最低1を適用する。
この構造へ固定軽減をそのまま追加すると、3hitは3回、6hitは6回差し引かれ、総倍率が同じ
単発より不当に弱くなる。完全防御無視は現状では割合軽減だけを無視するが、新方式で割合と
固定の双方を無視させると価値が大きく上がる。

## 候補の長所・短所

### A: 現行

- 長所: 単純、段階依存が小さい、既存バランスと完全互換。
- 短所: 高ATKが火力と貫通を兼ね、DEF型の高クリティカル対抗という特色が弱い。

### B: DEF×1.5割合

- 長所: 防御投資の効果が明確で、固定値による多段格差がない。
- 短所: 高ATK・高クリダメへの対抗は割合のままで、クリティカル自体を抑える特色は弱い。

### C: B + DEF×0.25固定（クリティカル前）

- 長所: 固定軽減もクリ倍率で拡大される計算順のため、高クリダメに最も強い。DEF型の役割が明瞭。
- 短所: 低倍率hitを最低1へ押し込みやすい。スキル単位に一度だけ引くにはエンジン改修が必要。

### D: B + DEF×0.25固定（クリティカル後）

- 長所: 非クリティカルではCと同等で、高クリティカルの爽快感をCより残す。
- 短所: クリ倍率が上がるほど固定軽減の相対効果が薄れ、今回の狙いにCほど合わない。

### E: 上限付き固定軽減（参考のみ）

`min(DEF×0.25, 割合軽減後ダメージ×0.25)` をクリティカル前に一度差し引く。
低倍率・低ATKを常時1へ落とす問題を緩和できる反面、式が複雑で、高DEFの特色も頭打ちになる。
比較候補に留め、本番採用しない。

## 極端なケース

- DEF=0では全方式が基礎ダメージを維持する。
- ATK=0付近では割合式の `max(1, ATK)` によりほぼ全軽減となり、最低1へ丸められる。
- 理論装備のHP 92,293でH=0.15は約13,844、DEF 6,531でD=3は約19,593をATK項へ追加し、
  高耐久とATK型以上の最大火力を両立し得る。破綻検出には有用だが調整基準にはしない。
- 完全防御無視3倍はATK 3,000ならDEFに関係なく9,000であり、高DEF側の通常被害との差が急拡大する。
- 最低1保証のため0以下、NaN、Infinityは公開シミュレーション関数で発生しない。

## タイプ、能力ポイント、レアリティの考察

前調査の代表値は攻撃型ATK 1,733（強6,057、理論10,034）、HP型HP 15,940
（強55,710、理論92,293）、DEF型DEF 1,128（強3,942、理論6,531）。
0/50/100ptはツール表で最終被ダメージまで比較した。DEF +2/+3/+4はいずれも防御を増すが、
方式Cでは固定軽減も同時に増えるため+4の限界効用が大きい。まず現行+3を維持し、新防御式を
決めた後で再評価するのが安全である。

初期★5対★3の★6 Lv60平均差（HP 1.16、ATK 2.29、DEF 1.27、SPD 1.24）は、各母集団の
役割構成が異なる。レアリティだけの効果と見なさず、スライム/ゴーレム/トレント等の役割別、
初期★3/4/5別の個体を装備なし・強装備・理論装備で併読する。理論装備は本番基準にしない。

## 推奨案（未確定）

次のユーザー確認用候補はC、固定軽減はスキル全体に一度、完全防御無視は両軽減を無視、とする。
HP依存はH=0.03〜0.05、DEF依存はD=0.5〜1.0を開始域としてスキルごとに設定する。
HP/DEF型の最大火力をATK型未満に保ち、CT・範囲・hit数・付随効果込みで個別調整する。

弱点は、低倍率多段の実装が複雑になること、防御無視が即死級になり得ること、固定軽減で
ダメージ表示が1に偏ること、装備やバフでクリダメに上限がないこと。採用前に実戦ターン数、
防御無視スキルの倍率/CT、最低ダメージ規則を追加検証する。
