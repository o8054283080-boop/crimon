## 結論

候補A/B/Cは、どれもそのままでは採用しない。

- 1〜30FはCでも全勝で、30Fも味方残HP99.4%。想定した「NORMAL100F付近の次の壁」にならない。
- 50FはCでも勝率95.0%、全滅0%、時間切れ5.0%。強敵というより、少し長くなっただけ。
- 70FはAの時点で中央値300手・時間切れ56.5%。HP/DEFと超再生が重なり、主に時間切れで難しくなる。
- 90Fは逆にAの時点で勝率0%、敵残HP63.2%。A→B→Cは難易度調整ではなく、全滅が早くなる比較になっている。
- 99FはA 84.5% / B 46.0% / C 10.5%と段階を読めるが、B/Cの負けは主に時間切れ。
- 100FはA/B/Cすべて0%。Aでも全滅98.0%、敵残HP60.4%なので、長期目標にはなるが現環境との距離は大きい。

## 階帯ごとの解釈

### 序盤（1〜20F）

A/B/Cの全候補が勝率100%、敵はほぼ行動できていない。Cでも20Fは中央値8手・味方残HP100%。「NORMAL100F制覇者なら比較的進める」は満たすが、A/B/Cの差は実質ない。序盤はCを使っても安全。

### 30F

A/B/Cはすべて100%で、Cでも中央値27手・味方残HP99.4%。指定倍率の範囲では壁にならない。NORMAL30Fのボス実数がHP42,724 / ATK3,307と、NORMAL100F（HP400,000 / ATK24,500）より大幅に低いため、単純な1.3〜1.5倍では届かない。

Dの30F端点（HP×5.00 / DEF×1.30 / ATK×14.00 / SPD×1.45）では勝率19.0%となり、NORMAL100Fの22.0%に近づいた。ただし時間切れ76.0%で、理想的な強敵というより削り切れない壁の比重が大きい。

### 50F

A/B/Cは100.0% / 99.5% / 95.0%。Cでも全滅0%、味方残HP94.0%で、「NORMAL100F制覇者でも明確に難しい」には不足する。Cの平均手数166.1はNORMALの72.4から大きく伸びるため、既に硬さだけは増えている。

Dの50F端点（HP×1.20 / DEF×1.00 / ATK×5.50 / SPD×1.23）は勝率12.5%まで下がるが、時間切れ82.0%・全滅5.5%。ここもステータス倍率だけで狙いを作ると、時間切れへ偏る。

### 70F

A 43.0% / B 17.5% / C 2.0%。ただし時間切れは56.5% / 79.0% / 96.0%で、HP・DEF強化と始祖ベヒモスの超再生が強く掛け合わさっている。A/B/Cの差の大半は「倒される」ではなく「300手で削り切れない」。

D（HP×1.45 / DEF×1.10 / ATK×2.20 / SPD×1.05）は勝率26.0%、全滅15.5%、時間切れ58.5%。A/B/Cよりは脅威と耐久の両方が出るが、なお時間切れ中心。

### 80F

A 88.5% / B 60.5% / C 33.0%。A/B/Cでは全滅が最大でも1.5%で、主に時間切れが増える。Dは勝率9.5%、全滅41.5%、時間切れ49.0%となり、敵の脅威は明確になる一方で急に重い。

### 90F

Aの時点で勝率0%、敵残HP63.2%。B/Cは96〜99%全滅し、敵残HP78.5〜84.2%。A/B/Cはすべて過剰で、特にB/Cは敵/味方行動比1.15〜1.23、敵連続行動p95=11〜12となり、SPD倍率と90F固有の狂化・戦鼓晶テンポが重なって敵に周回される。

D（HP×1.25 / DEF×1.05 / ATK×1.40 / SPD×1.03）は勝率10.0%、全滅24.5%、時間切れ65.5%、敵連続p95=7。A未満まで倍率を下げる必要がある。

### 99F

A 84.5% / B 46.0% / C 10.5%。段階差は読めるが、Cは時間切れ84.0%・味方残HP78.9%で、ほぼ「硬すぎて終わらない」。D（HP×2.10 / DEF×1.25 / ATK×3.50 / SPD×1.15）は14.0%で、全滅43.0%・時間切れ43.0%に分散し、Cより強敵らしい負け方になる。

### 100F

## SPD確認

- 1〜50FのA/B/Cは敵連続行動p95が最大2で、SPD倍率の問題は見られない。
- 70FはA/B/Cともp95=4。速度より超再生と耐久が支配的。
- 80FはA/B/Cでp95=6/6/7。
- 90FはA/B/Cでp95=11/11/12、敵/味方行動比0.92/1.15/1.23。ここは明確に敵側が周回しやすい。90FではAのSPD×1.08でも高すぎる。
- 99FはA/B/Cでp95=6/8/8。
- 100FはNORMALのp95=10に対してA/B/Cは9/8/7。HARD側が低いのは安全だからではなく、味方が早く全滅して長い連続行動列が記録されにくいため。

## 最終提案

最も自然な案は、A/B/Cのいずれかではなく候補D。ただし、**Dをそのまま本番採用しない**。

次の検証では、Dの端点を基準にしつつ、通常階と10階ごとのボス階を別カーブに分けて全100階を走査する。特に次を満たすまで本番HARD実装へ進めない。

1. 30F・50F・70F・90Fの時間切れ率を下げ、全滅と勝利へ振り分ける。
2. 29→30、39→40、49→50などのボス壁と、ボス直後の易化幅を確認する。
3. 90FのSPDはA未満（実測上はDの×1.03付近）を維持する。
4. 100FはAより少し弱いDでも勝率0%なので、B/Cへ上げない。

現時点で「本番へ入れる倍率を1つ選ぶ」なら結論は**見送り**。検証候補として1つ選ぶなら**D**。
