# モンスターの2D絵 — 発注仕様とプロンプト

モンスターの造形を3Dから2Dのデフォルメ絵へ移すための、**絵を描く側への注文書**。
コード側の受け皿がこの通りに読み込むので、**名前と規格は必ず守ること。**

絵そのものはこのリポジトリの中では作れない(手続き的な背景は焼けるが、
キャラクターの絵は生成できない)。**絵は外で作って、ここへ置く。**

---

## 1. どこへ、どんな名前で置くか

```
src/web/assets/monsters/<種族>-<属性>.png
```

- 種族: `slime` `wolf` `golem` `fairy` `imp` `wisp` `treant` `knight`
  `griffon` `dragon` `seraph` `nemesis` `ancient_demon`
  `ancient_crystal` `ancient_crystal_curse`
- 属性: `FIRE` `GRASS` `ELECTRIC` `WATER` `LIGHT` `DARK`

例: `slime-WATER.png` / `imp-DARK.png` / `golem-LIGHT.png`

15種 × 6属性 = 90枚。**置いた種族から順に2Dになり、置いていない種族は
3Dのまま動く。** 一斉に差し替える必要は無い。

### 差し替え用の追加ポーズ(任意)

```
src/web/assets/monsters/<種族>-<属性>-attack.png   攻撃の瞬間
src/web/assets/monsters/<種族>-<属性>-hit.png      のけぞる瞬間
src/web/assets/monsters/<種族>-<属性>-cast.png     サポート技の瞬間
```

**無くてよい。** 無い場合は基本の1枚を変形させて動かす(次節)。
あればその瞬間だけ差し替わり、より良くなる。

---

## 2. 動きについて — 「絵は1枚でも、4つのモーションは動く」

依頼主の要望は **待機・攻撃・被ダメージ・サポート技の4モーション**。
「動きがないと安っぽい」— そのとおりで、静止画を置くだけにはしない。

**基本の1枚だけでも、次のようにコードが動かす。**

| モーション | 何が起きるか |
| --- | --- |
| 待機 | 呼吸で縦に潰れて伸びる。上下にゆっくり漂う。体の上ほど遅れて撓む(ゼリーの追従)。足元の影も合わせて伸縮する |
| 攻撃 | 沈んで溜める → 前へ踏み込んで横に伸びる → 当たった瞬間に縦へ潰れる → 揺り戻しながら戻る |
| 被ダメージ | 後ろへ流されてのけぞる。白く光る。細かく震える。バネで戻るので「押された・こらえた」が出る |
| サポート技 | 少し浮き上がる。体が縦に伸びる。属性色の光が下から上へ抜ける |

だから **まずは基本の1枚を全種族ぶん**揃えるのが最優先。
追加ポーズはその後でよい。

**このため、基本の絵は「素立ち・力を抜いた待機の姿勢」で描くこと。**
攻撃の途中のような、強い動きの付いた姿勢にしない(変形させると破綻する)。

## 3. 規格(ここを外すとゲームに載らない)

1. **透過PNG。** 背景は完全な透明。白や市松模様を塗らない
2. **正方形。** 1024×1024 を目安(2048でもよい。縦横比が違うものは不可)
3. **右向きの斜め(3/4)。** 顔と体をやや右へ向ける。
   ゲームは味方を右向き、敵を**左右反転**して出す。
   **真正面・真横・左向きは不可**(反転したとき味方と敵が同じ絵になる)
4. **接地。** 立つものは**足裏を画像の下端から約8%上**に置く。
   浮くもの(妖精・ウィスプ・古代の魔人など)は体の下に空間を残す。

   ※ 大きさと位置が多少ずれていても、**コード側が透明部分を測って自動で揃える**
   (画像生成に画素単位の精度を求めるのは無理があるため)。
   ただし**端で切れているものは直せない**ので、8番の余白だけは必ず守ること
5. **影を描かない。** 地面の影はゲームが落とす
6. **エフェクトを描かない。** 炎・雷・光の粒・魔法陣・オーラはゲームが出す。
   属性は**体色と、ごく一部の意匠**だけで表す
7. **枠・台座・地面・文字・ロゴ・署名を描かない**
8. **四辺に5%以上の余白。** 角・翼・尾・武器を画像の端で切らない
9. **1体だけ。** お供・小物・背景物を足さない
10. **同じ種族の6属性は、シルエットを完全に同じに保つ。**
    変えるのは色と、ごく一部の意匠だけ。図鑑で6体を並べるので、
    形が変わると別のモンスターに見える

## 4. 画風

いただいた見本(インプ・フェアリー・ゴーレム・ウルフ・スライム)が基準。

- **太い暗色の輪郭線。** 真っ黒ではなく、その体色を深く落とした色
- **セル塗り+柔らかいグラデーション。** 厚塗りの写実にしない
- **目は大きく、白いハイライトを入れる。** 目が命
- **頭身は低め(2〜3頭身)。** ゴーレムやドラゴンのような大型でも頭は大きめに
- **彩度は高め。** 暗い戦闘背景の上に置くので、沈む色にしない
- 「かわいい」と「強そう」の両立。**怖くしすぎない**

### 属性の色

| 属性 | 日本語 | 基準色 | 寄せ方 |
| --- | --- | --- | --- |
| `FIRE` | 火 | `#e74c3c` | 朱〜橙。明部に黄を差す |
| `GRASS` | 草 | `#2ecc71` | 若草〜深緑。明部に黄緑 |
| `ELECTRIC` | 電気 | `#f1c40f` | 山吹〜黄。暗部に紫を差すと締まる |
| `WATER` | 水 | `#3498db` | 空〜藍。明部に白青 |
| `LIGHT` | 光 | `#f5e6a8` | 生成り〜淡金。白飛びさせない |
| `DARK` | 闇 | `#6c3483` | 紫〜藍紫。暗部を潰しすぎない |

3Dで積み上げた「見分けどころ」をそのまま持ち込む。
**特に似た者どうしの描き分けは崩さないこと**(ネメシス/セラフ/古代の魔人、
古代のクリスタル/古代の呪晶)。

| 種族 | 名前 | 役割 | 造形の芯 |
| --- | --- | --- | --- |
| `slime` | スライム | アタッカー | 骨も四肢も無い一塊の粘体。床に置かれた雫型。**顔は体の表面に浮かぶ**。動きは関節ではなく体積の変形で出す |
| `wolf` | ウルフ | アタッカー | 細身の胴・首まわりの豊かな毛・立った耳・ふさふさの尾。**毛で「獣」を読ませる**。鱗を出さない |
| `golem` | ゴーレム | ディフェンダー | 積み上がった岩塊が歩いている比率。**首は無く、肩が極端に広く、腕は膝下まで**。胸に核 |
| `fairy` | フェアリー | ヒーラー | 小柄であること自体が特徴。**低い頭身・薄い翅で浮き・足は宙にぶら下がる**。杖ではなく小さな花の錫杖 |
| `imp` | インプ | デバッファー | 小悪魔。**角・蝙蝠の翼・矢じり形の尾**。いたずらっぽい笑み。手は鉤爪 |

```

・のけぞり: 後ろ(左)へ押され、目を閉じてこらえている瞬間
・サポート技: 少し浮き上がり、両手または体を上へ掲げた瞬間
接地の高さと画像内の大きさは、待機の絵と揃えてください。
```

## 7. 受け取ったあとの手順

### 生の絵を整えるのは道具の仕事

**描く側は「描くこと」だけでよい。** 大きさ・形式・余白・重さは道具が引き受ける。

```
art/monsters-raw/ へ <種族>-<属性>.png のまま置く
node tools/prepareSprites.mjs
    → src/web/assets/monsters/<種族>-<属性>.webp
```

道具がやること:
1. 透明部分を測って、絵の実体へぴったり切り抜く(余白のばらつきが消える)
2. 長辺を512pxへ縮める
3. WebPへ変換する

実測(最初に届いた5枚): **1枚1〜2MB → 43〜58KB。**
90枚でも約4.5MBに収まる。PNGのまま入れると150MB近くになり、配れない。

端で切れている絵は道具では直せないので、**「左の端で切れている」と警告を出す。**
出たら描き直す。

### 確かめ方

1. `node tools/harness.mjs` を起こし、戦闘画面で実際に見る
2. `HARNESS_PORT=<port> node tools/tour.mjs` を通す
3. **フレームレートを測る。** 2Dへ寄せる目的の半分は軽さなので、
   良くなっていることを数字で確かめる(3Dのままの実測は31.5fps)
4. `tools/blindCompare.mjs` で、直した本人以外の目に見た目を判定させる

## 8. 見本

`docs/art-reference/` に、依頼主から届いた5体を置いてある。
**画風はこれが基準。** (`prepareSprites.mjs` を通したあとの状態)

- `imp.webp` `fairy.webp` `golem.webp` `wolf.webp` `slime.webp`
- `battle-goal.jpg` — 戦闘画面の目標イメージ

この5体で直すべき点:

- **ゴーレムが真正面を向いている。** 右向きの斜めに描き直す
  (真正面だと、左右反転しても味方と敵が同じ絵になる)
- ウルフとゴーレムは**どの属性なのかが未確定**。決めてから置く
