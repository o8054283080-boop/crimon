# 潜在覚醒 全モンスター3候補・本番戦闘仕様（⑧-3）

## 実装境界

72体×3=216候補を宣言データ化し、覚醒オーブ1個での選択、個体保存、ロード、表示に加えて、**216件すべてを本番BattleEngineへ実装済み**とする。潜在は戦闘定義化時に安定ID索引から一度だけ解決し、skillSlot=0との一致でS1だけに適用する。覚醒オーブの入手・消費仕様は変更しない。再選択は現在どおり一度選ぶと不可。

候補データはid/name/description/category/effectType/value/chance/duration/target/status/resolutionを持つ。`SEPARATE`は既存S1効果と別判定、`ADD_TO_EXISTING`は既存発動率へ加算（上限100%）。全候補はskillSlot=0、CT0前提。

## 個別重点評価

- **闇ドラゴン**: 竜牙研磨（S1のみ+12%）、崩鱗（既存DEF低下+15pt）、竜鱗（自己7%盾）。S3防御無視や全体火力は強化しない。
- **光ドラゴン**: 同3候補。S2/S3の支援・制圧へ直接影響せず、万能化を防ぐ。
- **ネメシス**: 復讐の刃（+10%）、報いの刻印（強化不可20%・1T）、逆境反射（HP30%以下・戦闘中1回）。既存性能を踏まえ上限より抑えた。
- **低レア**: スライムの味方盾、ゴーレムのDEF係数/挑発、ウィスプの強化不可/自己回復など、単純火力以外に終盤の役割を付けた。

## タイプ・能力ポイントの危険な相乗

防御タイプ+ゴーレム/ナイトのDEF係数、体力タイプ+トレントのHP係数、妨害タイプ+インプのスキル不可/ウィスプ・ネメシスの強化不可、攻撃タイプ+ウルフ/グリフォンのクリ条件を重点監視する。100ptのDEF/HP極振りと依存係数は乗るが係数を8～12%に制限。SPD100ptと妨害タイプを重ねたCT0妨害は試行回数が増えるため、⑧-3ではターン当たり成功回数とPvP拘束率を検証する。単一ビルドが支配的なら確率または係数を下げ、タイプ/能力ポイントそのものは変更しない。
