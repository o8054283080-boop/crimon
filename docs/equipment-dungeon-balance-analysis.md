# 装備ダンジョン難易度・報酬バランス総合調査（⑥）

調査日: 2026-08-27 / 基準: commit `5f5cd4e`（作業開始時 HEAD）

## 0. 結論と調査方法

**現状を一律に「簡単すぎる」とは判定しない。** 1～6階は完成済み★6編成には当然簡単だが、入口～中盤用として機能する。7階は完成編成への関門、8～10階は急激に難化し、10階は高レア・★6装備サブ4の現実的な高育成編成でも実測勝率22%（速度選別）/18%（無選別）だった。むしろ主要課題は、(1) 6→7階の段差、(2) 8階で通常編成が急に0%になる型間格差、(3) 10階報酬の難度上昇に対する伸び不足、(4) UIの1階推奨説明と実測の不一致である。

調査には `rg` による全リポジトリ検索、`buildDungeonEnemyTeam`（本番の丸め・敵ATK係数込み）、`BattleEngine`、`calcDamage` と同じ `calculateBaseDamage` / `applyDefenseE`、既存の `tools/dungeonPressure.ts`、`tools/dungeonTurns.ts`、`damage:balance`、`defense:compare` を使用した。独自の旧式ダメージ式は使用していない。単発ダメージ表は状態効果なし・等倍属性・非クリティカルを基準とし、クリティカルは実効クリダメを乗算した。行動数は厳密な「ラウンド」ではなく BattleEngine の1ユニット行動=1である。

ボスHPは各階でお供単体の約5～9倍、ATKは概ね2～3倍で「雑魚とほぼ同じ」ではない。9～10階は結晶の回復/積層buffと呪晶の全体DEF低下/回復阻害が危険で、10階はボス値を下げてもお供合計HP85,704により実測上最難関。ボスがHPだけの的という問題も、SPD×1.3、全体技、7hit反撃で緩和されている。

回復はフェアリー最大35%/CT5、セラフ等、体力4set毎手番5%が強い。シールドはウィスプ15%/CT5/3T、トレント20%/CT5/3T、ナイト12%/CT5/3T。1～7階の高耐久は敵DPSを上回りやすく安定するが非常に長い（7階224行動）。8階以降は反撃頻度、全体火力、9～10階の剥がし・回復阻害で完封されず、耐久実測が4%→2%→0%。したがって回復/シールドの永久化は最上層では問題ではない。

AIは「使用可能な番号最大スキル（S3→S2→S1）」を必ず選ぶ。CT開始時は強技を使い、全体技は全対象、単体回復/buffはHP割合最低の味方、単体攻撃は属性有利→低HPを狙う。強技を温存しない点は攻撃AIとして妥当。一方、満HPでも回復S3をS2より優先し、結晶のATK buffもHP最低者を選ぶため必ずしもボスを強化せず、シールド再使用の必要性も判定しない。**AI不足は中程度の問題**で、特に支援役の無駄撃ちが難度を下げる。

新9状態（我慢、復活、無敵、反射、挑発、強化不可、スキル使用不可、被クリ率増減）は本番モンスター定義に割り当てがなく、現状分析への影響はない。勝手な割当はしていない。既存の剥がし・回復阻害・反撃は別機構として現に使われる。

## 8. 5段階評価と原因分類

基準は「その階に初めて到達する想定育成」。完成Eから見た1～6階の簡単さを不具合とは扱わない。

|F|基準|難度|判定・主因|
|---:|---|---:|---|
|1|B|3 適正|A未育成はほぼ敗北、Bは高勝率。初心者導線を守る|
|2|B|3 適正|緩やかな次段階|
|3|B～C|3 適正|回復役が加わり編成意識が出る|
