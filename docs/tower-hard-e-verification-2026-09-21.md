# 試練の塔 HARD 候補D/E・全階走査検証（2026-09-21）

## 結論

- 候補Eは採用不可。1～49Fはほぼ無傷の全勝で、HARD開始地点として弱すぎる。
- 50F・70F・80F・90F・100Fはボス固有の完成ステータス／ギミックの影響が強く、帯域一律倍率では大きな崖が残る。
- 90FのE（SPD×1.03）は0勝、全滅74.5%。SPD×1.00でも0勝、全滅65.0%であり、主因は速度だけでなくHP×2.35・DEF×1.45・ATK×1.65の総量。
- 100FのD基準0%は「悪い0%」。平均本体残HP40.5%、20%以下到達4.0%、197/200戦で全滅しており、長期目標としても入口が狭すぎる。
- 倍率だけで序盤をNORMAL終盤攻略者向けにするには、NORMAL序盤の基礎値が低すぎる。追加探索Fで1～10FをHP×30・ATK×20まで上げても1Fは敵行動ゼロ、全勝だった。HPを盛るだけでは戦闘時間が延びる。
- 現時点の「倍率方式だけで選ぶ最も自然な案」は後述F。ただしFも51F・70F・71F等の崖を解消できず、**本番採用値ではなく次回検証の基準**とする。

## SPD検証

81～99FをEのままSPDだけ×1.03→×1.00にして全階200戦比較した。

- 81～89F、91～99Fの勝率改善は概ね0～5pt。行動比も小幅低下。
- 90Fは勝率0%のまま。全滅74.5%→65.0%、味方残HP17.5%→24.9%、敵残HP70.9%→68.1%。速度据え置きは有効だが、これだけでは解決しない。
- 90Fの敵/味方行動比は0.88→0.80、敵連続行動p95は11→11。NORMAL専用編成の速度・人数・行動構造が支配的。

結論として、81F以降はSPD×1.00を推奨。難度はHP/ATKとボス専用倍率で作る。

### F探索結果の重要点

- Fは49→50の勝率崖をほぼ解消したが、50→51は82.5%→100%、平均226.8→27.4手で大きく戻る。

## 最終判断（依頼事項への回答）

1. **1～50FはEで適切になったか:** いいえ。1～49Fは全勝、1～20Fは無傷・敵行動ゼロ。
2. **50Fまでに自然な壁ができたか:** いいえ。49→50で突然時間切れが増えるだけ。
3. **51～80Fとのつながり:** 不自然。50→51、69→70→71、79→80→81に大きな往復。
4. **90F SPD×1.03:** 不採用。×1.00が安全。ただしEの0%はSPDだけでは解消しない。
5. **100F D基準0%:** 強すぎる「悪い0%」。専用弱化1が妥当。
6. **全100階の崖:** 多数あり。主に完成済みNORMALボス値と通常階の差に一律倍率を重ねたことが原因。

Fを倍率方式での次回基準として提示するが、現時点で本番採用を推奨しない。自然なHARDを実現するには、少なくとも各10階帯の一律倍率ではなく、通常階とボス階を分離した倍率、または序盤の絶対ステータス下限を検証する必要がある。
