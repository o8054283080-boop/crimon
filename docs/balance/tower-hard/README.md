# 試練の塔 HARD 通常階バランス検証(ABSOLUTE_CURVE × STRONG / CONTROL / DOT_CONTROL)

- 対象: PR #431「検証: HARD通常階 実数カーブとDOT編成」(ブランチ `verify/tower-hard-absolute-dot-control`)
- **検証のみ。本番の `trialTowerHardMultipliers` もステータス案も変更していない。PRはマージしない**
- 実測: 9/19/29/39/49/59/69/79/89/99F × 3編成 × 各200戦 = **6,000戦(完走を確認)**
- seed 20260926 / maxTurns 300 / 本番 BattleEngine(Battle Lab `runMany`)/ 装備 STRONG
- 基準: 最新main(f00874e。#430 の終末胞子Lv5修正・火傷の式・ふいうちの牙などを含む)を取り込んで測った
- 生データ: `tower-hard-absolute-dot-control.json` / `.csv`(このフォルダ)。
  再現: `npx tsx tools/towerHardScan.ts --floors 9,19,29,39,49,59,69,79,89,99 --candidates ABSOLUTE_CURVE --profiles STRONG,CONTROL,DOT_CONTROL --runs 200 --seed 20260926 --max-turns 300 --out tower-hard-absolute-dot-control`

## 確かめたこと(前提)

- **ABSOLUTE_CURVE は正しく掛かっている。**各階の敵の平均は目標値と一致し、戦闘の中の最大HP(エンジンの最終スナップショット)とも一致した(下の表)。敵ごとの相対差は残したまま平均だけを合わせている
- **火マッシュルンは本編定義のまま。**S1 胞子弾 / S2 毒胞子の雨 / S3 毒床(Lv5: 毒1〜2スタック、1スタックにつき最大HPの6〜7%、最大5スタック)
- 毒・気絶・ゲージ減少は、**本編が出したログの行を検証ツール側で数えただけ**(BattleEngine は無変更)
- 同じ条件で3回流し、3回とも同じ戦闘が再現された

## 検証ツール側の修正(`tools/towerHardScan.ts` のみ)

- 追加した計測: 毒(総ダメージ・付与回数・スタック・敵最大HP比・被ダメに占める割合)、敵の気絶回数、敵のゲージ減少回数、敵最大連続行動の最大値、直接攻撃ダメージの敵最大HP比、敵の回復量、味方が受けた火傷
- ABSOLUTE_CURVE の**実際の敵ステータス**(目標と実測)を JSON/CSV に出す(CSVの倍率欄は常に1で、何を測ったかが残らなかった)
- 200戦走っていなければ止める検査
- 試算用の `--anchor-override`(既定では何もしない)
- Battle Lab の被ダメ(`damageTaken`)は直接攻撃の行だけで毒を含まないため、割合は「毒 ÷(直接+毒)」にした

## 読み取り

### STRONG と CONTROL の差
- 9〜49F: 両方100%。CONTROLはターン数が6〜7割で速い
- **59〜79F: CONTROLが明確に上**(59F 96.5→100、69F 76.5→93.0、79F 86.0→99.5)
- **89〜99F: 両方ほぼ勝てない**(89F 3.5 / 4.0、99F 0.5 / 7.0)。差が消える

### CONTROL と DOT_CONTROL の差
- 9〜79F: 勝率は同じ(100% 前後)。DOT_CONTROLは闇ドラゴンが抜けるぶん遅い(9Fで中央値 11→51ターン)
- **89〜99F で初めて差が出る**(89F 4.0→36.5、99F 7.0→27.5)

### 毒がいつから効くか
- 与えたダメージに占める毒の割合: 9F 27% → 49F 73% → **59F 79% → 69〜99F 85〜89%**
- 59〜79Fでは毒だけで敵の最大HP合計の101〜121%を削っている。ただしCONTROLも同じ勝率なので、勝敗を分けてはいない
- **毒が勝敗を分けるのは89F以降だけ**

### 狙い(後半は行動阻害+毒で攻略)になっているか
**半分だけです。**
- 59〜79Fは「STRONGより行動阻害が強い」はできているが、CONTROL・DOT_CONTROLとも93〜100%で、ほぼ確実に勝てる。全滅0%・味方残HP96〜98%で、敵が脅威になっていない
- 89〜99Fは急に崖になる。STRONG・CONTROLはタイムアウトが7〜9割で、敵をほとんど倒せない(撃破率4〜9%)。「毒がないと実質攻略不能」に近い
- 89〜99Fは、DOT_CONTROLでもタイムアウトが38% / 20.5%残る
- **敵の速度が味方を追い越す。**敵の平均速度は79F 230 → 89F 245 → 99F 260。味方はクロノス(330〜344)以外が235〜295なので、89Fから先手を取れず、CONTROLの敵/味方行動比が0.23 → 0.80 に跳ねる
- **89F・99Fの顔ぶれにも理由がある。**電気クロノスのS2「時の逆流」(自己回復30%+解除)、S3「終焉時計」(CT延長+ゲージ-50%+ゲージ20%以下なら確定スタン)と、電気アビスリーパーが共通して入っている。79Fは水クロノス・火アビスリーパーで、性格が違う
- 通常攻撃: 89/99FのSTRONGは、300ターン戦っても敵最大HP合計の22〜23%しか削れない

### 強すぎる/弱すぎる階
- **易しすぎる: 9〜49F**。全編成100%で、敵の行動は1戦あたり0〜6回しかない(ほぼ何もさせずに終わる)
- 易しめ: 59F・79F(CONTROL系 99.5〜100%)。**79Fは69Fより易しい**(STRONG 86.0 対 76.5)。顔ぶれの差で、並びが逆転している
- **難しすぎる: 89F**(崖)と 99F

## 最小限の調整案(試算つき。どれも本番には入れていない)

### 案1: 89F・99Fの速度アンカーだけを抑える(推奨)
- 89F 245→238、99F 260→246(79F 230 から10階あたり+8)
- 試算(`whatif-W1.json`、各200戦):
  - 99F: STRONG 0.5→4.0% / CONTROL 7.0→23.5% / DOT_CONTROL 27.5→55.0%。DOT_CONTROLのタイムアウトは20.5→16.5%
  - 89F: 3.5→10.0 / 4.0→8.0 / 36.5→39.0%
- 99Fは「STRONG < CONTROL < DOT_CONTROL」の順がはっきり出て、DOT_CONTROLも100%にならない。狙いに一番近い
- さらに抑えた W2(89F 236・99F 242)は、99F で 6.0 / 32.5 / 62.5%

### 案2: 89Fは数値ではなく顔ぶれで見る
- 89Fは速度238にしたうえで、防御を79F並み(8,200)・HP 290,000まで下げても、DOT_CONTROL 42% / CONTROL 12.5% だった(`whatif-W5.json`)
- 防御だけ、HPだけを下げた案(W3・W4)でもほぼ動かない。**数値の曲線では89Fの崖は消えない**
- 原因は、電気クロノス+電気アビスリーパーの組み合わせが89Fから入ること
- 89Fを79Fと99Fの間に置きたいなら、89Fの電気クロノスを79Fと同じ水クロノスにするのが最小の手。**ただし未測定**で、NORMALの89Fも変わるので要相談

### 案3: 59〜79Fを締めるならHPではない
- 59/69/79FのHPを+10%にしても、勝率はほぼ動かず(69F STRONG 76.5→70.5%、他は±0〜3pt)、ターン数が伸びるだけ(`whatif-W7.json`)
- この帯は敵がほとんど行動できていない(敵/味方行動比0.1〜0.2)。締めるなら速度か攻撃だが、速度は89Fの崖と同じ境目(味方の235〜265)に近いので、**上げ幅は小さく、測ってから**
