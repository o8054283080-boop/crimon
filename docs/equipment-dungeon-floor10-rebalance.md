# 装備ダンジョン10階 本番再調整（⑥-2）

調整日: 2026-08-27。固定seed 62000以降、本番 `BattleEngine` で各候補100戦、最終値500戦を実施した。なお指定された⑥-1.5の2資料は作業開始時のリポジトリに存在しなかったため、依頼本文に列挙された実パーティ結果を入力事実として扱った。

## 変更前の問題と⑥-1.5結果

⑥の22%は実パーティではなく、実パーティ（闇ドラゴン★6、光ドラゴン★6、光ネメシス★6、水ウィスプ★5、草スライム★5）は10階適性が高かった。闇ドラゴンS3の全体・完全防御無視2.0倍と、約4万HPのお供を全体攻撃で自然に消せることにより、闇+光ドラゴンだけ高品質でも100%となった。さらにAIは呪晶→結晶→魔人を自然に選び、敵結晶は満HP回復やHP最低者へのATKバフで手番を浪費していた。

## 新勝利条件と集中攻撃

`victoryTarget` を敵定義の汎用フラグとして追加した。フラグがある戦闘は全対象死亡、ない通常戦闘は従来通り敵全滅で勝利する。10階だけ魔人を対象とし、護衛生存中でも魔人死亡直後に勝利する。

敵本体またはHUDをタップすると集中対象を指定し、再タップで解除、別敵で切替する。死亡時は自動解除される。プレイヤーオートの単体攻撃・単体デバフだけが対象を優先し、全体技、味方回復・バフ・解除には影響しない。挑発がある場合は挑発を優先する。HUDには小型照準と枠を表示し、pointerイベントと `touch-action: manipulation` により縦画面タッチに対応した。

## 耐久候補と最終採用

候補は結晶/呪晶HP約4万、8万、10万、12万、15万（個体HP倍率2/4/5/6/7相当）、魔人約18万、25万、30万、35万、40万（倍率5/7/8.5/10/11.2相当）を比較した。4万は全体技で消え、12～15万は安全ルートの時間費用が過大だった。魔人18～25万は速攻の短縮が大きく、35～40万は中程度育成を締めすぎた。最終的に魔人303,735、結晶87,512、呪晶83,897を採用した。ATK/DEF/SPDはワンパン化を避けるため据え置いた。

|敵|変更前 HP/ATK/DEF/SPD|変更後 HP/ATK/DEF/SPD|HP変更率|理由|
|---|---|---|---:|---|
|古代の魔人|178,668 / 4,186 / 2,673 / 196|303,735 / 4,186 / 2,673 / 196|+70.0%|即勝利速攻に十分な滞在時間|
|古代のクリスタル|43,756 / 1,281 / 1,824 / 122|87,512 / 1,281 / 1,824 / 122|+100.0%|処理可能だが手数を要する装置|
|古代の呪晶|41,948 / 1,851 / 1,442 / 128|83,897 / 1,851 / 1,442 / 128|+100.0%|同上（丸めで1差）|

7hit反撃は維持した。速攻時に魔人へhitが集中して既存より明確に発動し、5/6hit化は多段編成を過度に罰するため不採用とした。

## 敵AI改善

回復を含むスキルは全生存味方がHP80%以上なら選ばない。古代の結界を満HPで空撃ちせずS2へ移る。単体ATKバフは `primaryTarget`、なければ基礎ATK最大の味方を選び、10階では魔人を優先する。完全最適化ではなく明白な無駄だけを除いた。

## 闇ドラゴンS3

Lv1倍率を2.0から1.2へ変更した。全体、完全防御無視、Lv1吸収25%は維持した。既存共通成長式による倍率は Lv1 1.20 / Lv2 1.27 / Lv3 1.34 / Lv4 1.42 / Lv5 1.42（Lv5はCT短縮）で、専用成長式は設けていない。S1/S2や他モンスター、防御方式Eは変更していない。

## 安全ルート・速攻ルートと育成段階別勝率

500戦、勝率 / 勝利時平均行動数。安全は呪晶→結晶→魔人、速攻は開幕から魔人指定。

|段階|安全|速攻|
|---|---:|---:|
|A 全員未装備|0.0% / -|0.0% / -|
|B 2体のみ中程度|0.0% / -|0.0% / -|
|C 2体のみ高品質|24.2% / 51|36.0% / 53|
|D 全員中程度|10.4% / 65|16.4% / 65|
|E 全員中程度+能力点|23.2% / 65|30.2% / 64|
|F 全員中程度+スキル育成|97.8% / 49|99.2% / 46|
|G 全員高品質|99.8% / 45|100.0% / 44|
|H 完成育成|100.0% / 31|100.0% / 29|

ランダム装備によりCがDを上回る。実パーティのスキル完成効果が非常に大きく、依頼の50～80%目安を超えたが、共通スキル成長方式や指定外モンスターを歪めず、完成専用周回編成90～100%を優先した。速攻は完成時2～3行動短い。中育成では速攻の勝率が高く、想定した「安全側が高安定」には達しておらず今後の課題である。ただし左右を放置すると回復・積層ATKバフ・妨害が継続するため支援価値は明確になった。

## 変更前後比較・報酬

変更前の⑥-1.5では闇+光ドラゴン高品質のみでも100%。変更後の対応するCは安全24.2%、速攻36.0%となった。10階の難度と育成目標化に合わせ、★6率を23%から32%へ、★4/★5/★6を30/47/23から20/48/32へ変更した。初回200ダイヤは一度限りとして十分なため維持した。

## 今後の課題

安全ルートの安定優位、装備セットを選別した実セーブデータ、スキル育成の急峻さを継続観測する。7～9階、初回報酬、防御方式E、装備性能は変更していない。
