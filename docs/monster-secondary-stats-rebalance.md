# モンスター特殊ステータス最終平準化レポート（⑧-2）

## 正式範囲と方針

プレイヤー使用可能な12種族×6属性=72体を対象とし、素材・敵専用は除外した。装備・タイプなし、属性補正込みの正式範囲は**クリ率15～23% / クリダメ150～170%**。LIGHTはクリ率+3pt、DARKはクリダメ+5ptへ縮小した。accuracy/resistance、HP/ATK/DEF/SPD、装備、タイプ補正、能力ポイントは変更していない。レアリティではなくS1を含む役割を基準にした。
