# クリエイト育成システム（⑧-1.5）

## 能力ポイント

能力ポイントは★4で解放する。合計上限は★1～3が **0pt**、★4が **20pt**、★5が **50pt**、★6が **100pt**。換算値は HP 1pt=+20、ATK 1pt=+2、DEF 1pt=+3、SPD 10pt=+1（端数切り捨て）。★4→★5、★5→★6では配分を0へ戻し、★6だけ100,000 GOLDで任意リセットできる。

## 6タイプと正式補正

★6は何度でも転生でき、★6のまま **Lv1 / EXP0 / 能力ポイント0** になる。SPDのマイナス補正はどのタイプにも設けない。

| タイプ | プラス補正 | マイナス補正 |
|---|---|---|
| 攻撃 | ATK +20%、クリ率 +10pt | HP -15%、DEF -10%、抵抗 -10pt |
| 体力 | HP +20%、抵抗 +10pt | ATK -15%、クリ率 -5pt、クリダメ -10pt |
| 防御 | DEF +20%、抵抗 +10pt | ATK -10%、クリ率 -10pt、クリダメ -10pt |
| 補助 | SPD +10%、HP +10%、抵抗 +5pt | ATK -15%、クリダメ -15pt |
| 妨害 | SPD +8%、的中 +15pt | ATK -15%、クリダメ -15pt、抵抗 -5pt |
| バランス | なし | なし |

バランス型は「すべての能力補正なし。長所も短所もない標準型」である。`type=null` は未転生、`type=BALANCE` はバランス型へ転生済みであり、戦闘性能は同じでも保存上・育成状態上は区別する。既存の5タイプは保存値を維持する。

## 計算順と安全域

1. 基礎値へ星・レベル成長を適用する。
2. HP/ATK/DEF/SPDへタイプ倍率、クリ率・クリダメ・的中・抵抗へタイプ加算を適用する。
3. 能力ポイントを加える。
4. 装備の固定値・割合値・セット補正を適用する。
5. 戦闘中の既存バフ/デバフを適用する。

タイプ適用時にクリ率・的中・抵抗は0～100%へ clamp し、クリダメは最低100%を保証する。妨害の的中および各タイプの抵抗は `toBattleDefinition()` の戦闘定義へ入り、既存の命中/抵抗式へそのまま反映される。装備、能力ポイント、バフの仕様・係数は変更しない。

## 補正案の比較

弱案（主要倍率±10～15%、特殊値±5～10pt）、第一候補、強案（主要倍率±20～25%、特殊値±10～20pt）を代表的なATK/HP/DEF依存個体で比較した。弱案は従来同様に選択差が薄く、強案はSPD先行と依存火力の固定化が強いため、正式値は第一候補を採用した。補助+10%・妨害+8%は装備・能力ポイント・SPDバフと乗算されるものの、タイプ間のSPD低下を作らず、火力低下を明確な代償とする。
