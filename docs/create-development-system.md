# クリエイト育成システム（⑧-1）

## 能力ポイント

能力ポイントは★4で解放する。合計上限は★1～3が **0pt**、★4が **20pt**、★5が **50pt**、★6が **100pt**。換算値は従来通り HP 1pt=+20、ATK 1pt=+2、DEF 1pt=+3、SPD 10pt=+1（端数切り捨て）で、どの能力への配分も自由である。

★4→★5、★5→★6のランクアップ直後は全配分を0にし、新しい上限をゼロから振り直す。★6だけは確認後に100,000 GOLDを払い任意リセットできる。残高不足なら変更も課金も行わない。

## タイプ転生

★6だけが、何度でも「攻撃・体力・防御・補助・妨害」へ転生できる。追加費用はなく、転生後も★6のまま **Lv1 / EXP0 / 能力ポイント0** となる。

| タイプ | 正式補正 |
|---|---|
| 攻撃 | ATK +15%、クリ率 +5pt、HP -5% |
| 体力 | HP +15%、ATK -5% |
| 防御 | DEF +15%、SPD -5% |
| 補助 | SPD +8%、HP +5% |
| 妨害 | SPD +5%、的中 +10pt、ATK -5% |

`type=null` は全倍率1.0、クリ率・的中加算0であり、未転生個体の従来性能を維持する。妨害の的中は表示専用値ではなく、戦闘定義の `accuracy` に入り既存の命中/抵抗判定に使われる。

## 計算順と他システム

1. モンスター基礎値へ星・レベル成長を適用する。
2. 成長後の HP/ATK/DEF/SPD にタイプ倍率を掛け、クリ率・的中を加算する。
3. 能力ポイントの固定値を加える。
4. その結果へ装備の固定値・割合値・セット補正を適用する。
5. 戦闘中のバフ/デバフを既存バトル処理で適用する。

従ってタイプ、能力ポイント、装備は独立して選べる。HP依存スキルは体力タイプ、DEF依存スキルは防御タイプで威力と耐久が同時に伸び得るが、係数や防御方式Eは変更しない。攻撃タイプはATK依存には有利でもHP/DEF依存へ直接の攻撃補正を持たない。
