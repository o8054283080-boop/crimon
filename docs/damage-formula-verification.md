# 防御計算を入れ替えた場合の検証

新しい防御計算 `damageMultiplier = 1000 / (1000 + 1.2 * DEF)` を、
本編の `BattleEngine` にそのまま当てて各コンテンツを実測した記録。

**この検証で本番仕様は何も変わっていない。** 既定は現行の方式Eのままで、
`src/battle/balanceFlags.ts` のフラグが立っている時だけ式が切り替わる
（テスト2,221件が既定のまま通ることで確認済み）。

## 測り方

| | |
|---|---|
| 比べた条件 | 旧式（方式E）／ 新式（係数1.2）／ 新式＋防御低下50%・上昇30%へ統一 |
| 戦数 | 各条件200戦（DEF逆算は150戦、係数スキャンは120戦） |
| 乱数 | **3条件とも同じ seed 群**。装備の生成も seed から回るので、同じ装備の同じ編成が同じ敵に挑む |
| 使ったもの | `tools/battleLab`（塔）／ `tools/dungeonPressure.ts`（魔人・魔獣）／ 目覚の深域は `awakeningDepths.ts` と同じ3編成 |
| 拡張したもの | `dungeonPressure.ts` に魔獣と敵加工の口を追加／`towerFloors.ts` に70・80・90・100階を追加 |

勝率が0%や100%に張り付く帯があるので、敵残HP・味方残HP・手数・全滅率・時間切れ率を必ず併記した。

---

## 1. 新防御式による全体的な影響

**勝敗より先に、戦闘の長さが変わる。**

新式はあらゆるDEF帯で旧式より軽減が強い。基礎ダメージ10万に対して「通る割合」は次のとおり。

| DEF | 旧式（相手ATK 5,000 / 10,000 / 20,000） | 新式（相手ATKによらず一定） |
|---|---|---|
| 1,000 | 77% / 87% / 93% | **45%** |
| 2,000 | 62% / 76% / 86% | **29%** |
| 3,600 | 47% / 64% / 78% | **19%** |
| 6,000 | 34% / 51% / 67% | **12%** |

性質の違いが2つある。

1. **旧式は攻める側の攻撃力との比で決まる。**攻撃を積めば相手の防御を抜ける
2. **新式は攻撃力を見ない。**同じDEFなら誰が殴っても軽減率は同じ

CRIMONの終盤のDEFは3,000〜6,000ある。サマナーズウォーのDEF帯（数百〜1,000台）向けの係数1.2をそのまま当てると、DEF3,600で81%軽減になり、旧式（攻撃力1万に対し36%軽減）とは別物になる。

結果として**全コンテンツで手数が2〜3.5倍に伸びた。**

## 3. 難化しすぎたコンテンツ

**目覚の深域の分散型だけが、はっきり難化した。**

- 8階 72% → 36%（−36pt）
- 9階 59% → 21%（−38pt）
- 10階 34% → 2%（−32pt）

敗因はすべて時間切れで、全滅率は0%。**倒されて負けているのではなく、削り切れずに終わっている。**
分散型は才能適応（同じ相手から連続で受けるほど硬くなる）が乗り切らないよう攻撃役を分けた編成で、
1体あたりの火力が低い。新式の軽減が乗ると、その火力では敵のHPに届かなくなる。

塔90階も勝率は8%→4%とわずかだが、**時間切れが32%→93%**になり、負け方の質が変わった。

## 4. 易化しすぎたコンテンツ

**魔人10階が、勝率だけ見ると大きく易化した。**

- 通常バランス 25% → 74%（新式+統一で90%）
- 毒重ね 34% → 71%

ただしこれは「敵を倒しやすくなった」のではない。**味方が死ななくなった**結果で、
味方残HPが20.2% → 89.7%、全滅率が67% → 0%。手数は149 → 268手に伸びている。
つまり**長く粘れるようになったぶん勝ちを拾っている**だけで、
時間切れも8% → 27%に増えている。

## 5. 問題ないコンテンツ

勝率が±4pt以内で収まったもの。

- 試練の塔 70階・80階・100階、通常階（51/61/71/81/91/99）
- 目覚の深域の集中型・耐久型（すべて100%のまま）
- 魔人11・12階、魔獣10〜12階（0%のまま）

**ただし「問題ない」のは勝敗だけ。**この全てで手数が2〜3.5倍に伸びている。
周回コンテンツでは、これは難易度ではなく**周回時間そのもの**の悪化になる。

## 6. 各主要ボスの推奨DEF

係数1.2のまま旧式と同じ「通る割合」に戻すには、プレイヤーの実効攻撃力を10,000と置いた場合、
**全ボスで一律にDEFを現在の13%まで下げる**必要がある。

| 対象 | 現在のDEF | 旧式で通る割合 | 新式1.2のまま | 同等にするDEF |
|---|---|---|---|---|
| 魔人10階 | 3,352 | 66% | 20% | **435** |
| 魔人11階 | 3,250 | 66% | 20% | **421** |
| 魔人12階 | 3,600 | 64% | 19% | **468** |
| 魔獣10階 | 3,650 | 64% | 19% | **475** |
| 魔獣11階 | 4,050 | 61% | 17% | **528** |
| 魔獣12階 | 4,500 | 59% | 16% | **589** |
| 塔60階 | 3,800 | 63% | 18% | **495** |
| 塔70階 | 4,000 | 62% | 17% | **522** |
| 塔80階 | 3,800 | 63% | 18% | **495** |
| 塔90階 | 4,200 | 60% | 17% | **549** |
| 塔100階 | 4,600 | 58% | 15% | **603** |
| 目覚8階 | 3,400 | 65% | 20% | **441** |
| 目覚9階 | 3,700 | 63% | 18% | **481** |
| 目覚10階 | 4,000 | 62% | 17% | **522** |

**この案は勧めない。**理由は2つ。

第一に、実測でDEFを85%下げても手数が戻らなかった。魔人12階でDEF 3,600 → 540（15%）にしても
手数は73 → 81手で、旧式の16手には遠い。DEFをほぼ0（1）にして初めて、
魔人10階で269 → 149手と旧式の136手近くまで戻る。つまり**現実的な下げ幅では足りない。**

第二に、敵のDEFだけ1/8にすると、**DEFという数値の意味が敵と味方で食い違う。**
プレイヤーのDEF型は6,000前後を積むのに、終盤ボスが500では、
「防御を抜く」スキルや防御低下デバフが敵に対してほぼ無意味になる。

**DEFを下げるのではなく、係数を下げるべき**というのが実測からの結論（項目10）。

## 7. 防御低下50%・防御上昇30%の妥当性

**妥当。ただし効き方は小さい。**

現行はスキルごとに防御低下 0.25〜0.5、防御上昇 0.15〜0.8 とばらついている。
低下0.5・上昇0.3へ統一した影響は次のとおり。

| 対象 | 新式のみ | 新式+統一 |
|---|---|---|
| 魔人10階・通常バランス | 74% | 90%（+16pt） |
| 魔人11階・通常バランス | 7% | 13%（+6pt） |
| 目覚8階・分散型 | 36% | 66%（+30pt） |
| 目覚9階・分散型 | 21% | 42%（+21pt） |
| 塔60階 | 99% | 100% |
| 魔獣10〜12階 | 変化なし | 変化なし |

**プレイヤー側に有利に働く。**低下0.5への統一で、0.25しか下げられなかったスキルが
倍の効果を持つようになるため。新式で難化した目覚の深域・分散型が
36%→66%、21%→42%と戻っているのは、この統一が効いている。

つまり**新式を採るなら統一も一緒に入れたほうがよい。**
新式の難化を部分的に打ち消す方向に働く。
魔獣で変化がないのは、魔獣のお供が防御デバフを持たないため。

## 8. プレイヤー側 HP型・DEF型・ATK型への影響

ナイト（水）★6 Lv60・装備TYPICALで型だけ変えて測った。

### 実効HP（HP ÷ 1発あたりに通る割合。大きいほど長く立てる）

| 型 | HP | DEF | SPD | 相手ATK 5,000 旧/新 | 相手ATK 10,000 旧/新 | 相手ATK 20,000 旧/新 |
|---|---|---|---|---|---|---|
| ATK型 | 24,858 | 2,339 | 175 | 43k / 95k（2.21倍） | 34k / 95k（2.80倍） | 29k / 95k（3.22倍） |
| HP型 | 73,930 | 2,674 | 217 | 135k / 311k（2.31倍） | 105k / 311k（2.98倍） | 89k / 311k（3.48倍） |
| DEF型 | 38,992 | 6,068 | 117 | 115k / 323k（**2.81倍**） | 77k / 323k（**4.21倍**） | 58k / 323k（**5.57倍**） |
| 速度型 | 72,291 | 2,111 | 260 | 119k / 255k（2.14倍） | 96k / 255k（2.66倍） | 84k / 255k（3.03倍） |

**狙いどおり、DEF型がいちばん得をする。**そして**相手の攻撃力が高いほど有利が広がる**（2.81倍 → 5.57倍）。

旧式では相手ATK 10,000 に対して HP型105k > DEF型77k で**HP型が有利**だったが、
新式では HP型311k < DEF型323k と**DEF型が逆転する**。
「HPが強すぎる」という問題意識に対して、式としては正しく働く。

ただし旧式の列を縦に見ると、DEF型の実効HPは相手ATKが上がるにつれ 115k → 77k → 58k と半減する。
**旧式では、相手が強くなるほど防御が無意味になる。**これが現行でHP偏重が起きている原因。

### 実測（魔人12階の3体を相手に、1体だけで立たせて倒れるまでの手数・各100戦）

| 型 | 旧式 | 新式 | 伸び |
|---|---|---|---|
| ATK型 | 5.4手 | 12.7手 | 2.35倍 |
| HP型 | 20.5手 | 88.3手 | **4.32倍** |
| DEF型 | 12.6手 | 44.9手 | 3.57倍 |
| 速度型 | 18.0手 | 37.4手 | 2.08倍 |

**実効HPの計算とは順位が逆になる。**実測ではHP型がいちばん長く立っている。
理由は速度で、DEF型はSPD 117、HP型はSPD 217。実効HPは「1発あたり」の話で、
実際に何発受けるかは速度と行動順で決まる。**DEF型は硬いが、遅いぶん多く殴られる。**

DEF型を本当に選択肢にするには、式だけでなく**守護4セットの速度の付きにくさ**にも手を入れる必要がある。

## 9. 新防御式を採用する場合に必要な追加調整

1. **係数を1.2から下げる**（最重要。項目10）
2. **周回時間の再確認。**手数が2〜3.5倍になると、装備ダンジョンの周回が実時間で2〜3倍になる。
   `CLAUDE.md` の実測では装備ダンジョン5階でx8速度でも1戦37秒。3倍なら約110秒
3. **`maxTurns` 300 の見直し。**塔90階が時間切れ93%、魔人10階の耐久編成が100%、
   魔獣10階の耐久編成が79%。**上限に張り付くと勝敗が「削り切れたか」ではなく
   「300手に入ったか」で決まる**ため、難易度として読めなくなる
4. **目覚の深域・分散型の救済。**3階層すべてで30pt以上落ちる。防御低下50%統一で半分戻るが、
   8階66% / 9階42% / 10階11% とまだ旧式（72/59/34%）に届かない
5. **DEF型の速度。**項目8のとおり、式を変えただけではDEF型は選ばれない
6. **防御無視スキルの価値が跳ね上がる。**新式では軽減が一律に強いので、
   防御を無視する手段の相対価値が上がる。既存の `ignoreDefenseRatio` 持ちを洗い直す必要がある

## 10. 最終推奨案

### 係数を 1.2 → 0.25 前後にする

係数を振って現行（旧式）との近さを測った結果。

| 対象 | 旧式 | 係数1.2 | 係数0.6 | 係数0.3 | 係数0.2 |
|---|---|---|---|---|---|
| 魔人10階 勝率 | 21% | 72% | 80% | **23%** | 9% |
| 魔人10階 敵残 | 35.2% | 3.8% | 7.0% | **34.3%** | 43.7% |
| 魔人10階 手数 | 136 | 269 | 224 | **113** | 94 |
| 塔60階 手数 | 34 | 131 | 71 | 50 | **33** |
| 塔99階 手数 | 41 | 132 | 87 | 54 | **38** |
| 塔90階 勝率 | 8% | 6% | 3% | 8% | 9% |
| 魔獣10階 手数 | 77 | 189 | 88 | 60 | 53 |

**魔人10階は係数0.3で、勝率・敵残HP・手数の3つとも旧式にほぼ一致する**（23%/34.3%/113手 対 21%/35.2%/136手）。
塔は係数0.2で手数がほぼ一致する。対象によって最適点が 0.2〜0.3 に分かれるので、
**0.25を起点に各コンテンツで微調整する**のが現実的。

この案の利点は、**ボスのDEFも装備も1つも触らずに済む**こと。
変えるのは式の係数1つだけで、得られるものは新式の本来の狙い——

- 防御の価値が相手の攻撃力によらず一定になる
- DEF型の実効HPがHP型を上回る（項目8）
- 「攻撃を積めば防御は無意味」がなくなる

——がそのまま残る。

### 採用するなら、あわせて入れるもの

- **防御低下50%・上昇30%への統一**（項目7）。新式の難化を打ち消す方向に働き、
  目覚の深域・分散型の救済にもなる
- **目覚の深域・分散型の再確認**。係数0.25でも旧式に届かない可能性がある
- **周回時間の実測**。係数0.25なら手数はほぼ据え置きになるはずだが、実機で確かめること

### 勧めない案

- **係数1.2のまま採用する。**全コンテンツで手数が2〜3.5倍になり、
  周回時間が現実的でなくなる。勝敗はほとんど変わらないので、
  難易度を上げる効果もない（変わるのは戦闘の長さだけ）
- **係数1.2のままボスのDEFを下げる。**現在の13%まで下げる必要があり（項目6）、
  実測ではDEF 15%でも手数が戻らなかった。加えて敵と味方でDEFの桁が食い違う

## 再現方法

```
npx tsx tools/defenseFormulaVerify.ts --runs 200              # 全対象
npx tsx tools/defenseFormulaVerify.ts --only tower --runs 200 # 塔だけ
npx tsx tools/defenseFormulaVerify.ts --only none --def-scan  # DEFの逆算
npx tsx tools/defenseFormulaArchetype.ts --runs 200           # 型ごとの影響
```

環境変数でも切り替えられる（本番の既定は常に旧式）。

```
CRIMON_DEF_FORMULA=sw CRIMON_DEF_SW_RATIO=0.25 CRIMON_UNIFY_DEF=1 npx tsx tools/...
```

## 11. 係数1.2を固定し、PvE敵ステータスを作り直す検証

> **2026-09-13 再検証注記:** 初回測定では `towerFloors.ts` が `trialTowerFloor` を
> `BattleEngine` へ渡しておらず、塔の階固有ギミックが動いていなかった。以下の塔に関する
> 初回スキャン結果は候補探索の履歴として残すが、**難易度評価には使用しない。**
> 正しい本編ギミック込みの200戦結果は11.3の塔表と11.3.1を正とする。

### 11.4 戦術別の副作用

| 魔人10F・編成 | 旧式 勝/手 | 新式1.2 勝/手 | 再設計(.80/.30/2.20) 勝/手 | 読み取り |
|---|---:|---:|---:|---|
| 通常 | 25% / 149 | 74% / 268 | 31% / 129 | 目標内 |
| 毒重ね | **34% / 39** | 71% / 51 | **8% / 32** | 敵火力を戻すと毒役が先に落ちる |
| 耐久 | 0% / 300 | 0% / 300 | 0% / 300 | 時間切れ75%→90%、まだ安全すぎる |
| 防御無視 | 0% / 98 | 0% / 300 | 0% / 88 | 敵残HP76.9%→64.2%、全滅96%→96% |

- **攻撃特化の一撃**：DEF30%化で、係数1.2の通過率はたとえばDEF3,600→1,080なら
  18.8%→43.6%へ2.32倍になる。新式そのままより明確に通る。ただし旧式と同じ一撃値ではなく、
  敵HP80%化と合わせて総手数を戻している。
- **防御無視**：未調整の新式では「通常攻撃が通らず防御無視だけ通る」ため、魔人10Fで
  敵残HPが76.9%→40.5%まで動き、300手時間切れ99%になった。DEF30%化後は敵残64.2%、
  中央値88手となり旧式98手へ戻る。相対価値は高いが、この編成では壊れて勝てる状態にはならない。
- **毒・割合ダメージ**：毒は敵最大HP比例なので、HP倍率だけでは必要な毒ターン数はほぼ変わらない。
  問題はATK2.2倍で毒役が早く落ちる方で、魔人10Fは34%→8%。強すぎる副作用は無いが、弱化しすぎる。
- **回復・シールド**：塔と目覚めの耐久型は味方残HPと手数が旧式付近へ戻った。一方、魔人10F耐久は
  味方残HP62.2%→80.1%、時間切れ75%→90%。カテゴリ内でも編成によって必要火力が違い、3倍率だけでは揃わない。

### 11.5 防御低下50%・防御UP30%

DEF30%化した敵への防御低下50%は、例として元DEF3,600なら実効DEF1,080→540となり、
新式の通過率は43.6%→60.7%（ダメージ約1.39倍）。ボスに対して無意味ではなく、完全防御無視ほどでもない。

ただしC2の実測は多くの対象でプレイヤー有利へ寄った。魔人10F通常31%→38%、
目覚10F分散49%→61%、塔70F64%→72%、塔80F92%→96%、塔100F7%→8%。
塔90Fはどちらも勝率0%だが、敵残HP47.7%→45.6%、味方残HP7.4%→12.0%へ動いた。
とくに目覚めと塔70FはC1でも勝率が高めなので、**新式導入と同時の統一は勧めない。**
低下50%・上昇30%という値自体は成立し得るが、敵倍率を決めた後に別変更として再調整すべき。

### 11.6 結論

1. **共通倍率案は成立しなかった。** 指定の0.60/0.20/1.60は大幅易化し、125組の最良案も全カテゴリを満たさない。
2. **別調整が必要なのは全カテゴリ。** さらに塔は70Fを通常階・他のボス階から分ける必要がある。
3. 推奨HP倍率（次の検証起点）：塔は0.80を基準（70Fは再探索）、魔人0.80、魔獣0.60、目覚め0.80。
4. 推奨DEF倍率（次の検証起点）：塔は0.30を基準（70Fは再探索）、魔人0.30、魔獣0.20、目覚め0.30。
5. 推奨ATK倍率（次の検証起点）：塔は2.60を基準（70Fは再探索）、魔人2.20、魔獣1.60、目覚め2.20。
6. **SPD変更は現時点では不要。** ただし塔70FはHP/DEF/ATKを再探索してから再判定する。
7. 防御低下50%・防御UP30%は式との相性は悪くないが、同時導入すると勝率をさらに上げるため後回し。
8. **新式1.2は、PvE敵のHP/DEF/ATK調整だけではまだ本採用できない。** 塔70F、魔人の通常/毒編成、
   目覚めの勝率/中央値で最適点がずれる。塔100Fの旧式100%という根拠も訂正され、正しくは10%だった。

これは「係数1.2が絶対に不可能」という結論ではない。カテゴリ別倍率に加え、魔人の攻撃対象・攻撃の配分、
目覚めの300手上限付近の勝敗分布まで個別に再設計するなら採用余地はある。ただしそれは敵3ステータスの
機械倍率ではなく、コンテンツと戦術の再バランス作業になる。本番データへはまだ反映しない。

### 再現方法

```bash
# 指定の共通倍率（A/B/C1/C2、各200戦）
node --import tsx tools/defenseFormulaVerify.ts --runs 200

node --import tsx tools/defenseFormulaVerify.ts --only none --redesign-scan --scan-runs 40

# 絞った候補を同一seedで全対象へ再測定
node --import tsx tools/defenseFormulaVerify.ts --runs 200 \
  --candidates '0.8,0.3,2;0.8,0.25,2;0.7,0.3,2'

node --import tsx tools/defenseFormulaVerify.ts --only tower --runs 200 --gear STRONG \
  --enemy-hp 0.8 --enemy-def 0.3 --enemy-atk 2.6
node --import tsx tools/defenseFormulaVerify.ts --only tower --runs 200 --gear FINISHED \

node --import tsx tools/defenseFormulaVerify.ts --only demon --runs 200 \

```
