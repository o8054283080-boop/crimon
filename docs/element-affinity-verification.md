# 属性相性をサマナーズウォー準拠へ寄せる案の検証

現行は **有利×1.5 / 不利×0.5**。サマナーズウォーは不利側が「かすり」で実効0.7倍前後なので、
**現行のほうが不利のペナルティが重い**。そこを緩めた場合の影響を測った。

**本番データは1つも変えていない。** `balanceFlags.elementMultiplierOverride` に
載せて測り、既定は現行の 1.5 / 0.5 のまま（テスト2,221件が通過）。

## 測定条件

| 項目 | 値 |
|---|---|
| 有利倍率 | **×1.5 のまま据え置き** |
| 不利倍率 | 0.5（現行）/ 0.6 / 0.7 / 0.8 を比較 |
| プレイヤー側 | 採用候補で固定 |
| 敵側 | 確定倍率（魔人 .80/.30/2.20、魔獣 .80/.30/2.00、目覚 .80/.30/2.20、塔90F .70/.25/2.50、塔100F 1.00/.30/2.50） |
| 戦数 | 各200戦・装備TYPICAL・seed 20260913 |

## 結果: ほとんど変わらない

| 対象 | ×0.5（現行） | ×0.6 | ×0.7 | ×0.8 |
|---|---|---|---|---|
| 魔獣12F(光) 共通高レア | 1% / 72手 | 1% / 72 | 1% / 72 | 1% / 72 |
| 魔獣12F(光) 実戦通常 | 47% / 300 | 47% / 300 | 47% / 300 | 47% / 300 |
| 魔獣10F(闇) 共通高レア | 98% / 34 | 98% / 34 | 98% / 34 | 98% / 34 |
| **魔人12F(草) 共通高レア** | **9% / 76** | 2% / 70 | **0% / 65** | 1% / 61 |
| 魔人11F(電) 実戦耐久 | 100% / 66 | 100% / 65 | 100% / 65 | 100% / 64 |
| 魔人11F(電) 共通高レア | 100% / 21 | 100% / 21 | 100% / 21 | 100% / 21 |
| 目覚10F 共通高レア | 100% / 11 | 100% / 11 | 100% / 11 | 100% / 11 |
| 塔90F 基準編成 | 2% / 139 | 2% / 128 | 2% / 130 | 3% / 132 |
| 塔100F 基準編成 | 6% / 92 | 6% / 92 | 6% / 92 | 6% / 92 |

## なぜ変わらないのか

理由は3つある。

1. **光・闇は環の外**なので、そもそも不利が発生しない。
   魔獣は10F(闇)・12F(光)で、どちらも全く動かない
2. 不利属性の味方が**回復役・支援役**だと火力に関係しない。
   魔人11Fの水セラフ・水ウィスプなどがこれで、手数が1手動く程度
3. 今回測った編成は**どれも階の属性に合わせて組んである**ため、
   「不利属性で殴る」場面がほとんど無い

## 唯一動いた魔人12Fは、逆方向に動いた

共通高レアは火ドラゴン・火ヴァルキリアの2体が火。12Fの敵は草で、**草→火は不利**。
不利を緩めると、**敵の攻撃が火の味方へ1.4倍通る**ようになる。

| 不利倍率 | 魔人12F 共通高レア |
|---|---|
| ×0.5（現行） | **9%** |
| ×0.7 | **0%** |

つまり「プレイヤーが不利属性でも殴れる」恩恵より、
**「敵の不利属性攻撃も痛くなる」副作用のほうが強く出た。**
弱点属性を当てて挑んだ時ほど、返り討ちのダメージが増える。

## 判断材料

| | 現行 ×0.5 | SW準拠 ×0.7 |
|---|---|---|
| 不利属性編成でも挑める | ✗ 火力半減 | ○ 3割減で済む |
| 弱点を突いた時の安全性 | ○ | ✗ 被弾が1.4倍 |
| 環外（光・闇）コンテンツ | 変化なし | 変化なし |
| 魔人12F 共通高レア | 9% | **0%** |

**効果が出るのは「不利属性の攻撃役を入れた編成」だけ。**
今回測った編成はどれも属性を合わせてあるため、恩恵は表に出なかった。

恩恵を測るなら「わざと不利属性で挑む編成」を別に用意する必要がある。

## 再現方法

```
npx tsx tools/elementAffinityScan.ts --runs 200
npx tsx tools/elementAffinityScan.ts --runs 200 --gear STRONG
```
