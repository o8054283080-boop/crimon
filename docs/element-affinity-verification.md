# 属性相性をサマナーズウォー準拠へ寄せる案の検証

現行は **有利×1.5 / 不利×0.5**。サマナーズウォーは不利側が「かすり」で実効0.7倍前後なので、
**現行のほうが不利のペナルティが重い**。そこを緩めた場合の影響を測った。

**本番データは1つも変えていない。** `balanceFlags.elementMultiplierOverride` に
載せて測り、既定は現行の 1.5 / 0.5 のまま（テスト2,221件が通過）。

## 測定条件

| 項目 | 値 |
|---|---|
| 有利倍率 | **×1.5 のまま据え置き** |
| 不利倍率 | 0.5（現行）/ 0.6 / 0.7 / 0.8 を比較 |
| プレイヤー側 | 採用候補で固定 |
| 敵側 | 確定倍率（魔人 .80/.30/2.20、魔獣 .80/.30/2.00、目覚 .80/.30/2.20、塔90F .70/.25/2.50、塔100F 1.00/.30/2.50） |
| 戦数 | 各200戦・装備TYPICAL・seed 20260913 |

## 結果: ほとんど変わらない

| 対象 | ×0.5（現行） | ×0.6 | ×0.7 | ×0.8 |
|---|---|---|---|---|
| 魔獣12F(光) 共通高レア | 1% / 72手 | 1% / 72 | 1% / 72 | 1% / 72 |
| 魔獣12F(光) 実戦通常 | 47% / 300 | 47% / 300 | 47% / 300 | 47% / 300 |
| 魔獣10F(闇) 共通高レア | 98% / 34 | 98% / 34 | 98% / 34 | 98% / 34 |
| **魔人12F(草) 共通高レア** | **9% / 76** | 2% / 70 | **0% / 65** | 1% / 61 |
| 魔人11F(電) 実戦耐久 | 100% / 66 | 100% / 65 | 100% / 65 | 100% / 64 |
| 魔人11F(電) 共通高レア | 100% / 21 | 100% / 21 | 100% / 21 | 100% / 21 |
| 目覚10F 共通高レア | 100% / 11 | 100% / 11 | 100% / 11 | 100% / 11 |
| 塔90F 基準編成 | 2% / 139 | 2% / 128 | 2% / 130 | 3% / 132 |
| 塔100F 基準編成 | 6% / 92 | 6% / 92 | 6% / 92 | 6% / 92 |

## なぜ変わらないのか

理由は3つある。

1. **光・闇は環の外**なので、そもそも不利が発生しない。
   魔獣は10F(闇)・12F(光)で、どちらも全く動かない
2. 不利属性の味方が**回復役・支援役**だと火力に関係しない。
   魔人11Fの水セラフ・水ウィスプなどがこれで、手数が1手動く程度
3. 今回測った編成は**どれも階の属性に合わせて組んである**ため、
   「不利属性で殴る」場面がほとんど無い

## 唯一動いた魔人12Fは、逆方向に動いた

共通高レアは火ドラゴン・火ヴァルキリアの2体が火。12Fの敵は草で、**草→火は不利**。
不利を緩めると、**敵の攻撃が火の味方へ1.4倍通る**ようになる。

| 不利倍率 | 魔人12F 共通高レア |
|---|---|
| ×0.5（現行） | **9%** |
| ×0.7 | **0%** |

つまり「プレイヤーが不利属性でも殴れる」恩恵より、
**「敵の不利属性攻撃も痛くなる」副作用のほうが強く出た。**
弱点属性を当てて挑んだ時ほど、返り討ちのダメージが増える。

## 判断材料

| | 現行 ×0.5 | SW準拠 ×0.7 |
|---|---|---|
| 不利属性編成でも挑める | ✗ 火力半減 | ○ 3割減で済む |
| 弱点を突いた時の安全性 | ○ | ✗ 被弾が1.4倍 |
| 環外（光・闇）コンテンツ | 変化なし | 変化なし |
| 魔人12F 共通高レア | 9% | **0%** |

**効果が出るのは「不利属性の攻撃役を入れた編成」だけ。**
今回測った編成はどれも属性を合わせてあるため、恩恵は表に出なかった。

恩恵を測るなら「わざと不利属性で挑む編成」を別に用意する必要がある。

## 再現方法

```
npx tsx tools/elementAffinityScan.ts --runs 200
npx tsx tools/elementAffinityScan.ts --runs 200 --gear STRONG
```

# 追補: サマナーズウォーの本来の方式を実装して測る

倍率を緩めるのではなく、**本物の仕組み**を実装して測り直した。

| 相性 | 効果 |
|---|---|
| 有利 | クリ率 **+15pt** |
| 等倍 | 通常 |
| 不利 | クリ率 **−15pt**、さらに **50%でかすり** |
| かすり | ダメージ **−30%**、クリティカル不可、**弱体を入れられない** |
| 光→闇 / 闇→光 | 有利 |
| 光闇 → 火水風 | 等倍 |

実装は `balanceFlags.elementMode = "sw"` で切り替わる（既定は現行のまま、テスト2,221件通過）。
かすった相手の instanceId を `SkillResolution.glancedTargets` に記録し、
弱体付与の共通入口 `rollEffectSuccess` で止めている。

## 動作確認

魔人12F(草)へ**わざと不利属性（電気）の攻撃役**を入れた編成で挑んだ結果（TYPICAL・60戦）:

| 方式 | 勝率 | 手数 | 敵への命中 | かすり | 防御低下の成功 |
|---|---|---|---|---|---|
| 現行（不利×0.5） | 93% | 271 | 258.5回 | 0.0回 | 0.2回 |
| **sw方式** | **87%** | 276 | 256.8回 | **17.0回** | 0.2回 |

かすりが1戦17回発生しており、仕組みは動いています。

## 結果: 既存コンテンツはほぼ変わらない

| 対象（TYPICAL・200戦） | 現行（不利×0.5） | 倍率だけ0.7 | **sw方式** |
|---|---|---|---|
| 魔獣12F(光) 共通高レア | 1% / 72手 | 1% / 72 | 1% / 72 |
| 魔獣12F(光) 実戦通常 | 47% / 300 | 47% / 300 | 47% / 300 |
| 魔獣10F(闇) 共通高レア | 98% / 34 | 98% / 34 | 98% / 34 |
| **魔人12F(草) 共通高レア** | **9% / 76** | 0% / 65 | **0% / 67** |
| 魔人11F(電) 実戦耐久 | 100% / 66 | 100% / 65 | 100% / 64 |
| **魔人11F(電) 共通高レア** | 100% / **21** | 100% / 21 | 100% / **24** |
| 目覚10F 共通高レア | 100% / 11 | 100% / 11 | 100% / 11 |
| 塔90F 基準編成 | 2% / 139 | 2% / 130 | 1% / 140 |
| 塔100F 基準編成 | 6% / 92 | 6% / 92 | 6% / 92 |

動いたのは魔人12F（9%→0%）と魔人11Fの手数（21→24手）だけです。

## なぜ sw方式のほうが厳しくなるのか

期待ダメージだけを見ると **sw方式のほうが緩い**はずです。

| | 実効倍率 |
|---|---|
| 現行の不利 | **×0.50** |
| sw方式の不利 | かすり50%×0.7 ＋ 非かすり50%×0.87（クリ率−15ptぶん） = **約×0.79** |

それでも「わざと不利属性で挑む編成」が 93% → 87% と厳しくなったのは、
**かすると弱体が一切入らない**ためです。
測定に使った編成の主力は電気ネメシス（MAX_DEBUFFER）で、
火力より弱体で貢献する役でした。**属性不利がデバッファーの役割そのものを止めます。**

引用いただいた資料の「属性不利は火力だけでなくデバッファーにも効く」が、
そのまま実測に出た形です。

## 判断材料

| | 現行 | sw方式 |
|---|---|---|
| 不利での火力 | 半減（×0.5） | **約0.79倍（緩い）** |
| 不利でのデバフ | 入る | **50%で入らない** |
| 不利でのクリ | 通常 | −15pt |
| 有利 | ×1.5 | クリ率+15pt（実効 約1.37倍） |
| 光・闇コンテンツ | 影響なし | **影響なし** |
| 既存コンテンツの勝率 | – | **ほぼ変化なし** |

## 私の見立て

**導入しても既存コンテンツはほとんど動きません。**光・闇が環の外という構造は
サマナーズウォーと同じで、魔獣10F(闇)・12F(光)では属性相性が一切働かないためです。

変わるのは**戦術の質**です。

- 「不利属性でも火力は出せる」（0.5→0.79）
- しかし「**不利属性のデバッファーは仕事をしない**」（50%で弱体が入らない）

当初の狙い（不利属性の手持ちでも戦える）は、火力役には効きますが、
デバッファーには逆に厳しくなります。**役割によって向きが逆になる**変更です。

安全に入れられる（既存が壊れない）ことは確認できたので、
採否は「属性で役割を縛りたいか」という設計判断になります。

```
npx tsx tools/elementAffinityScan.ts --runs 200 --gear STRONG
```

# 追補2: 本番仕様のまま sw方式だけを入れると、魔人12階が壊れる

**訂正がある。**上の「既存コンテンツはほとんど変わらない」は、
**新防御式などの最終候補を当てた状態**での測定だった。
sw方式を単独で本番へ入れる場合は話が別で、測り直したところ大きく動いた。

敵の倍率は一切掛けず、**本番のデータそのまま**で測っている（200戦・seed 20260913）。

| 対象 | 装備 | 現行 | sw方式 | 差 |
|---|---|---|---|---|
| **魔人12F 共通高レア** | STRONG | **56% / 39手** | **3% / 58手** | **−53pt** |
| 魔人12F 実戦毒 | STRONG | 99% / 25手 | 88% / 27手 | −11pt |
| **魔人12F 共通高レア** | TYPICAL | 11% / 53手 | **0% / 48手** | −11pt |
| **魔人12F 実戦毒** | TYPICAL | **89% / 23手** | **59% / 42手** | **−30pt / 手数+83%** |
| **魔人12F 共通高レア** | MID | 12% / 53手 | **0% / 47手** | −12pt |
| **魔人12F 実戦毒** | MID | **92% / 26手** | **61% / 55手** | **−31pt / 手数+112%** |
| 塔80F | TYPICAL | 87% / 25手 | 79% / 27手 | −8pt |
| 塔80F | MID | 87% / 26手 | 77% / 28手 | −10pt |

魔獣・目覚・塔の大半（60/70/90/99/100F）は変化なし。

## 原因: デバッファーの属性が合わないと役割ごと消える

魔人12Fは**草属性**。編成に含まれる**電気のデバッファー**が電気→草で不利になる。

| 編成 | 不利になるデバッファー | 止まる仕事 |
|---|---|---|
| 共通高レア | 電気ネメシス（MAX_DEBUFFER） | 防御低下・弱体全般 |
| 実戦毒 | 電気フェンリル（MAX_DEBUFFER） | 毒・防御低下・回復阻害 |

かすると弱体が入らないので、**火力ではなく役割そのものが消える。**
実戦毒が MID で手数112%増（26→55手）なのは、毒が入らず削り切れなくなったため。

## 選択肢

| 案 | 内容 | 懸念 |
|---|---|---|
| **A** | **sw方式と新防御式をセットで入れる** | 新防御式下では魔人12Fが元々9%なので落差が小さい。ただし他の未確定項目も巻き込む |
| B | かすり率を50%→30%程度に下げる | サマナーズウォー準拠から離れる |
| C | かすり時も弱体は入るようにする | 「デバッファーにも効く」という肝が消える |
| D | 魔人12Fの属性を草以外へ | 11F(電気)→12F(草)の並びを変えることになる |
| **E** | **sw方式を入れたうえで魔人12Fの敵を調整** | 11F調整と同じ枠で吸収できる |

sw方式自体は設計として筋が通っており、問題は
**現行の魔人12Fがデバッファー前提のバランスになっている**こと。
階側で受け止める **A か E** が自然だと考える。

## 再現方法

```
npx tsx tools/elementSwOnLive.ts --runs 200
```
