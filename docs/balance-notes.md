# 戦闘バランスの決め方

数字を触る前に、ここを読むこと。**過去に何度も、序盤の数値だけを見て
「問題なし」と判断し、終盤で壊れていることに気付かなかった。**

## 基準ステータス

終盤に装備込みで到達する水準を、この1組に固定してある。

| | 値 |
|---|---|
| HP | 30000 |
| 攻撃 | 3500 |
| 防御 | 3500 |
| クリ率 | 60% |
| クリダメ | 150%(与ダメージ×1.5) |

星6・Lv60に星6装備を6箇所ぶん揃えると、おおむねこの辺りに来る
(ゴーレムでHP41101/攻3088/防3782、ドラゴンで攻7154)。
アタッカーは攻撃が、受け手はHPと防御が、この基準を超える。

道具はこの基準を内蔵している。

```
npx tsx tools/skillBalance.ts          # 全スキルが実際に何をするか
npx tsx tools/skillBalance.ts --detail # 補正の内訳も出す
npx tsx tools/lightDarkProbe.ts        # 光/闇が通常より強いかの実測
```

## 目安

`tools/skillBalance.ts` が使っている、**敵1体あたりに削るHPの割合**。

| クールタイム | 下限 | 上限(全体技) | 上限(単体技) |
|---|---|---|---|
| 0(通常攻撃) | 2% | 12% | 20% |
| 1〜3 | 5% | 28% | 48% |
| 4以上 | 8% | 34% | 58% |

読み違えやすいところ:

- **判定には「1体あたり」を使う。**「合計」は全体技で4体ぶんを足しただけなので、
  100%を超えても敵1体につき25%でしかない
- **単体技は全体技より高くて当たり前。**当たる相手が1体しかいないぶんを取り返す
- **デバフを積む技は火力が低くて当たり前。**インプのような妨害役を
  「火力不足」と呼ぶのは、役割ごと否定することになる。
  不利な効果1つにつき下限を20%緩めている
- **継続回復はその場の回復と足さない。**数ターンかけて戻る量なので、
  足すと1回の回復量を大きく見誤る

## 二度と踏まないための決め事

### 防御による軽減は攻撃力との比

```
軽減率 = 防御 ÷ (防御 + 攻撃)
```

以前は `防御 ÷ (防御 + 300)` という固定の定数だった。この300は序盤の防御力
(100〜200)に合わせた値で、**終盤の防御3500では92%を弾き、攻撃力1.0倍の技が
相手のHPを1%も削れなくなっていた。** 定数を終盤に合わせ直すと、
今度は序盤の防御力がほぼ無意味になる。

攻撃力との比なら段階に依存しない。攻防が釣り合っていれば常に50%軽減で、
序盤の防御役も終盤の防御役も同じ意味を持つ。

### ステータス補正は基準値に対する割合

```ts
scaleBonus: { stat: "hp", bonusAtReference: 0.8 }  // HP30000のとき+0.8倍
```

以前は「能力値1につき+○倍」だった。HPは3万、防御は3500、速度は110なので、
桁が30倍違う。同じ係数を書いてもHP補正は+72、速度補正は+0.4にしかならず、
**説明文に書いた倍率が意味を失っていた。**

実際に起きていたこと:

| スキル | 素の倍率 | 補正 | 実効倍率 |
|---|---|---|---|
| トレント「ソウルルート」 | 2.0倍 | +72.0 | 74倍 |
| ゴーレム「たいあたり」(CT0の通常攻撃) | 0.7倍 | +14.0 | 14.7倍 |
| ネメシス「ラストジャッジメント」(CT5の必殺技) | 4.2倍 | +10.5 | 14.7倍 |

通常攻撃と必殺技が同じダメージになっていた。

### 敵の強さは耐久と殺傷力を分けて触る

`powerScale` はHP・攻撃・防御に同じ倍率を掛ける。硬くしたいだけのつもりでも
殺傷力まで上がるので、事故死が増える。攻撃力だけを別に触れるよう
`ENEMY_ATK_SCALE`(`src/battle/enemyPower.ts`)を分けてある。

下げるのは「敵を弱くする」ことではなく、
**殴り合いの長さを保ったまま事故死だけを減らす**ことを意味する。

### 効果の向きは対象に従う

回復・シールド・バフは**スキルの対象**に向かう。敵を狙う技にそのまま置くと
**敵を回復する**(光スライムのセイントスラッシュが実際に敵を12%回復していた)。

向きを変えたいときは `applyTo` を指定する。

```ts
{ kind: "HEAL", healRate: 0.15, applyTo: "ALLIES" }   // 敵を殴りながら味方を癒す
{ kind: "BUFF", stat: "def", amount: 0.5, durationTurns: 3, applyTo: "SELF" }
```

`tests/skillDirection.test.ts` が全スキルを走査して食い違いを検出する。

## 光/闇のスキルを足すとき

- **役割を変えないこと。**同じ種族として育ててきた意味が消える。
  支援役の闇を火力一本にしたら、実測で30戦中29敗になった
  (`tools/lightDarkProbe.ts` の トレント の項)
- 強さは `npx tsx tools/lightDarkProbe.ts` で実測する。
  通常スキルの時点で押し込み具合が +0.65 を超えている種族は
  **伸びしろが残っていない**ので、差が出ないからと倍率を盛らないこと
