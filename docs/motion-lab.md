# CRIMON Motion Lab

ゲーム本体から独立した、透明PNG向けの無料・ローカルモーション生成画面です。`/motion-lab`、静的配信では `/?motion-lab` で開けます。

## 利用手順

1. 透明背景PNGを1枚選ぶ
2. モーション、キャラクタータイプ、フレーム数、FPS、出力サイズを選ぶ
3. 「無料でモーション生成」を押す
4. 再生プレビューとフレーム一覧を確認する
5. Sprite sheet PNGまたはPNG連番ZIPを書き出す

画像処理はブラウザ内で完結し、外部サービスへの送信、APIキー、アカウント、利用料は不要です。

## 設計

- `MotionGeneratorProvider` を生成実装の境界として維持し、主経路には `AutoRigMotionProvider` を使用
- `RigEstimator` 相当の `estimateRig` がアルファ境界、外接矩形、画素重心を解析
- シルエットを頭・胴・下半身・左右の突出部へ分割し、体型に応じて尻尾／浮遊部の制御領域を追加
- `resolvePose` がモーションの溜め・作用・復帰と、体型別の振幅、パーツ別の位相差を解決
- 各領域は独立したピボット、回転、拡縮、シアー（局所ワープ）、遅延追従を持つ。顔を含む頭部は変形量を抑える
- 生成結果のObject URLは再生成時と画面離脱時に破棄

対応モーションは待機、攻撃、回復、被弾、バフ、デバフ、防御、勝利、倒れる、スキル発動です。体型は slime、humanoid、quadruped、floating、heavy、dragon に対応します。

## 出力と制約

Sprite sheet PNGとPNG連番ZIPに対応します。Animated WebP/GIFは透過アニメーションの安定したブラウザ標準エンコーダーがないため準備中です。単一画像からの領域推定なので、隠れている関節の復元や、重なった手足の厳密な分離はできません。必要に応じて将来、制御点の手動微調整、輪郭の連結成分解析、三角メッシュの高密度化を追加できます。
