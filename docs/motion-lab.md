# CRIMON Motion Lab

ゲーム本体から独立した、透明PNG向けのAIモーション素材生成画面です。開発サーバーでは
`/motion-lab`、GitHub Pagesのような静的配信では `/?motion-lab` で開けます。

## 利用手順

1. 透明背景PNGを1枚選ぶ
2. モーション、キャラクタータイプ、フレーム数、FPS、出力サイズを選ぶ
3. OpenAI APIキーを入力する（ページを閉じるまでのメモリ内だけで扱い、保存しない）
4. 送信先とAPI利用料についての確認にチェックし、「AIでモーション生成」を押す
5. フレーム一覧と再生プレビューを確認する
6. Sprite sheet PNGまたはPNG連番ZIPを書き出す

ファイルはOpenAI Images Edit APIへ1フレームずつ送ります。APIキーも入力画像もCRIMONの
サーバーや保存領域へは格納しません。生成ボタンを押すまでは外部送信も行いません。

## 設計

- `MotionGenerationRequest` / `MotionGenerationResult` が入出力の境界
- `MotionGeneratorProvider` が生成実装の差し替え口
- `ExternalAIMotionProvider` が本命の外部AI接続
- モーション種別と体型から、デザイン維持・透過・同一カメラ・余計な物を出さない指示を合成
- 結果フレームはオブジェクトURLとして保持し、再生成時と画面離脱時に破棄

入力モデルが配列へ拡張でき、プロバイダー境界は1リクエスト単位なので、将来は属性違いの
複数画像を同じ設定でキュー処理し、成果物をまとめたZIPとして返せます。

## 現在の制約

- 各フレームを独立した画像編集リクエストで生成するため、動画専用モデルほどの時間的一貫性は保証されません。
- 36フレームなら36回のAPI呼び出しになり、時間と利用料がかかります。
- Animated WebPは、透過・複数フレームを安定して符号化するブラウザ標準APIがないため未実装です。画面上でも「準備中」と明記しています。
- API利用料が発生するため、自動テストではモック応答を使用します。実キーでの課金API実行は自動化していません。
