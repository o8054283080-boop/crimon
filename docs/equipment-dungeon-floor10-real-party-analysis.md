# 装備ダンジョン10階・実パーティ乖離原因調査（⑥-1.5）

調査日: 2026-08-27 / 基準: `b7dbdb0`（PR #90取り込み済み） / 固定seed: 15000～15099

## 0. 結論

⑥の「22%」は、ユーザーの5体を再現した値ではない。実際に測っていたのは `griffon_GRASS / dragon_FIRE / seraph_WATER / nemesis_ELECTRIC / griffon_WATER`、全員★6 Lv60、**スキルLv1、能力ポイント0、毎試行新規生成した★6・サブ4装備**であり、「高育成」「スキル育成」という文言と実装条件が一致していなかった。100試行で24%と再現した。

実パーティは闇ドラゴンの全体完全防御無視2.0倍、光ドラゴンの全体高倍率+暗闇+ATK低下、光ネメシスの単体5.0倍+DEF項+スタン+40%ゲージ吸収、水ウィスプの解除+全体15%シールド/全体20%回復+免疫、草スライムの最大HP割合毒を同時に持つ。これは⑥の代表編成と別物である。固定した高品質装備を闇・光ドラゴンの2体だけに付けるケースはスキルLv1・能力0でも100/100勝った。一方、育成途中を表す★5+9ランダム装備を2体だけでは0/100だった。したがってユーザーの「まとも」が本調査の中程度より強い、実スキルLv/能力点が高い、または残り3体にも「まともではないが有効な装備」がある可能性がある。セーブデータなしに実装不一致とは断定できない。

`tools/equipmentFloor10RealParty.ts` は本番 `setupDungeonBattle` → `toBattleDefinition` → `BattleEngine.run()` を直接呼ぶ。独自戦闘式はない。各比較は100戦、同じseed 15000～15099、最大300行動である。

## 4. 闇ドラゴンの防御無視

S3「破壊の流星」は `ignoreDefense: true` で方式Eの割合軽減と固定軽減を**両方スキップ**する。属性補正とクリティカルは防御計算後に通常どおり掛かる。10階は水、闇は等倍である。素ATK 2,474なら全3体へ非クリ4,948、クリ（200%）9,896。ボスHP178,668には非クリ37発/クリ19発、結晶HP43,756には9発/5発、呪晶HP41,948には9発/5発相当（S3だけを数えた理論値）。実戦では全体攻撃、毒、他2アタッカーが同時に削る。

方式Eに「DEF固定軽減だけ残す」という例外はない。`applyDefenseE(..., true)` は完全スキップする。多段でもなく1hitなので、ボス反撃カウンタも対象ごと1hitだけ進む。⑥資料の例示「0.45×2防御無視」はウルフS2の一般比較であり、⑥高レア編成にも実パーティにもそのウルフはいない。実闇竜は **2.0×1全体**で、倍率合計は例示0.9の2.22倍かつ3体同時、同一条件ではなかった。

## 5. 各個体の10階寄与

- **闇ドラゴン**: 敵DEFや結晶のDEFバフに左右されない全体削り、25%吸収、S2全体攻撃。最重要の面制圧。高品質装備2体ケース成立の主因。
- **光ドラゴン**: S3の素状態基礎値は `2474×2.6 + 15597×0.05 = 7,212`（防御前）。全体暗闇は攻撃を50%で75%減衰させ追加効果も止め、ATK低下も重なる。S2のSPD/クリダメは3アタッカーの手数とクリ火力を同時に上げる。防御無視はない。
- **光ネメシス**: ヒーラー/シールド役ではない。S3基礎値は `2689×5 + 1183 = 14,628`（防御前）で単体最大火力、スタンと40%ゲージ吸収で危険な対象を遅らせる。S2 DEF低下も後続の光竜/自身/スライムへ効く（闇竜S3には不要）。
- **水ウィスプ**: ★5でも回復/シールドが対象自身の最大HP割合なので基礎ATKの低さに依存しない。初手AIはS3回復+免疫を満HPで空撃ちする欠点があるが、次のS2解除+シールドとS1常時DEFバフがDEF低下・回復阻害へ対抗する。高品質2体ケースでは本人が落ちてもアタッカーが削り切る時間を作る。
- **草スライム**: 水10階に対し属性上は不利（0.5倍）だが、毒は敵最大HP5%なので通常ダメージの属性不利・DEFを迂回する。全体2hitは反撃カウントを進めるリスクもあり、安定の中心ではない。全中程度から外すと28%→13%だったため補助削りとして有効。

## 7. 近似装備

正確なセーブ装備はリポジトリに存在しない。装備データに「レアリティ」はなく、星、強化Lv、サブ数、setだけがある。本調査は次の固定生成規則を採用した。全個品のset/main/sub値はツール出力の `mediumEquipment` / `highEquipment` に記録され、再生成してもIDと値は固定である。

- 中程度: ★5、初期サブ2、+9。+3/+6でサブが増えるため最終サブ4。slot 1/3/5固定main、2/4/6は通常抽選。setも通常抽選で、理想setになるまで再抽選しない。
- 高品質: ★6、初期サブ4、+15。5回のサブ強化を含む。通常抽選1回で、理想値選別はしない。
- 例（闇竜・中程度）: s1速攻 ATK+116 [SPD+5, DEF+13, HP+7.3%, crit+8.6%]、s2筋力 HP+49.2% [DEF+15, 的中+14%, ATK+17, DEF+6.9%]、s3体力 DEF+110 [抵抗+7.1%, crit+4.5%, HP+191, SPD+12]、s4守護 HP+55.5% [crit+3.6%, ATK+32, ATK+7.2%, 抵抗+6.9%]、s5速攻 HP+1232 [DEF+7.3%, HP+7.0%, ATK+36, 的中+6.5%]、s6抵抗 DEF+57.3% [SPD+6, 抵抗+6.6%, ATK+17, ATK+16.2%]。

これは「全員★6理想サブ4」ではない。高品質も理想選別なしだが、★6+15自体が完成域なので、ユーザーの「まとも」の上側感度として扱う。

## 10. AI、対象、撃破順

両陣営で同じAIを使う。使用可能な最大番号を必ず選ぶ（S3→S2→S1）。単体攻撃は属性有利→残HP**割合**最低、同率なら元配列順。単体味方はHP割合最低。全体は全対象。

敵の弱点:

1. 結晶は満HPでも初手S3回復を使い、回復分を完全に捨てる。
2. 次のS2 ATKバフはHP割合最低へ行くため、ボス固定ではない。少し削れたお供自身へ使うことが多い。
3. バフ残存/シールド残存を考えず最大番号を撃つ。
4. 呪晶も対象状況を見ず最大番号を即使用する。ただし全体技なので対象選択の無駄は小さい。

プレイヤーの強み/弱点:

- 闇竜S3、光竜S3、草スラS3は初手即使用され、支援2体を一気に低HP割合へする。
- その後の光ネメ単体技等は低HP割合へ集中し、自然に支援を落とす。
- 光ネメのスタン/ゲージ吸収も現在狙っている低HP対象へ集まり、反撃前にお供を止めやすい。
- 一方、水ウィスプは満HPでも初手S3を空撃ちするため最適ではない。

最頻撃破順は全ケースで **E3呪晶 → E2結晶 → E1ボス**。これは手動でギミックを理解しなくても、全体攻撃が低HP/低DEFのお供を相対的に大きく削り、低HP割合AIが自動集中するためである。回復阻害/剥がし役→回復/buff役→ボスというほぼ理想順になる。

## 11. 本番BattleEngineとの再現性

⑥ツールと今回ツールはいずれも本番エンジンを使うため、戦闘内部（属性、crit、命中対抵抗、CT tick、ATB/SPD、多段、方式E、防御無視、固定軽減、回復、シールド、buff/debuff、反撃、死亡）は一致する。差は「エンジン簡略化」ではなく**入力条件と集計**である。

|項目|一致/差|
|---|---|
|スキル選択/対象|本番 `chooseSkill/chooseTargets` と同一|
|属性/crit/方式E/防御無視|本番 `calcDamage` と同一|
|状態成功|本番のchance→的中/抵抗判定と同一|
|CT/SPD/行動順/多段/死亡|本番 `BattleEngine` と同一|
|反撃|本番bossTraitsと同一|
|装備|⑥は試行ごとに生成、速度だけ40択、+0。ユーザー実装備ではない|
|育成|⑥は全員★6 Lv60だがスキルLv1/0pt。資料の「スキル育成」「能力100」説明と不一致|
|編成|⑥高レアと実パーティは5体中0体一致（種族としてドラゴン/ネメシスはあるが属性・スキルが別）|
|乱数|固定seedで再現可能。ただし装備生成と戦闘が同じrngを共有し、装備抽選回数が戦闘乱数列も変える|

## 12. 乖離原因と10階評価

優先度順の原因:

1. **別編成**: 22%は実パーティを測っていない。
2. **闇ドラゴンS3の見落とし**: ⑥の説明は0.45×2単体を代表防御無視にし、2.0全体の実闇竜を評価していない。
3. **自然な役割完備**: 全体防御無視、全体制圧、単体処理+行動阻害、解除/盾/回復/免疫、毒が一編成に揃う。
4. **AIが理想撃破順を自動生成**: 呪晶→結晶→ボス。
5. **敵支援AIの浪費**: 満HP回復、ボス非固定buff。
6. **⑥の育成ラベル誤り**: +0装備、スキルLv1、0ptを「高育成」と総括した。
7. **実装備不明**: 2体が★6+15級なら100%を再現、★5+9級なら0%。「まとも」の語だけでは入力を一意にできない。

現在10階は無装備0%、中程度2体0%、中程度全員28%で、一般編成に一律簡単ではない。しかしこの適正5体では高品質2体だけで100%になるため、**特定編成に対して簡単すぎる構造**である。最高階安定を全体育成目標にする思想には届いていない。

目標勝率は提示案を維持する: 未/ほぼ未装備0～5%、一部中程度5～20%、全員中程度20～50%、十分育成した適正50～80%、完成適正90～100%。ただし「2体だけ完成、残り未装備」は一部装備帯として20%以下を目標に含めるべきである。

## 13. ⑥-2候補（今回は実装しない）

優先順:

1. 敵AI: 結晶S3は回復必要時、S2はボス優先。状況判定を先に直し、数値増加と混ぜない。
2. お供の早期蒸発対策: 呪晶/結晶のHPまたはSPD、Wave/登場順を小刻みに検証。単純HP2倍追加は避ける。
3. ボス側に全体防御無視連打への対策要求を持たせる。ただし闇竜ナーフ、防御無視無効という直接メタは避け、予告可能な反撃/段階ギミックを検討。
