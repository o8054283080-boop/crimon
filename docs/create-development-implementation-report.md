# ⑧-1 実装・バランス検証レポート

## 変更前と採用案

変更前は転生操作、保存フィールド、戦闘定義への適用口だけがあり、全タイプ倍率が1.0、能力ポイント上限は全★共通100だった。候補は「弱め」（主要+10%、SPD+5%）、「標準」（提示第一候補）、「強め」（主要+20%、SPD+10～12%）を比較した。弱めはLv60の丸め後にも役割差が薄く、強めはHP/DEF依存型が耐久と火力を同時に20%得ることや高速型の先手固定を強める。そこで**標準案を変更せず正式採用**した。各タイプに不得意または限定した得意分野があり、完全上位互換はない。

## 戦闘評価

ATK依存の通常攻撃・主力スキルは攻撃タイプで概ね+15%（クリティカル期待値はクリ率+5pt分だけ追加）で、1.5～2倍にはならない。HP依存は体力タイプ、DEF依存は防御タイプで概ね+15%だが、既存係数は不変。防御方式Eで同一攻撃を受ける場合、体力型は被ダメージ自体を変えずHPと生存回数が約15%増え、防御型は既存の逓減式により被ダメージを穏やかに減らす。最大HP割合はそれぞれ既存計算に従う。

高速代表（基礎SPD126）は補助136、妨害132。さらに能力ポイント100ptなら+10、その後に装備を適用し、戦闘中SPDバフは最終戦闘処理で掛かる。+8%を上限側にしたためタイプ単独で極端な固定化をしない。妨害型の的中+10ptは戦闘の命中/抵抗計算へ到達する。

## 能力ポイント・migration・UI

上限は★1～3=0、★4=20、★5=50、★6=100。ランクアップとタイプ転生で無料全リセットし、★6の任意全リセットだけ100,000 GOLD。ロード時は非整数・負数・その★の合計上限超過を全0へ安全に正規化するため、★4の20超、★5の50超、★6の100超は0、★6の100以内は維持する。型不正は従来通りnullへ戻す。

能力画面は★、使用/最大、残り、換算値、★1～3の解放案内、★6リセットボタンと確認文を表示する。タイプ画面は全正式補正と傾向を表示し、確認で選択タイプ、傾向、Lv1、EXP0、能力0を明示する。比較は装備構成で表示が揺れて誤解を生まないよう、数値の常時比較ではなく正式補正の並列表示を採用した。

STEP27は★6で100ptを利用でき、STEP28の転生で0になってもSTEP29はレベル条件、STEP30は再配分で達成可能なので条件変更は不要。潜在覚醒、スキル継承、防御方式E、各依存係数、装備性能は変更していない。
