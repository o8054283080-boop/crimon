# 試練の塔 HARD 40～70F 攻撃型再検証

## 結論

40～70FがNORMALとほぼ同じだった問題に対し、HP/DEFだけを増やすのではなく、ATKとSPDを大幅に上げた検証候補 `H4_MID_FINAL_OFFENSE` を作成した。

STRONG・同一seed・各200戦の直接比較では、NORMALの40～69Fが全階勝率100%だったのに対し、HARDは帯平均で40～49F 30.2%、50F 0%、51～59F 62.4%、60F 11%、61～69F 54.1%、70F 0%となった。NORMALとの差は明確になった。

ただし、敵編成ごとの強さの差が大きいため、50F 0%→51F 84.5%、60F 11%→61F 67%、67F 80%→68F 6.5%のような上下が残る。今回の候補は「40～70Fを明確に強くする攻撃型」の検証結果としては有効だが、自然な階段状カーブとしてそのまま本番採用する段階ではない。

## 評価

### 強さ

NORMALとの差は十分に生まれた。特に40、44、46、48～50、56、59～60、68～70Fは現STRONGの通常編成に対して明確な壁になった。46F、50F、70Fは勝率0%だが、今後の装備強化・アクセサリーを含む長期目標とする前提なら許容可能である。

### SPDと行動阻害

SPDを上げたことで、NORMALではほぼ行動できなかった敵がHARDでは実際に行動するようになった。たとえば46FはNORMALの敵行動発生10.5%からHARD 100%、48Fは30.5%から100%へ増えた。ゲージ操作・気絶で完全に封殺できれば突破余地は残るが、通常STRONG編成で敵に手番を渡すと壊滅する設計になっている。

### 耐久偏重の解消

初期案では40F 46.5%、46F 51.0%、48F 53.5%、50F 82.0%、68F 37.5%が時間切れだった。攻撃型へ振り直した結果、それぞれ8.0%、1.5%、7.5%、12.5%、1.5%まで低下した。DEFは一切増やしていないため、「硬いだけ」の難度ではなく、主に全滅圧で強くなっている。

### 難易度の崖

倍率を階ごとに調整しても、元の敵編成・スキル差が非常に大きく、勝率は単調にはならない。特に50→51F、60→61F、67→68Fは大きな崖または逆戻りがある。全帯を現STRONG勝率0～20%程度へ統一するなら、51、54、57～58、61～62、65～67Fをさらに個別強化する必要がある。一方、全階をほぼ0%へ揃えると編成差や制御戦術を試す余地が減るため、今回の候補は「通常階にも30～80%の攻略余地を残し、特定階を壁にする」案として扱う。
