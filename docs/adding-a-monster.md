# モンスターを1体足す手順

型チェックは通るのに中身が嘘、という壊れ方をする所なので、
**道具に見張らせながら進める。**

```
npx tsx tools/monsterDoctor.mts --new <種族名>   # 雛形を書き出す
npx tsx tools/monsterDoctor.mts --id <種族名>    # 書いたら検診
npx tsx tools/monsterDoctor.mts --table <種族名> # 属性ごとに何を引くか見る
npm run monster                                  # 全部まとめて検診
```

## 1. 雛形を出して貼る

`--new` の出力を `src/data/monsters.ts` へ貼り、
**`MONSTER_TEMPLATES` と `ALL_MONSTER_TEMPLATES` の両方**に足す。
`ALL_MONSTER_TEMPLATES` に入れ忘れると、検診とテストから漏れる。

## 2. スキルを書く

スキルは7本(スキル1 + スキル2の変種3 + スキル3の変種3)。

**説明文は効果と1対1で合わせること。** 倍率・発動率・ターン数・回数のどれかが
食い違うと検診が落ちる。逆に、効果があるのに説明文に書かれていない場合も落ちる
(この検診を作った時、バフ剥がしと回復封じが**一言も書かれていない**のが見つかった)。

**確率は書いてよい。**「65%で火傷」のような戦闘スキルの発動率は、
プレイヤーが編成を考えるために要る情報なので伏せない
(伏せるのはガチャの排出率とドロップ率だけ)。

## 3. 属性ごとに何を引くか確かめる

```
npx tsx tools/monsterDoctor.mts --table <種族名>
```

**どの属性がどの変種を引くかはハッシュで決まる。**
「この種族は盾を張る」と思っていても、属性によっては盾を持たない個体になる。

実際にこれで事故を出している。試練の塔の「守りの階」に
`templateId: "golem"` とだけ指定した結果、**半数の階に盾を張れる敵が1体もいなかった**
(ゴーレムが盾を持つのは草・水・光だけ)。

狙った効果を全属性に持たせたいなら、**変種3つ全部にその効果を入れる**。

## 4. 強さを測る

見た目のステータスだけでは分からない。既存のバランスに与える影響を測ること。

```
npx tsx tools/dungeonPressure.ts     # 装備ダンジョン
npx tsx tools/towerPressure.mjs      # 試練の塔
```

芯にある2つ(`docs/design-concept.md`)を潰していないかを確かめる。
とくに**通常モンスターの選択肢を狭めていないか**。

## 5. 仕上げ

```
npx tsc --noEmit
npx vitest run
npm run monster
```

3Dの造形(`src/web/three/creature/templates.ts`)は別作業。
造形を足さない場合は既存の骨格が流用されるので、**必ず実ブラウザで見て**、
別の種族と同じ姿になっていないか確かめること。
