# ⑧-3 潜在覚醒 実装・検証レポート

## 実装方式

`latentAbilityId` は `toBattleDefinition()` でO(1)索引から候補へ解決し、`MonsterDefinition.latentAbility` として戦闘単位へ渡す。BattleEngineは使用スキルの配列位置（S1のオブジェクト同一性）と `skillSlot=0` を照合するため、ID文字列へ依存せずS2/S3へ波及しない。戦闘中1回フラグはBattleUnitだけに保持し保存しない。

## effectType処理と216候補整合性

全72体・216候補を自動検査した。DAMAGE_UP（最終通常ダメージ倍率）、CRIT_TRIGGER（クリ結果へ追加倍率）、HP_SCALING/DEF_SCALING（装備・タイプ・能力点反映後の値）、DEBUFF_CHANCE_UP（同じ既存効果へ加算、100%上限）、ADD_DEBUFF（命中後にchance→正式命中/抵抗）、TURN_METER_DOWN、SELF_HEAL、ALLY_SUPPORT、SHIELD、ADD_BUFF、SPECIAL_TRIGGERを統一処理する。回復・盾は受け手の最大HP基準。インプの特殊効果は実際のデバフ成功が1件以上の時だけ1回発動する。

## 候補変更・属性固有変更・最終値

⑧-2から候補、chance、value、durationの変更はない。光/闇ドラゴン、ネメシス、セラフを再確認したが、潜在はS1限定でS2/S3へ影響しないため属性固有差し替えは行わない。闇/光ドラゴンはいずれも +12%、DEF低下+15pt、自己盾7%。ネメシスは+10%、強化不可20%/1T、HP30%以下反射1T/戦闘中1回。インプは+14%、スキル不可20%/1T、成功時ゲージ8%。ウィスプは+12%、強化不可25%/1T、自己7%回復。ゴーレムはDEF12%、挑発25%/1T、自己8%盾。トレントはHP8%、ATK低下30%/1T、自己6%回復。

## バランス評価

同一ブループリント単位の仮評価は、火力A=適正、妨害B=適正（インプBとウィスプBは強い寄り・継続監視）、耐久/支援C=適正。危険候補は高速妨害インプのスキル不可、毎手番全体DEF支援と併用するウィスプ強化不可、高速ネメシス強化不可。妨害タイプ・SPD100点は試行回数を増やすが、20～25%抽選と抵抗判定が常時封殺を防ぐ。DEF/HP係数は最終DEF/HPと相乗するが係数が12%/8%のため既存本体やタイプを変更しない。

固定seedの1000回インプ単発S1試験は `npm run latent:balance` で再現でき、成功186回、平均付与0.186回、機会を1行動に揃えた推定S2/S3阻害割合18.6%だった。これは長期対戦勝率とは区別する。ウィスプ/ネメシスのバフ失敗、ゴーレムの対象固定は正式状態効果経路を再利用し、既存状態効果回帰テストでも検証する。我慢は1T中の複数致死をHP1で耐え続ける既存仕様、反射は実HPダメージ25%で反射ループを作らない既存仕様を維持する。

## PvE・PvP・装備ダンジョン10階

通常ステージ、試練の塔、装備ダンジョン、アリーナはいずれも同じ `toBattleDefinition()` とBattleEngine経路を使うため有効。潜在なしは定義にフィールドを付けず旧挙動を維持する。10階の敵性能・装備・本体性能は変更していない。実パーティの統計的勝率は今回の再現可能な既存 `floor10:rebalance` 環境で別途測るべきであり、未計測値を捏造しない。潜在はS1に限定されるため、闇ドラゴンS3完全防御無視/吸収には影響しない。
