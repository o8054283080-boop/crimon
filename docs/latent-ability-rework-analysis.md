## 調査範囲と現行実装の事実

- `LATENT_ABILITY_CANDIDATES` は12種族の原本を6属性へ展開し、72体×3=216件を生成する。全IDは `{templateId}_{element}_latent_{1..3}`、全件 `skillSlot: 0` でS1限定である。
- `LatentAbilityCandidate` は `effectType/value/chance/duration/target/status/resolution/skillSlot` を持つ。現行effectTypeは `DAMAGE_UP/CRIT_TRIGGER/HP_SCALING/DEF_SCALING/DEBUFF_CHANCE_UP/ADD_DEBUFF/TURN_METER_DOWN/SELF_HEAL/ADD_BUFF/ALLY_SUPPORT/SHIELD/SPECIAL_TRIGGER`。
- **重要な基準差分:** 現在のリポジトリには `LATENT_ABILITY_BY_ID` も `BattleEngine.applyLatent()` も存在せず、`BattleEngine` は潜在データを参照していない。したがって現行216件は選択・保存・表示用の宣言であり戦闘未適用である。本書の評価は「宣言どおり実装した場合」の設計評価とし、将来実装時に索引と適用処理を追加する前提を明記する。
- 既存戦闘の敵対DEBUFF/STATUS/STUN/BLINDは発動抽選後に命中/抵抗処理を通す。潜在も同じ経路を使い、必中にしない。ゲージは0未満へ行かず、既存GAUGE drainは実減少量を術者へ移す。本案の半量吸収には専用表現が必要。
- スタン、防御DOWN、攻撃DOWN、速度DOWN、回復阻害、強化不可、スキル使用不可、挑発、暗闇、毒、シールド、我慢、反射、回復、ゲージ増減を状態定義・適用経路と全S1記述に照合した。毒は現候補にないため追加乱配しない。
- オーブ供給は恒久5個、月間0個。72体すべてを覚醒できないため、「数値が見える」「用途で選び直す」価値が必要である。再覚醒は同じID集合から再選択するので、A=火力、B=妨害、C=耐久/回転/支援を基本にする。

## 再設計ルール

1. **主＋副:** S1最終ダメージ10～20%＋軽い15～25%効果、デバフ率/持続強化＋成功時の小ゲージ操作、回復/盾量強化＋25%解除/軽い防御支援を基本とする。
2. **強デバフ:** STUN/SKILL_LOCK/BUFF_BLOCK/TAUNTは原則1T。追加スタンは「主デバフ成功後に10～15%」を標準（AoEは8～10%）とし、本表では既に強デバフを持つ候補へ重ねない。
3. **ゲージ:** 軽い副効果は-10%、専業妨害は-15%（最大-20%）。吸収は敵-15%・自身+7.5%を標準とし、実減少量の50%だけ加算する。抵抗された場合は双方0。
4. **持続:** ATK/DEF/SPD DOWN、暗闇、回復阻害など軽い効果は必要なら2T。強化不可、スキル不可、挑発、スタンは1Tを維持する。
5. **多段/AoE:** 全副効果は原則「S1使用1回につき1判定」、最終ヒット後に主対象へ解決する。AoEは主対象のみ、または全対象なら確率を単体案の60～70%へ落とす。ヒットごとの抽選は禁止。
6. **装備・タイプ:** ATTACK/高クリ率/高クリダメは火力案、DISRUPT/高SPD/高的中は妨害案、DEFENSEはDEF係数・盾、HPはHP係数・回復、SUPPORTは解除・味方ゲージ、BALANCEは用途選択が伸びる。抵抗は防御側の回答として維持する。
7. **未覚醒との距離:** S2/S3へ波及させず、追加ターン・確定強制行動・必中を配らない。未覚醒でも完成、覚醒でS1の個性が明確になる範囲に止める。

## effectType別方針

|系統|主効果|副効果上限・注意|
|---|---|---|
|DAMAGE_UP / CRIT_TRIGGER|最終+12～20%。クリ型はクリ時+20%|ゲージ±8～10%、軽デバフ15～20%。闇ドラゴン/ネメシスは下限寄り|
|HP_SCALING|係数+10～12%|回復阻害、自己回復、ゲージ-10%のいずれか|
|DEF_SCALING|係数+14～16%|攻撃DOWN、盾。挑発との二重制御は禁止|
|ADD_DEBUFF / CHANCE_UP|軽効果30～35%・2T、強効果20～25%・1T|成功時だけゲージ-8～10%等。すべて命中/抵抗あり|
|TURN_METER_DOWN|35%で-15%程度|高速反復を測定。吸収は一部個体だけ|
|SELF_HEAL / ALLY_SUPPORT|最大HP9～10%程度|25%解除、ゲージ+8～10%、超過の一部盾|
|SHIELD|最大HP11～13%・2T|25%防御UP 1Tまたは対象ゲージ+8%|
|ADD_BUFF / SPECIAL_TRIGGER|我慢/反射は戦闘中1回を維持|発動時ゲージ+20%。反射は30%目安、追加ATK DOWN20%|

ゲーム内文言は「S1ダメージ+17%。さらに20%で対象の行動ゲージを10%減少。」のように、主効果1文＋副効果1文の2行相当とする。判定単位・命中抵抗など共通規則はヘルプへ寄せ、各説明を3行以上にしない。

## 重点個体評価

- **闇ドラゴン:** 本体S3の防御無視・高火力へ潜在倍率を転用しないことが絶対条件。AはS1最終+14%に限定し、副効果ATK DOWNもS1対象だけ。B/CもS3の係数・防御無視・盾を変更しない。現B/A/C、再設計後はいずれもA想定。
- **光ドラゴン:** 支援・制圧S2/S3へ波及しない。BのDEF DOWN成功時-10%は単体S1の対象だけとし、全体制圧へ連鎖させない。現B/A/C。
- **インプ:** BのSKILL_LOCK20%はS評価。率・持続は据置、スタンを追加せず成功時自身+10%だけ。高SPD・DISRUPTでは拘束率を重点監視する。
- **ウィスプ:** BのBUFF_BLOCK25%はA評価。率を上げず成功時-10%で横方向に価値を足す。高速PvPで過剰なら-8%へ戻す。
- **ネメシス:** Bと高速の相乗、Cと高耐久反射を警戒。Aは+12%、Bは20%/1T据置、Cは戦闘中1回を維持する。
- **ゴーレム:** DEF係数、挑発、盾を役割分離。挑発＋スタンは作らず、盾時DEF UPも25%に抑える。
- **トレント:** HP係数、ATK DOWN、自己回復を長期戦向けに強化。回復の無限化を避け、超過盾は最大HP6%上限・2T。
- **セラフ:** 既存吸収とAの相乗はS1内だけ。Cは毎回確定の被クリDOWN 2Tが更新されるため、副支援は+8%まで。

## 将来の新effectTypeと複合データ構造

推奨新型は `METER_STEAL`（減少量と自己還元率）、`CLEANSE`（個数・確率）、`CONDITIONAL_DEBUFF`（HP/クリ等条件）、`BONUS_EFFECT_ON_DEBUFF`、`BONUS_EFFECT_ON_CRIT`、`OVERHEAL_TO_SHIELD`、`ON_ENDURE`、`ON_REFLECT`。追加ターン型は連鎖リスクから今回は採用しない。

単一 `effectType` の意味を過積載せず、次を推奨する。

```ts
interface LatentAbilityCandidateV2 {
  id: string;                 // 現IDを不変で維持
  skillSlot: 0;
  effects: readonly LatentEffect[];
  triggerScope: "SKILL_USE"; // 多段でも1回
  description: string;
}
interface LatentEffect {
  effectType: LatentAbilityEffectTypeV2;
  value?: number;
  chance: number;
  duration?: number;
  target: LatentTarget;
  status?: StatusEffectType;
  resolution: LatentResolution;
  requiresEffectIndex?: number; // 主効果成功時だけ副効果
  meterReturnRatio?: number;    // 吸収の50%還元等
  oncePerBattle?: boolean;
}
```

`effects[0]`を主、`effects[1]`を副とする。旧データはローダーで単一要素へ正規化できる。保存値は候補IDだけなので、**全216の既存`latentAbilityId`を変更せず効果本文を差し替え可能**。将来 `LATENT_ABILITY_BY_ID` を同じ候補配列から生成し、未知IDだけ安全に無効扱いする。

## 実装後のテスト／シミュレーション計画

1. 各候補で固定seedのS1を最低1,000回。発動率95%信頼区間、命中0/中/最大×抵抗0/中/最大を記録する。
2. 主デバフ成功率、条件付き追加スタン率（主成功数を分母）、総合スタン率、持続ターン占有率を測る。
3. ゲージ減少の試行平均・成功時平均・下限clamp、吸収の敵減少量/自己加算量と50%比を検証する。
4. 無潜在比の平均/中央値/P95ダメージ増加率、クリ率0/50/100%、高クリダメ、ATTACK型を比較する。
5. PvE長期戦（300T上限、ボス免疫あり/なし）で回復、盾、デバフ稼働率、討伐ターンを測る。
6. PvP短期戦（4対4、10～30T）を高SPD DISRUPT、高抵抗、防御、支援編成で総当たりし勝率差を±5pt目安にする。
7. 多段S1を1/2/3/5hitで実行し、副効果の抽選回数が常に使用回数と一致することをアサートする。
8. 全体S1は主対象だけの案と全対象60～70%率案を比較し、付与対象数・全員拘束率を測る。
9. STUN/SKILL_LOCK/BUFF_BLOCK/TAUNTの連続行動不能率、追加ターン相当のゲージ連鎖、反射・我慢の戦闘中回数を検査する。
10. セーブ互換、全216 ID索引、説明2～3行、再覚醒で同ID集合を選べることを回帰テストする。

## 覚醒オーブ価値と全体強化幅

恒久5個・月間0個の現状では60件のC候補は投資対象になりにくい。提案後は全候補をA相当（インプBはS維持）にし、主効果の数値だけは概ね1.15～1.5倍、副効果を含む**体感平均+40%**を推奨する。これはS1総ダメージを40%上げる意味ではない。火力は最終+10～20%内、強デバフ率は据置とし、潜在だけで勝敗が決まる場合は副効果率→値→条件の順に下げる。この範囲ならオーブ1個で明確な変化がありつつ未覚醒も実用的である。

## 最終推奨

このゲームに最も合うのは、**S1限定・主効果＋役割整合の軽い副効果・1使用1判定**へ統一し、強制制御の確率は増やさず横方向の選択価値を足す案である。火力、妨害、耐久/回転の三角形を各個体に作ることで、オーブが希少でも「誰に、どの用途で使うか」が面白くなり、未覚醒を未完成品にしない。
