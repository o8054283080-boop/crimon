## 装備ダンジョン10F比較

`npm run balance -- --help` の本番BattleEngine測定では、装備D10の全掲載完成級プローブが0%。塔50Fも上記2編成とも0%であり、少なくとも塔50FがD10より明らかに弱い状態ではない。敵残HPは塔50Fで87%/99%のため、塔50Fは非常に厳しい側にある。

## 特殊規則

- 70F超再生はボスがスタンせず実際に行動できる時だけ最大HP72%回復。HEAL_BLOCK適用後の共通回復処理を通る。
- 80F免疫は3ターン、4ボス行動ごとに再展開。永久免疫ではない。STRIPは命中・抵抗判定を維持したままIMMUNITYを剥がせる。
- IMMUNITYは既存仕様どおりGAUGE DOWNを防がない。80Fのためのグローバル変更は行わない。
- 90Fは8回目の実行可能なボス行動でATK/SPD永続段階変化。
- 100FはHP帯70%/40%/10%で超再生、免疫、狂化、最終強化を切り替える。
