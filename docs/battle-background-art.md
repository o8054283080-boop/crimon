# 戦闘背景の絵 — 発注仕様とプロンプト

戦闘画面の背景を2Dの絵にするための、**絵を描く側への注文書**。

モンスターは既に2Dになっている(`docs/monster-2d-art.md`)。
残っているのは舞台で、いまも3Dで組んだ闘技場が動いている。
ここを1枚の絵に置き換えると、画面全体が本当に2Dになる。

---

## 1. どこへ、どんな名前で置くか

```
src/web/assets/stages/<場所>.webp
```

| 名前 | どこで出るか |
| --- | --- |
| `arena-fire` | 敵チームに**火**属性が最も多い戦い |
| `arena-water` | 同じく**水** |
| `arena-grass` | 同じく**草** |
| `arena-electric` | 同じく**電気** |
| `arena-light` | 同じく**光** |
| `arena-dark` | 同じく**闇** |
| `arena-duel` | アリーナ(対人戦)。**届いた明るい闘技場がこれ** |
| `arena-tower` | 試練の塔 |

**まず1枚あれば動く。** 足りないぶんは近い属性の絵で代用するので、
8枚を描き切らないと何も出せない、という形にはしない。

いまの舞台は「敵チームで最も多い属性」で空気を変えている。
背景もそこへ乗せるので、**6属性ぶんあれば全ステージ・全ダンジョンを賄える。**

## 2. 規格(ここを外すと画面に載らない)

1. **縦長。1080 × 2160(1対2)。** 届いた闘技場は 864×1821 で、
   iPhoneの画面(390×844)とほぼ同じ比率だった。あの比率でよい
2. **透過は不要。** 画面いっぱいを埋める絵なので、背景まで描き切る
3. **上から約27%の高さに地平線。** そこより上が遠景、下が床
4. **床は下の73%を占める。** ここにモンスターが立つ
5. **人物・モンスター・生き物を描かない。** 舞台だけ
6. **文字・数字・ロゴ・枠・UIを描かない**
7. **明るすぎない。** モンスターは彩度の高いデフォルメ絵で、
   その手前に光る演出が重なる。背景が明るいと全部が同じ明るさになって
   何も見えなくなる。**主役はモンスター、背景は舞台**

### 画面のどこに何が乗るか

```
┌─────────────────────────┐
│  遠景(空・建物・地形)        │  上 0〜27%
├─────────────────────────┤
│ 札 │   モンスターが立つ床   │ 札 │  27〜88%
│ 札 │                      │ 札 │
├─────────────────────────┤
│  下の帯(スキルの操作欄)      │  88〜100%
└─────────────────────────┘
  ↑左13%          ↑右13%
```

- **左右の端(それぞれ13%)にはHPと行動ゲージの札が乗る。**
  ここに細かい模様や明るい部分を置かない。**やや暗く落としておくと札が読める**
- **中央の縦帯には攻撃の演出が出る。** 派手な光り物や、目を引く紋様を置かない
- **下の12%はスキルの操作欄が覆う。** そこは見えなくなるので描き込まない

## 3. 画風

モンスターと同じ世界に見えることが第一。

- **セル塗り+柔らかいグラデーション。** 厚塗りの写実にしない
- 遠くほど霞ませて、奥行きを色の淡さで出す
- 床は**平面ではなく、奥へ向かう遠近**を付ける。
  ただし消失点を極端にしない(モンスターは同じ大きさで並ぶため)
- **モンスターより彩度を落とす。** 背景が主張すると、
  かわいいデフォルメのモンスターが背景に溶ける

### 属性ごとの舞台

| 名前 | 場所の案 | 色の芯 |
| --- | --- | --- |
| `arena-fire` | 溶岩の岩場。ひび割れた黒い岩と、赤く光る裂け目 | 赤黒〜橙 |
| `arena-water` | 浅瀬の遺跡。水を張った石畳、遠くに滝 | 藍〜青緑 |
| `arena-grass` | 森の広場。苔むした石畳と、囲む大樹 | 深緑〜若草 |
| `arena-electric` | 雷雲の下の高台。走る稲光と、帯電した石柱 | 紫紺〜山吹 |
| `arena-light` | 天空の神殿。白い大理石と、差し込む光の柱 | 生成り〜淡金 |
| `arena-dark` | 月下の廃墟。崩れた黒石と、紫の霧 | 藍紫〜黒 |
| `arena-duel` | 明るい闘技場。観客席・旗・円形の石畳(**届いた絵**) | 砂色〜青空 |
| `arena-tower` | 塔の内部。石壁が上へ伸び、下へ深い闇 | 灰紫〜金 |

### 6属性ぶんを揃えるとき

**1枚目を描いたあと、それを見せて「同じ世界の別の場所」として続ける。**
最初から6枚別々に頼むと、画風も明るさもばらばらになり、
戦うたびに別のゲームに見える。

```
いま描いた背景と**同じ画風・同じ明るさ・同じ構図**で、
<場所の案> を描いてください。
色の芯だけ <色の芯> へ変えます。
規格(1080×2160・地平線は上から27%・人物やUIを描かない・
左右の端を暗く・中央は空ける)は前回と同じです。
```

## 5. 受け取ったあとの手順

```
art/stages-raw/ へ <名前>.png のまま置く
node tools/prepareBackgrounds.mjs
    → src/web/assets/stages/<名前>.webp
```

道具が縮小とWebPへの変換をする。**切り抜きはしない**
(背景は画面いっぱいを埋めるので、余白を測る意味が無い)。

確かめ方はモンスターの絵と同じ。

1. `node tools/harness.mjs` を起こし、戦闘画面で実際に見る
2. `HARNESS_PORT=<port> node tools/tour.mjs` を通す
3. **モンスターが背景に溶けていないか、自分の目で見る。**
   数値では拾えない。背景が明るすぎると全部が同じ明るさになる
